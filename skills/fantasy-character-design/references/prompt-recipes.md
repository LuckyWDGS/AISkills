# Prompt Recipes

## 1. Full Character Sheet Prompt Formula

```text
Create a tall premium fantasy character design sheet, no tiny generated text inside art panels.
Character: [name], [archetype].
Identity lock: [face, hair, expression, body proportion].
Costume lock: [silhouette, fabric, jewelry, sleeves, train, footwear].
Materials: [material list].
Props and magic motifs: [prop list].
Palette: [main, secondary, highlight, metal, shadow].
Reference strategy: [face/costume/prop/style anchors with priority, weight, crop, focus, and lock].
Layout: large full-body hero illustration on the left, front/side/back turnarounds on the right, face close-up, eye close-up, fabric and accessory detail panels, footwear detail, magic prop panel, palette chips.
Style: [xianxia / mythic / game concept art / dark luxury / ethereal].
Avoid: [avoid list], extra characters, modern objects, random costume changes, unreadable text, comic storyboard timeline.
```

## 2. Chinese Full Sheet Prompt

```text
生成一张竖版高级玄幻角色设定板，画面内不要生成小字，文字后期排版添加。
角色：[角色名]，[角色身份]。
身份锁定：[脸型、发型、眼神、身材比例、气质]。
服装锁定：[服装廓形、袖型、裙摆、披帛、首饰、鞋履]。
材质：[薄纱、丝绸、水晶、玉石、金属、花瓣、星尘等]。
法器/符号：[法器、魔法阵、花枝、星盘、剑、权杖等]。
色彩：[主色、辅助色、光效色、金属色、阴影色]。
参考策略：[脸部/服装/法器/风格锚点的 priority、weight、crop、focus、lock；冲突时先看 priority，再看 weight]。
版式：左侧大幅全身主立绘，右侧正面/侧面/背面三视图，下方脸部特写、眼睛特写、服装材质、法器、鞋履、色卡分区。
风格：唯美玄幻、国风仙侠、游戏美术设定稿、暗色高级长图、细节丰富、角色一致。
避免：多角色混乱、现代物件、科幻机甲、随机换服装、画面内乱码文字、漫画分镜时间线。
```

## 3. Section Prompts

### Hero Full Body

```text
Full-body hero illustration of [name], [archetype], [identity lock], wearing [costume lock], holding or surrounded by [prop/magic motif], [palette], premium fantasy game character concept art, clean no-text art panel.
```

### Turnaround

```text
Character turnaround view, [front/side/back], same [name], same face, same hair, same costume silhouette, neutral standing pose, clear costume construction, no text, no background clutter.
```

### Face Close-Up

```text
Face close-up of [name], preserve face shape and hairstyle, [eye/makeup details], expression [temperament], high-detail fantasy portrait crop, no text.
```

### Eye Detail

```text
Extreme close-up of one eye, [iris color/motif], [magic glow], same character identity, high-detail concept-art crop, no text.
```

### Costume Material

```text
Close detail panel of costume materials: [fabric, embroidery, jewelry, transparency, trim], same palette, tactile texture, no text.
```

### Prop Or Magic Device

```text
Design panel for [prop], [shape language], [magic color], [ornament logic], fantasy prop concept art, no text.
```
