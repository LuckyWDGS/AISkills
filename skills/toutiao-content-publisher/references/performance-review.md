# 只读检查头条图文效果

用于“之前发的效果如何”等请求。先确认用户要求的平台和题材，只读文章管理及内容数据；不发布、编辑、删除、点广告收益开关、回复互动或建立自动监控。用户暂缓检查头条时，不因安装或更新本 Skill 自动恢复检查。

## 定位作品与记录口径

- 在当前账号文章列表定位题材，以真实文章 ID 为主键，标题和封面辅助。区分审核中、定时待发、已发布与历史缺记录；未在本次列表看到不等于从未发布。
- 记录采集时间／时区、平台、内容类型、筛选条件、分页范围、首发日期筛选和指标统计窗口。按首发日期筛选不等于数据只累计该区间。
- 读取当前页面实际提供的指标，例如展现、阅读、点击率、阅读时长、互动、收藏、涨粉及收益；不预设每个账号均有这些字段。原始名称和单位照录，平台未展示的记未知，不填零。
- 用作品 ID 对齐管理页与数据页，保留数据更新时间。正文文章、微头条、图集和视频分别统计，不能借另一平台的 ID 或表现补齐。
- 后台截图和逐条指标留在项目指定的本地目录。汇总报告可按用户要求交付，但不默认提交真实后台指标或收益到 GitHub／Skill 源码。

## 分析与交付

区分进入分发、展现到阅读、阅读深度、互动收藏、关注转化。只有页面确有相应指标时才判断该环节，不能用点赞推断读完或粉丝，用服务器预览存在推断有效阅读。

计算派生率时写清分子分母，例如收藏次数／阅读次数、涨粉／阅读次数；这是次数比，不等于去重读者转化率。官方点击率保留原值；展现与阅读的统计口径不一致时不自行替代。跨篇汇总用总分子／总分母，不简单平均百分比。分母为零或未知时比率未知；“万”等缩略数字标近似。

比较时优先同平台、同类型、相近发布后观察窗口和统计范围。累计值受发布时间影响，无法统一窗口就说明局限，不直接给不同年龄文章排绝对优劣。收益仅用后台实际展示数据；广告开关开启不等于已经获得收益。

交付作品清单及来源时间、已展示指标、可支持的发现、证据不足处和下一条可验证改动。区分事实与创作判断；对首图、标题、空间主题或互动问题提出单变量假设和观察指标，不承诺流量，不凭低阅读归因限流。观察窗口建议不等于已创建提醒或获得下次自动执行授权。

单次快照无法证明某个标题或 A/B/C 形式导致结果，不能直接当作严格 A/B 实验。历史表只保留原日期；没有本次在线数据时明确仅能分析历史证据。
