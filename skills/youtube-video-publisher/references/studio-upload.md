# YouTube Studio 上传核验

适用：把用户已确定的成片通过 YouTube Studio 网页上传并填写到发布前。下列为 Studio 上传向导的稳定结构；按钮文字、字段位置、上限和资格要求每次以当次界面为准，界面与本文不一致时按界面执行并在记录中注明。

## 频道与查重

- 入口：`https://studio.youtube.com`。出现 Google 登录页时请用户在同一浏览器里登录，说明是哪个浏览器、哪个页面；等待期间做本地准备，不循环刷新。
- 一个 Google 账号可有多个频道（品牌账号）。核右上角头像菜单显示的频道名/句柄；与用户预期不一致就停下问，不自行切换。
- 在“内容 → 视频/Shorts”中按标题、时长和上传日期查重，草稿也算。发现疑似同片时先问用户，不重复上传。

## 格式判断：Shorts 与长视频

- 先实测成片：宽×高、时长、fps、编码、音轨、文件 hash。
- 竖版或方形、且时长在当次平台 Shorts 上限内的视频会被归为 Shorts；横版 16:9 走长视频。比例由文件决定，上传后无法在 Studio 里改。
- 同一内容想同时发 Shorts 和长视频，是两条独立上传，需用户分别确认。
- 竖片改横版不是发布环节的工作：交 douyin-ai-creator-lab 适配并验片，保留竖版源和独立横版文件。

## 上传

- “创建（Create）→ 上传视频（Upload videos）→ 选择文件”。用浏览器工具对页面的文件输入设置本地文件；工具拒绝该路径时，可把成片复制到工具允许的目录（如系统临时目录下的唯一子目录），核 hash 一致后再选，原文件保留。
- 浏览器扩展通常只能上传本会话可读目录内的文件；项目目录被拒时复制到会话临时目录，核 hash 后上传。
- 选中文件后向导立即打开并开始上传，标题默认取文件名；频道内同时生成一条私享草稿（标题栏显示“已保存为私享视频”），视频链接在上传开始后即出现在右侧预览下方。小文件的版权检查可能在填详细信息期间就完成。上传进度、“正在处理 SD/HD”与“处理完成”是不同状态，分别记录。高清版本可能晚于 SD 完成，不影响填写。
- 同一可恢复故障最多重试两次；重试前先查“内容”列表是否已存在该草稿，避免重复。

## 详细信息

必填与常用字段（中英文界面名称对照）：

| 字段 | 要点 |
| --- | --- |
| 标题 Title | 必填，上限以页面计数为准（目前为 100 字符）；不能包含 `<` `>`。标题承诺必须在片中兑现，不堆关键词 |
| 说明 Description | 上限以页面计数为准（目前为 5000 字节）；可写来源、AI制作方式、章节。章节时间戳须来自实际剪辑时间线，首个为 `0:00` |
| 缩略图 Thumbnail | 长视频可自定义；入口灰显通常是频道未完成验证或功能资格不足，如实报告。Shorts 封面在手机端/上传时选帧，网页可能不提供 |
| 播放列表 Playlists | 仅用户指定时加入 |
| 受众 Audience | 必选“是/否，为儿童打造”。按内容如实选择，并在交接时告诉用户；年龄限制只在内容需要时开启 |
| 付费宣传 Paid promotion | 有赞助、植入或品牌合作才勾选 |
| AI 使用情况（原“合成内容 Altered content”） | 2026-11 中文界面在“展开”后问“是否以下列任何方式使用 AI 生成或编辑了内容？”，四类：冒充真实人物言行、加工真实事件或地点片段、生成逼真但不存在的场景、**创作作为视频核心内容的音乐**。命中任一类选“是”（会加标签）；明显非写实、仅辅助制作时可为“否”。代码/AI 合成的配乐也要对照第四类。拿不准就选“是”并告诉用户 |
| 自动章节 / 精选位置 | 保持默认，用户要求时调整 |
| 标签 Tags | 可选，总长有上限（目前为 500 字符）；只放与片子真实相关的词 |
| 语言、字幕认证 | 视频语言按实际旁白/文字选择；无语音时可选“不适用”或按页面选项 |
| 录制日期与地点 | 不编造；无实拍时留空 |
| 许可与分发 | 默认“标准 YouTube 许可”，允许嵌入；用户要求时改 |
| 类别 Category | 按内容选（如 电影和动画、艺术、娱乐） |
| 评论与评分 | 保持默认或按用户偏好 |

- 无字画面不代表省略声明；用户不要画内文字时不自行叠字幕、水印或AI字样，平台元数据和合成内容声明照常填写。
- 不点击“AI生成标题/说明/缩略图”类建议，除非用户要求。

## 视频元素与检查

- 字幕、片尾画面、卡片默认跳过；用户要求时再添加，片尾画面需要长视频且有足够时长。
- “检查”步骤会扫描版权与广告适宜性。等待到明确结果（未发现问题 / 发现问题 / 仍在检查）并如实记录；有声明或限制时停下告诉用户，不自行申诉、静音或剪辑。

## 可见性与交接

- 选项：私享 Private / 不公开 Unlisted / 公开 Public / 安排时间 Schedule（可设首播 Premiere）。用户说“发布到 YouTube”且没有其他要求时选公开；只说上传、准备或没有表态时选私享。无论哪种都在交接时说明。
- 最终按钮随可见性变化：私享/不公开显示“保存”，公开显示“发布”，安排时间显示“安排时间”。鼠标停在最终按钮上时不要发出任何点击。
- 默认在此步停下，不点击“发布 / 保存 / 安排时间”。保留页面，告诉用户：频道名、标题、可见性、受众与合成内容所选项、检查结果、还差点击哪个按钮。
- 关闭向导而不点击最终按钮，已填信息通常会作为草稿保存；但用户若要在同一窗口最后处理，就不要关闭向导或刷新页面。
- 获得本条最终授权时只点击一次，随后在“内容”列表核视频 ID、可见性、处理状态与限制列，并打开 `https://youtu.be/<视频ID>` 只读确认可播放。由用户自行点击的记为 user-reported，除非实际回读到状态。
- 用户未要求监控时只记录本次可见状态；不建定时监控、不回复评论、不改变现金化设置。
