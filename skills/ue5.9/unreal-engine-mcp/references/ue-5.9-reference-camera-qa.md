# 参考照片机位与局部几何复核

适用于透视相机、居中投影、方形像素。准备 UE 世界坐标（cm）、水平 FOV（度）和原照
像素对应点。输入格式及完整示例见[室内搭建参考](ue-5.9-reference-interiors.md)。

## 比较两个机位

1. 从已保存的相机 actor 读世界位置、旋转、水平 FOV、画幅和裁切。保留这份基线。将
   窗、台面和近景物体的不同深度地标列入同一份 `anchors.json`。预先选择至少一个权
   重为零的留出点，可在远、中、近景各留一个。给每个点命名到具体位置，例如“门板靠
   入口一侧的下角”。
2. 在技能目录运行下列命令。第一行以 `anchors.json` 内的机位为基线，比较已有候
   选。第二行从标注文件中的搜索起点拟合，同时用另外保存的基线评分。两个姿态都用
   同一份世界点、像素和权重重新投影。相机文件可以只有 `location`、`rotation`、
   `fOV`，也可直接使用此前包含 `camera` 的 JSON 结果。

   ```text
   python scripts/fit_reference_camera.py anchors.json --candidate-camera candidate.json --photo reference.png --overlay poses.png
   python scripts/fit_reference_camera.py anchors.json --baseline-camera saved-camera.json
   ```

3. `initialWeightedRmsPx` 描述标注文件中的搜索起点。`baselineWeightedRmsPx`、
   `baselineHeldOutRmsPx` 描述选定基线。`weightedRmsChangePx` 和
   `heldOutRmsChangePx` 都取候选减基线，负值表示与标注更接近。检查每点的
   `photoPx`、`baselineProjectedPx`、`projectedPx` 和 `offsetPx`。`offsetPx` 是
   候选投影减照片标注，正 X 向右、正 Y 向下。留出计数为零，或有留出点在基线相机
   后方时，留出变化显示为 `null`。
4. `poses.png` 左侧保留原照片的完整像素网格，右侧图例列出名字和拟合用途。黄十字
   标出照片点，橙方框与青圆圈分别标出两个姿态的离线投影。使用单独的 PNG 输出路
   径。可视化需要 Pillow，已存姿态比较只需 NumPy，重新拟合另需 SciPy。

## 验证位置误差来自哪里

- 把真实 UE 截图与原照放到同一构图、同一像素网格。使用实际被渲染的相机 actor，记
  录实际输出宽高、水平 FOV、世界变换和宽高比约束。全幅等比例缩放时，像素中心坐标
  换算为 `(x + 0.5) × 缩放比例 − 0.5`，Y 同理。黑边、裁切和不同宽高比会改变这个
  换算。
- 分别标记原照可见的轮廓和 UE 实渲上的同名轮廓。门板、底板和黑色装饰条常在同一条
  缝附近形成几条边。出现台阶时分别记录两侧的门角。低对比或遮挡让地标无法辨认时，
  记录缺测和原因，再用清晰可见的五金件复核。
- 窗、墙和柜体共同向同一方向偏移时，回看镜头与画幅。误差集中在一排柜子时，锁住机
  位与其他布置，再试门宽、隔断位置、柜底高度和把手。单张照片的一条射线不能唯一确
  定三维尺寸。若将射线交到已知门面上，请记下固定的平面、相邻尺寸与接触条件。
- 改模型时保持室内接触关系。分两档柜高可以同时锁住顶线、门板水平边和把手尺寸。按
  新柜底调整灯槽、烟机安装垫和对应灯源的高度。由拟合门角得出的新尺寸应再用独立的
  可见部件、实际渲染及另一机位检查。

一次厨房样例用 23 个正权点和 3 个留出点评估已保存机位。重新拟合后，正权 RMS 从
13.76 降至 13.51 像素，留出 RMS 从 17.13 升至 20.59 像素。保留已存机位后，逐像素
检查发现一处原标签位于烟机饰条，两侧真正的门板下缘相差约 13 像素。保留最初的标注
及结果，新标门角独立列出，方便复核几何改动。

六个设计门角的离线投影 RMS 从 24.82 降至 8.05 像素。随后用相同曝光和同一相机渲染
修改前后各一帧，将两张 1158 × 1178 的全幅图缩至照片的 579 × 589 像素网格，另取可
见轮廓和四个把手验收。

| 实际画面量测（照片像素） | 参考照片 | UE 调整前 | UE 调整后 |
| --- | ---: | ---: | ---: |
| 门板两侧的台阶高度 | 13.63 | 约 0 | 12.37 |
| 三处木门下缘相对原照的纵向 RMS | — | 15.60 | 7.79 |
| 四个独立金属把手中心相对原照的二维 RMS | — | 30.25 | 12.03 |

门板底边取 X 为 302、345、430 的三个固定截面，沿可见木门面进入底边时的明度下降定
位。台阶在接缝两边分别描线并外推到缝中心。把手在各自的裁框内按金属与木面的色差提
取，改变阈值后结论一致。远端两个截面的门板仍比照片低约 9–10 像素。入口附近木边与
灯槽高光重叠，该处未纳入底边 RMS。
