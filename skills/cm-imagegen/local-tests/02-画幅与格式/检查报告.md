# cm-imagegen 参数与画幅实测

本轮使用 gpt-image-2.6-sunburst，quality=max、complexity=high，同一网关。每个案例只提交一次。前三个案例提示词完全一致，仅改变 size；追加案例单独检验明确画幅提示词。所有原图保持服务返回字节，未裁剪、缩放或转换格式。

仅改变 size 的三次请求均返回 1536×1024。明确写 1:1 后返回 1254×1254 方图；明确写 2:3 竖版后返回 1024×1536，符合目标。GIF 被当前请求通道以 HTTP 400 拒绝：尚未启用；SVG 请求实际返回 PNG，未获得矢量文件。

| 案例 | 请求 | 实际返回 | 画幅比例 | 精确尺寸/格式 |
|---|---|---|---|---|
| 方图：只改变 size | 1024x1024 / png | 1536x1024 / png | 不匹配 | 未通过 |
| 横图：只改变 size | 1536x1024 / png | 1536x1024 / png | 匹配 | 通过 |
| 竖图：只改变 size | 1024x1536 / png | 1536x1024 / png | 不匹配 | 未通过 |
| GIF 动画 | auto / gif | 未返回可读文件 / — | — | 未通过 |
| SVG 矢量 | 1024x1024 / svg | 1536x1024 / png | — | 未通过 |
| 方图：加入明确构图提示 | 1024x1024 / png | 1254x1254 / png | 匹配 | 未通过 |
| 竖图：加入明确构图提示 | 1024x1536 / png | 1024x1536 / png | 匹配 | 通过 |

客户端已加入：GIF 帧数/时长、SVG 与可选作者模型、markup 标注编辑、压缩、流式预览参数、审核级别及匿名用户标识。SVG 编辑因官方文档不一致暂未启用。默认不再发送旧 response_format。

77 项离线测试通过，技能结构校验和 diff 空白检查通过。该结果不证明网关透传了所有参数，也不证明真实上游模型身份；实测只依据收到的文件。
