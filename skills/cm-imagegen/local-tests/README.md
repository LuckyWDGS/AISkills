## 已有结果

- 11月8日文生图/图生图：两次均取得PNG，后者保留主要场景并改变天气、时间和光线；两图实际均为1672×941，未达到请求的2560×1440。已核对提示词、输出及编辑基底哈希，仅作为单次生成/编辑参考。
- 模型对比：八个条件均取得可读图片，2.6 Sunburst 在该次样本中获得 96 / 96 分；八张原图均未满足请求的 2560×1440，不能视作已验证的原生 2K 排名。
- 画幅：仅改变 size 时未稳定遵守目标画幅；明确画幅提示词的追加测试得到方图和竖图。实际分辨率仍需逐张核对。
- SVG / GIF：两次 SVG 请求实际返回 PNG；两次 GIF 请求返回“GIF output is not enabled for this request.”。后续网关检查见后台诊断，格式权限仍取决于上游。
- 历史排查反映当时服务状态；其旧版源码结论不能代替后续网关检查。
