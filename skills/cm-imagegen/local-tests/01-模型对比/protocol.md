# 2.5 / 2.6 四模型统一条件评测

评测登记日期：2026-11-07。开始生成前保存此协议。

## 范围与条件

- 模型：gpt-image-2.5-flare、gpt-image-2.5-sunburst、gpt-image-2.6-flare、gpt-image-2.6-sunburst。
- 每个模型各一张文生图 T1 和一张图生图 I1，共 8 个独立样本。保留首个结果，不挑图，不修图。
- 当前配置的同一个 cm 网关，Images API；generate 和 edit 各使用对应端点。保持请求模型 ID 原样，不换路由或替代模型。
- 统一参数：size=2560x1440，quality=max，n=1，output_format=png，response_format=b64_json；不传 complexity、reasoning 或 seed。当前 CLI 无 seed 参数，因此不声称同随机种子。
- 严格核验返回原图尺寸；不放大冒充原生 2K。单次请求最长网络等待 900 秒；每项 max_attempts=1，防止重复计费与挑选结果。异步任务由技能内置机制恢复或轮询。
- 每项提示词文件内容完全相同，以 SHA-256 验证；I1 输入为同一张独立程序绘制的 2560×1440 参考图，不来自四个受测模型。
- 文生图为复杂场景生成；图生图为布局约束下的写实转换加三处语义修改，不代表人脸身份保持或所有编辑任务。
- 先随机打乱模型对应的 A/B/C/D 评审代号，在完成视觉评分前不读取对应表。流程提供匿名图片评审，不声称经过独立双盲实验。
- 请求模型名称只代表发送的 ID。除非网关另提供可核验的上游信息，不声称已验证底层权重身份。

## 预先固定的评分

每项 100 分，延迟不计入画质分。失败或无可读图片为 N/A，不记为 0 分。尺寸不符单独列为不满足 2K。

T1 文生图：

1. 指令与关系 40：四人身份/位置 10；单只怀表交接 6；灯壶杯的数量与位置 10；猫与时钟 8；两处文字 6。
2. 解剖、几何与物理 20：手指/接触 8；人体与面部 5；透视、遮挡、倒影与透明介质 7。
3. 细节与材质 20：工具/齿轮 7；玻璃/金属/木材/织物 8；微细节清晰度 5。
4. 构图、光照与美感 15。
5. 画面洁净度与伪影 5。

I1 图生图：

1. 指定修改 35：顶部标题 10；02 瓶钴蓝 10；新增展示盒及单只完整蝴蝶 15。

3. 材质、细节与几何 20。
4. 整体构图与光照 10。

综合分 = 文生图与图生图各占 50%，仅在两项均有有效结果时计算。
