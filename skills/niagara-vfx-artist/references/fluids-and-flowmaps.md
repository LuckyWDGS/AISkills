# Niagara Fluids 与 Flow Map 方案指南

## 用途

这份文档用于处理“流体类高级特效”的方案判断。

适合在这些场景读取：
- 用户要做水流、烟流、火流、液体、波浪、喷溅
- 用户给出 Flow Map 参考图，想知道怎么落地
- 需要判断该用 Niagara Fluids、Flow Map、还是烘成 Flipbook
- 需要理解 Niagara Fluids 里关键参数怎么调

这份文档主要基于 Epic 官方资料整理：
- Fluid Simulation Overview
- Niagara Fluids in Unreal Engine
- Summary Quick Start Guide
- Niagara Flipbook Baker Quick Start Guide

## 1. 先做大判断

流体类特效不要一上来就决定“用 Niagara Fluids”。

先判断三件事：

1. 这是 **表面流动**，还是 **体积流体**
2. 这是 **实时长期运行**，还是 **一次性镜头/英雄效果**
3. 这是 **真实交互需求**，还是 **视觉假象就够**

这是最重要的决策逻辑。

### 一句话版

- **表面流动**：优先考虑 `Flow Map`
- **体积烟火水气**：优先考虑 `Niagara Fluids`
- **成本太高但视觉需要保留**：考虑 `烘成 Flipbook`

## 2. Flow Map 是什么

你给的图本质上是在说明：

- 普通 UV 是规则平铺
- 经过变形后的 UV 会沿着某种流向被扭曲

Flow Map 通常是一个 **UV 偏移方向图**。

最常见理解：
- `R/G` 通道存方向或偏移
- 材质采样时根据 Flow Map 改变 UV
- 让贴图“看起来像在流”

### 它最适合什么

Flow Map 最适合：
- 河流表面
- 水面流向
- 魔法能量流
- 熔岩表面
- 护盾表面流动
- 布满表面的流动纹样

### 它不擅长什么

它不适合：
- 真正的体积烟雾
- 真正会碰撞溅起的液体
- 大规模真实气体翻卷
- 真实液体物理交互

所以：

**Flow Map 更像“材质层的假流体”。**

## 3. Niagara Fluids 是什么

Epic 官方对 Niagara Fluids 的定位很清楚：

- 它是基于 Niagara 基础设施构建的实时流体系统
- 支持气体和液体
- 支持 GPU 计算
- 可以用于实时，也可以烘焙成 Flipbook

官方文档强调了几个关键点：

### 它更真实

相比简单粒子方案：
- 流体模拟结果更自然
- 更像真实翻卷、扩散、受碰撞影响

### 它更重

官方明确提醒：
- 这是图形上较重的方案
- 可能有较高 GPU 开销

### 它适合烘焙

官方也明确说：
- 很多复杂流体结果可以烘成 Flipbook
- 然后再拿去做更便宜的实时方案

所以真实项目里很常见的工作流是：

1. 用 Niagara Fluids 做高质量模拟
2. 烘成 Flipbook
3. 在正式游戏中用 Sprite / Material 播放

## 4. Unreal 官方流体类型

根据 Epic 官方 `Fluid Simulation Overview`，Niagara Fluids 常见类型有：

### 2D Gas

特点：
- 在二维域中模拟气体
- 比 3D 更便宜
- 适合实时游戏
- 可以伪装出 3D 感

特别适合：
- 火把火焰
- 小型火焰
- 小型烟流
- 屏幕朝向的气体效果

### 3D Gas

特点：
- 真实体积深度
- 更复杂的翻卷和流动
- GPU / 内存成本更高

适合：
- 英雄火焰
- 电影镜头烟火
- 需要体积感的气体

### 2D FLIP

特点：
- 粒子 + 网格混合
- 用于液体
- 比 3D 液体更便宜

适合：
- Splash
- 喷溅
- 假 3D 液体飞溅

### Shallow Water

特点：
- 更适合浅水面
- 高度场
- 不强调大量飞溅

适合：
- 水面波纹
- 船尾波
- 浅水互动

### 3D FLIP

特点：
- 最强的液体表现
- 可以做河流、浪、水体交互
- 最重

适合：
- 英雄水体
- 大型液体交互
- 高要求镜头

## 5. 什么时候用什么

### 场景 1：河面流向 / 水面流动

优先：
- `Flow Map + Material`

原因：
- 这是表面流动，不一定需要真实体积解算
- 便宜
- 容易控

### 场景 2：火把火焰

优先：
- `2D Gas Niagara Fluids`
或
- `Fluids 烘 Flipbook -> Niagara Sprite`

原因：
- 火焰需要体积感和翻卷
- 但常驻场景里往往不想实时跑太贵

### 场景 3：英雄级烟火 / 爆炸烟柱

优先：
- `3D Gas`
或
- 先 3D Gas 再烘焙

### 场景 4：水花、喷溅

优先：
- `2D FLIP`
或
- 更复杂时 `3D FLIP`

### 场景 5：浅水面、船尾波、脚踩水纹

优先：
- `Shallow Water`

### 场景 6：流水魔法、能量表面、护盾流动

优先：
- `Flow Map`

原因：
- 这类往往是表面假流动
- 不值得上完整流体模拟

## 6. Niagara Fluids 关键参数理解

下面这些是从 Epic 官方流体概览和 Summary View 逻辑里最应该理解的参数思路。

### 1. Grid Cell Size / Resolution

官方明确指出：
- 更小的网格单元 = 更高质量
- 但成本更高

理解方式：
- 你越想要细小翻卷和清晰细节，就越要更高分辨率
- 但 GPU 成本会上去

调参逻辑：
- 先从低分辨率跑通形体
- 再逐步提分辨率补细节
- 不要一上来拉满

### 2. Pressure Solve / Iterations

官方说明：
- 压力求解是让流体真实绕物、翻卷的重要环节
- 更多迭代 = 更真实
- 也更贵

调参逻辑：
- 如果流体显得“散、松、没卷起来”
  可以考虑提高求解质量
- 但要注意性能

### 3. Density

官方指出：
- 烟雾渲染时通常可视化的是密度网格
- 密度高的地方更不透明

调参逻辑：
- 密度高：烟更厚、更重
- 密度低：烟更轻、更薄

### 4. Temperature

官方指出：
- 火焰中温度影响颜色
- 更高温的气体上升更快，受浮力影响更明显

调参逻辑：
- 提高温度：更亮、更热、更上升
- 降低温度：更像普通烟，不像火

### 5. Buoyancy

和温度一起理解最有效。

调参逻辑：
- 高浮力：更明显上升
- 低浮力：更容易横向蔓延或停滞

### 6. Source / Injection

这是流体“从哪里进系统”的关键。

常见理解：
- 粒子源
- 发射器源
- 数据通道源

调参逻辑：
- Source 太弱：看不到明显形体
- Source 太强：整体太满，难控制

### 7. Noise / Turbulence

官方 Summary View 示例中就把：
- `Noise Strength`
- `Noise Frequency`
当成可暴露的重要参数

这说明它们对流体外观非常关键。

调参逻辑：
- Noise Strength 高：翻卷更乱
- Noise Frequency 高：细节更碎

### 8. Collision / Boundary Conditions

官方明确强调：
- 碰撞和边界条件是流体绕物的基础

调参逻辑：
- 没有正确碰撞，流体就不像在和世界交互
- 有碰撞后，水会绕物，烟会被挡和卷开

## 7. 调参时怎么思考

不要把 Niagara Fluids 当成“把每个参数都试一遍”的系统。

建议按这个顺序调：

1. 先定类型
   是 2D Gas、3D Gas、2D FLIP、Shallow Water、3D FLIP

2. 先定分辨率
   先决定预算，再决定细节

3. 再定 Source
   先让它“有形”

4. 再定大运动
   温度、浮力、主速度、碰撞

5. 最后补细节
   Noise、频率、扰动

这和做普通 Niagara 很像：
- 先骨架
- 再细节

## 8. Flow Map 在项目里的正确用途

你给的这张图非常适合拿来提醒一个核心点：

### Flow Map 最像什么

它本质上是：
- 在材质阶段扭曲 UV
- 让贴图沿某个方向或漩涡流动

### 它最适合的项目用途

- 河水表面
- 熔岩表面
- 魔法水纹
- 能量表皮
- 护盾表面流动
- 瀑布表面流动细节

### 它不适合替代什么

它不能替代：
- 真正的水体碰撞
- 真正的液体体积
- 真正的烟雾翻卷

所以我以后如果看到类似你这张图，我会优先判断：

这是：
- **材质流动方案**
而不是
- **完整流体模拟方案**

---

## 9. 当用户给我流体参考时我应该输出什么

以后你如果问我流体方案，我应该尽量明确输出：

1. 这是表面流动还是真实体积流体
2. 应该优先用：
   - Flow Map
   - Niagara Fluids
   - Flipbook
   - 组合方案
3. 如果用 Niagara Fluids：
   - 选哪种模拟器
   - 哪些参数先调
4. 如果用 Flow Map：
   - Flow Map 负责什么
   - 材质怎么接
5. 如果太贵：
   - 是否应该先模拟再烘焙

---

## 一句话原则

Flow Map 负责“表面流动的假象”，
Niagara Fluids 负责“体积流体的真实运动”，
Flipbook 负责“把重模拟变成便宜可用的最终资产”。
