# Niagara Fluids 参数调节手册

## 用途

这份文档专门用于沉淀 Niagara Fluids 常见参数的“调大 / 调小 / 视觉结果变化”。

目标不是只知道参数名，而是知道：
- 这个参数控制什么
- 调大后会看到什么
- 调小后会看到什么
- 什么时候应该动它
- 容易出现哪些误判

## 1. 使用方式

调 Niagara Fluids 时，不建议一口气乱拧所有参数。

推荐顺序：

1. 先看分辨率 / 网格
2. 再看 Source / 注入量
3. 再看大运动
4. 再看细节
5. 最后看消散和交互

简单说：

先让它“成形”，再让它“像”，最后让它“更细”。

## 2. Grid Cell Size

### 它控制什么

它本质上控制流体模拟网格的粒度。

可以理解成：
- 网格越细，细节越丰富
- 网格越粗，结果越块、越糊、越便宜

### 调大后

如果这里的“调大”指的是 **Cell Size 数值变大**：
- 质量下降
- 小细节消失
- 形体更块、更糊
- 性能更好

### 调小后

- 细节明显增加
- 小翻卷更清楚
- 边缘更自然
- GPU / 内存压力更高

### 什么时候该动它

- 流体整体形体对了，但缺少细节时
- 你发现像素化 / 方块感很强时
- 需要在质量和成本间做第一轮平衡时

### 常见误判

- 一上来就把分辨率拉很高
- 其实问题可能根本不在分辨率，而在 Source 太弱或 Temperature 不对

## 3. Pressure Iterations

### 它控制什么

它影响流体压力求解质量。

压力求解越充分：
- 体积感越稳定
- 流体越像“在推开 / 绕开”空间
- 翻卷更真实

### 调大后

- 流体更稳定
- 翻卷更自然
- 绕物体更合理
- 成本更高

### 调小后

- 结果更松
- 形体更散
- 容易显得“没聚起来”
- 成本更低

### 什么时候该动它

- 流体显得松散、软塌塌
- 绕物和卷边不够真实
- 大体方向对了，但“解算感”不够

### 常见误判

- 看到效果松，就只加 Pressure Iterations
- 其实也可能是 Density 太低、Buoyancy 太弱、Source 太小

---

## 4. Density

### 它控制什么

密度通常决定：
- 流体看起来厚不厚
- 烟看起来重不重
- 可见区域是否更明显

### 调大后

- 烟更厚
- 体积更重
- 可见性更强
- 容易糊、容易挡画面

### 调小后

- 烟更轻
- 更透明
- 更容易显得淡和薄
- 太低会像没内容

### 什么时候该动它

- 烟雾太虚、太透明时
- 烟雾太厚、太堵画面时

### 常见误判

- 看到烟不明显，就直接加 Density
- 但有时其实是光照、温度、颜色映射或 Source 分布的问题

---

## 5. Temperature

### 它控制什么

温度通常和火焰表现、高温上升、颜色映射强相关。

在火焰里，Temperature 往往决定：
- 热感
- 上升趋势
- 火焰的“活性”

### 调大后

- 上升更明显
- 更像热流
- 火焰部分更活跃
- 可能更尖、更轻、更躁

### 调小后

- 更像普通烟
- 火焰上升感减弱
- 热感不明显

### 什么时候该动它

- 火焰不像火，只像烟时
- 热流不够明显时
- 你想让火更活跃、更轻、更热时

### 常见误判

- 以为“火不亮”就只调 Temperature
- 但亮不亮也和渲染、黑体映射、Emissive 表现有关

---

## 6. Buoyancy

### 它控制什么

Buoyancy 控制上升浮力趋势。

它非常影响：
- 烟柱是否往上走
- 火焰是否有热空气上升感

### 调大后

- 更明显地向上拉
- 烟柱更竖
- 火焰更往上舔

### 调小后

- 更容易横向蔓延
- 更容易停滞
- 效果更“塌”

### 什么时候该动它

- 烟不往上走
- 火焰没有上升动力
- 你想让火把、篝火更像真实热流时

### 常见误判

- 如果上升感不够，只加 Buoyancy
- 但 Source 方向、Temperature、Dissipation 也会一起影响结果

---

## 7. Turbulence / Noise

### 它控制什么

这是决定“细节活性”和“翻卷花纹”的关键。

它通常影响：
- 扰动
- 翻卷
- 破碎感
- 流场复杂度

### 调大后

- 细节更多
- 翻卷更乱
- 结果更有活性
- 也更容易脏、乱、噪

### 调小后

- 流体更平滑
- 更容易显得假
- 缺少生命力

### 什么时候该动它

- 大运动对了，但结果太死板时
- 火焰边缘不活
- 烟雾翻卷不够丰富

### 常见误判

- 效果一无聊就疯狂加 Noise
- 结果会变成“只是更乱”，不一定更真实

---

## 8. Collision

### 它控制什么

Collision 决定流体如何和场景或碰撞体互动。

它会直接影响：
- 绕物
- 堵塞
- 冲击
- 偏转

### 调强 / 开启后

- 更像在真实绕开障碍
- 水、烟、火都更像和环境有关系
- 复杂场景里更可信

### 调弱 / 关闭后

- 流体像穿模
- 没有和世界交互的感觉
- 更适合纯视觉、不强调交互的情况

### 什么时候该动它

- 流体要绕柱子、贴地、打到地面、撞到障碍时
- 你发现特效“像在空中算自己的”

### 常见误判

- 看到流体不对，就怀疑模拟问题
- 但很多时候是碰撞体没有正确进入解算

---

## 9. Dissipation

### 它控制什么

Dissipation 控制流体衰减和消散。

它很关键，因为它决定：
- 烟会不会一直堆
- 火流是不是拖得太长
- 体积是否自然退去

### 调大后

- 消散更快
- 烟更轻、更短命
- 容易太快没掉

### 调小后

- 留存更久
- 更厚、更持久
- 容易越积越多

### 什么时候该动它

- 烟堆太满时
- 效果残留太久时
- 你想让某种流体更轻、更短促时

### 常见误判

- 看到烟太厚就只减 Density
- 实际上也可能要提高 Dissipation

---

## 10. 调参顺序建议

当效果不对时，建议按这个顺序排：

1. 先看 `Grid Cell Size`
   先确定是不是分辨率问题

2. 再看 `Source / Injection`
   先确认有没有足够输入

3. 再看 `Temperature + Buoyancy`
   决定大方向和上升感

4. 再看 `Density + Dissipation`
   决定厚薄和残留

5. 最后看 `Pressure + Noise + Collision`
   决定真实感、细节和交互

---

## 一句话原则

先让流体“成立”，
再让它“像”，
最后再让它“更细、更漂亮”。
