# 项目启动清单

## 用途

这份文档用于回答：一个新项目刚开始做 VFX 时，第一周应该先准备什么，避免后面代价很大的返工。

它不是某个效果怎么做，而是“项目一开始就该先建好的基础设施和模板”。

适合在这些场景读取：
- 新项目刚立项
- 新团队开始搭 VFX 流程
- 已有项目准备重建 VFX 基础设施

## 1. 第一周目标

第一周不是做很多漂亮效果，而是把“后面所有效果都要依赖的底层规则”先定住。

目标应该是：
- 让团队后续做任何效果，都站在同一套基础设施上

第一周优先级应该是：

1. 规则
2. 主材质
3. 预算与平台体系
4. 命名
5. 模板案例

而不是先做一堆零散技能。

---

## 2. 先定规则

第一批必须先定的规则：

- 项目总风格关键词
- 阵营差异
- 属性映射
- 常驻 / 爆发边界
- 项目是否偏写实还是风格化

建议直接参考：
- `vfx-direction-bible-template.md`
- `style-consistency-guide.md`

### 原则

如果这些规则不先定，后面项目越大，返工越大。

---

## 3. 先建主材质

不要先做很多具体材质，先做一批“主材质骨架”。

### 第一周最值得先建的主材质

- `M_FX_Additive_Core`
- `M_FX_Translucent_Smoke`
- `M_FX_Ribbon_Trail`
- `M_FX_ShieldShell`
- `M_FX_Sigil_Main`
- `M_FX_Flipbook_Base`

### 原则

先建主材质，再派生实例。

不要每做一个效果就新开一个“临时 master material”。

---

## 4. 先建命名规范

第一周就要定命名，不然后面最容易乱。

### 推荐先定

- 材质：`M_FX_*`
- 材质实例：`MI_FX_*`
- 纹理：`T_FX_*`
- Niagara System：`NS_*`
- Niagara Emitter：`NE_*`

### 参数命名

建议直接统一：
- Scalar：`S_`
- Vector：`V_`
- Texture：`T_`
- Static Switch：`SS_`

建议直接参考：
- `material-recipes.md`
- `asset-planning-checklist.md`

---

## 5. 先建 Effect Type / Scalability

这是非常容易被拖到后面、但后面代价很大的东西。

### 第一周应明确

- 是否建立统一 `Effect Type`
- 距离裁剪是否统一纳入
- Spawn Count 缩放是否统一纳入
- 平台差异是否一开始就考虑

### 原则

项目稍微有规模，就不要等几十个效果做完才开始补预算体系。

第一周先把框架搭起来。

---

## 6. 先定 User Parameters 规则

第一周就应明确：

- 哪类参数允许暴露给蓝图
- 哪类参数保留在内部
- 参数命名方式
- 默认值策略

### 推荐暴露类型

- 颜色
- 强度
- 尺寸倍率
- 生命周期倍率
- 开关类状态

### 不推荐一开始就暴露

- 每个噪声细节
- 只给特效师自己微调用的内部控制

---

## 7. 先做哪些模板案例

第一周不要追求“做很多”，而是先做几个最能代表项目基线的模板效果。

### 推荐优先做

- 命中特效
- 护盾
- 火把
- 法阵
- 一种拖尾 / Slash

如果项目偏环境特效，再补：
- 河流表面
- 瀑布

### 原则

这些模板不是为了上线，而是为了定：
- 风格
- 技术路线
- 预算边界
- 资产组织方式

---

## 8. 早期最容易漏的东西

下面这些最容易在第一周没做，后面代价很高：

- 命名规范
- 主材质骨架
- Effect Type / Scalability
- 低配版是否要存在
- 参数暴露规则
- 阵营 / 属性映射
- 场景 / 技能 / UI 的统一规则

### 一句话

这些都不是“以后再补也行”的东西。  
它们越晚定，后面返工越大。

---

## 9. 启动检查清单

- [ ] 项目总风格已定义
- [ ] 阵营差异已定义
- [ ] 属性映射已定义
- [ ] 常驻 / 爆发边界已定义
- [ ] 主材质骨架已建立
- [ ] 命名规范已建立
- [ ] Effect Type / Scalability 已接入
- [ ] User Parameters 规则已定义
- [ ] 至少 3 - 5 个模板案例已开始搭建
- [ ] 低配策略已提前考虑

---

## 一句话原则

项目启动阶段最重要的不是把第一个效果做得多漂亮，而是把后面一百个效果都要依赖的基础设施先搭稳。
