# VFX Direction Bible 模板

## 用途

这份文档用于作为项目级 VFX 方向总纲模板。

它不是某一个效果怎么做，而是定义：
- 整个项目的 VFX 风格边界
- 各阵营、属性、功能层级的统一与差异
- 技能、场景、UI 三类特效的关系

适合在这些场景读取：
- 新项目立项
- 需要建立整套 VFX 风格基准
- 需要让多个特效师或多个阶段产出的效果保持一致

## 6. 常驻 / 爆发边界

这一层定义项目里哪些效果该克制，哪些效果可以放开。

### 常驻效果

包括：
- Buff / Aura
- 武器附着
- 场景火焰
- 场景魔法装置

规则应偏：
- 克制
- 长时间不累眼
- 不挡玩法

### 爆发效果

包括：
- 命中
- 技能释放
- 爆炸
- 终极技能峰值

规则应偏：
- 短促
- 明确峰值
- 信息集中

## 7. UI / 场景 / 技能三类特效关系

这是项目里非常容易失控的一层。

### 技能特效

优先服务：
- 玩法
- 识别
- 打击感

### 场景特效

优先服务：
- 氛围
- 世界观
- 长时间稳定存在

### UI 特效

优先服务：
- 状态反馈
- 信息指引
- 不与场景和技能冲突

### 原则

这三类特效不能各自发展成三套完全不相关的风格。  
它们应该共享世界观语言，但在强度和功能上分层。

## 9. 统一检查清单

项目级检查时，至少过一遍：

- [ ] 世界观风格是否清楚
- [ ] 阵营差异是否建立
- [ ] 属性映射是否稳定
- [ ] 技能等级差异是否清楚
- [ ] 常驻 / 爆发边界是否明确
- [ ] UI / 场景 / 技能三类关系是否清楚
- [ ] 技术路线边界是否明确
- [ ] 低配规则是否明确

---

## 一句话原则

Direction Bible 的价值，不是把每个效果都写死，而是先定义底层规则，让整个项目的所有特效在同一套规则里自由变化。
