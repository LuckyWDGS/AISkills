# 参考图反推手册

## 用途

这份文档用于把“看一张图 / 一段视频，然后反推实现路径”做成更具体的判断框架。

目标不是只会拆层，而是明确：
- 看图先看什么
- 哪些现象说明是材质主导
- 哪些现象说明是 Niagara 主导
- 哪些现象说明需要 Flipbook / Flow Map / Mesh / Fluids
- 视频参考应该怎么拆关键帧
- 最后怎么给实现优先级

## 1. 看图先看什么

不要一上来就猜模块和参数。

正确顺序是：

### 第零步：先缓存参考图

如果参考图来自用户上传或聊天图片，先把它缓存到本地，例如：

```text
outputs/reference-cache/<effect-name>/design-reference.png
```

后续生成纹理、概念图、flipbook、atlas 时，都要把这个缓存图作为 reference image 传给 cm-imagegen。没有缓存图时不要只靠文字生图。

如果需要裁切局部来锚定某一层，不要把多个小裁切压进一张低清拼图后当主参考。这样会丢掉纹理、羽片、流光边缘、亮度衰减等关键证据，导致模型把层级理解错。正确做法是：

- 保留完整 `design-reference.png` 作为总体风格与结构锚点。
- 为每个效果层保存单独局部裁切。
- 如果局部裁切较小，另存一份轻锐化高清版本到 `hq-crops/`。
- 生成时优先传 `design-reference.png` + 相关高清局部单图，多图输入优先于拼图输入。
- 只有当工具不能传多图时，才退而使用 reference pack，并保证每个面板足够大。

### 第一步：看大轮廓

先问：
- 这个效果最主要的轮廓是什么
- 是圆环、壳层、火舌、拖尾、烟团、法阵图案，还是碎散点状

### 第二步：看主视觉点

先问：
- 第一眼最亮、最重、最重要的部分在哪

### 第三步：看动势

即使是静态图，也要猜：
- 它应该是向上、向外、向内、旋转、脉冲，还是停驻

### 第四步：看层级

尝试拆成：
- 主层
- 辅层
- 残留层

每一层都要记录图像证据：
- 它出现在哪个视角或编号
- 位于画面哪个区域
- 形状、亮度、颜色、材质和动势分别是什么
- 这一层对应模型材质、Niagara Mesh/Ribbon/Sprite、还是后期近似

不要只根据标注文字拆层。文字只能辅助，最终判断要回到肉眼可见的形状、重叠、亮度衰减和运动痕迹。

### 第五步：看技术暗示

最后才判断：
- 材质主导
- Niagara 主导
- Mesh / Fluids / Flipbook / Flow Map

## 2. 什么现象说明是材质主导

下面这些现象，通常强烈暗示“材质主导”：

### 1. 图案感很强

例如：
- 法阵纹样
- 六边形科技图层
- 规则光带
- 稳定能量表皮

### 2. 边缘逻辑更像贴图而不是粒子

例如：
- 清楚的边缘轮廓
- 规则对称纹样
- 稳定 Fresnel 边缘

### 3. 大形体稳定不抖

如果主体看起来是：
- 稳定壳层
- 平面发光层
- 固定图案

通常优先看材质。

### 4. 流动更像 UV 运动

例如：
- 表面流线
- 护盾表皮
- 河流表面
- 熔岩表皮

这类通常材质优先。

---

## 3. 什么现象说明是 Niagara 主导

下面这些现象通常暗示：
- 主要效果不是靠材质，而是靠粒子、生命周期和运动逻辑成立

### 1. 碎散感强

例如：
- 火星
- sparks
- 碎裂粒子
- 小量飞散 debris

### 2. 生命周期感强

如果你明显能感觉：
- 生成
- 扩张
- 消散

那通常是 Niagara 主导。

### 3. 轨迹感强

例如：
- 拖尾
- Slash
- 飞弹尾迹

这类通常靠 Niagara + Renderer 成立。

### 4. 随机变化强

如果形态明显依赖：
- 随机散射
- 随机速度
- 随机大小

那一般不是单靠材质。

---

## 4. 什么现象说明需要 Flipbook

下面这些现象通常说明：
- 单张图不够
- 需要 Flipbook / SubUV

### 1. 体积在连续变化

例如：
- 火焰翻卷
- 烟雾演化
- splash 主形体

### 2. 边缘是“活的”

不是简单噪声抖动，而是：
- 帧与帧有明显连续演化

### 3. 单张图会假

如果你一眼就知道单张图会变成：
- 橙色烟
- 一团静态雾
- 湿雾而不是水花

那通常需要 Flipbook。

---

## 5. 什么现象说明需要 Flow Map

下面这些现象通常说明：
- 重点是表面流向
- 不需要完整体积模拟

### 典型现象

- 河流表面
- 熔岩表皮
- 护盾表面流动
- 能量表面滑动

### 判断标准

如果它的动感更像：
- UV 在流
- 图案在滑
- 表面在扭曲

那么优先看 Flow Map。

---

## 6. 什么现象说明需要 Mesh

下面这些现象通常说明：
- 主形体需要几何承载

### 典型情况

- 护盾壳
- 法阵平面
- Portal 框体
- 科技结构体
- Slash 几何片

### 判断标准

如果主轮廓必须稳定、清楚、可控，
而 Sprite 很难承担时，就优先考虑 Mesh。

---

## 7. 什么现象说明需要 Fluids

下面这些现象通常说明：
- 单纯粒子和材质难以自然完成

### 典型情况

- 烟雾体积翻卷很多
- 火焰内部层次复杂
- splash 主体很真实
- 体积演化是效果的核心卖点

### 判断标准

如果最值钱的视觉特征来自：
- 真实体积变化
- 自然翻卷
- 流体感

那就要考虑：
- Niagara Fluids
- 或先模拟再烘焙

## 8. 视频参考怎么拆关键帧

视频不要直接整段看完就下结论。

推荐先拆成：

### 1. 起始帧

看：
- 起势是什么
- 第一眼主信息是什么

### 2. 峰值帧

看：
- 最亮点
- 最强轮廓
- 主次层关系

### 3. 扩张 / 演化帧

看：
- 动势来自哪里
- 哪些层在成长
- 哪些层在退

### 4. 消散帧

看：
- 残留逻辑
- 尾巴是否重要

### 原则

如果视频太复杂，至少抓 4 帧：
- 起始
- 峰值
- 中段
- 消散

---

## 9. 最后怎么排实现优先级

当你完成拆解后，不要同时做所有层。

正确优先级是：

### 第 1 优先级

- 主轮廓
- 主视觉点
- 主动势

### 第 2 优先级

- 核心材质语言
- 第二层支撑结构
- 关键时序变化

### 第 3 优先级

- sparks
- 残留
- 次级烟雾
- 小细节

### 一条非常重要的原则

如果主层还没立住，就不要先做次级粒子、残留和小炫光。

---

## 一句话原则

看参考图时，先看“它为什么成立”，再看“它由什么组成”；先抓主信息，再拆技术路线，最后才排实现优先级。
