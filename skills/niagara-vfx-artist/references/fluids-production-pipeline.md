# 流体效果生产流程

## 用途

这份文档用于把流体类特效从参考到最终资产的整条流程串起来。

适合在这些场景读取：
- 用户需要完整生产路线，而不只是技术点
- 需要判断什么时候直接材质做
- 什么时候先做流体模拟
- 什么时候烘成 Flipbook
- 什么时候进 Niagara
- 什么时候做低配版

## 1. 总体流程

推荐把流体效果的生产流程理解成：

1. 看参考
2. 判断类型
3. 选路线
4. 做主资产
5. 接进 Niagara
6. 做低配和交付版本

不要一上来就开始调 Niagara Fluids。

因为很多时候真正正确的答案是：
- 直接材质做
- 或先模拟再烘焙
- 而不是把所有流体都当实时体积解算来做

---

## 2. 第一步：读参考

先回答几个核心问题：

### 这是哪一类流体

- 表面流动
- 烟流
- 火流
- 水花喷溅
- 瀑布 / 大水流
- 熔岩 / 黏稠流体

### 它最重要的视觉信息是什么

例如：
- 水流方向感
- 烟雾体积感
- 火焰翻卷感
- 冲击 splash
- 表面黏稠流动

### 它是实时持续存在还是一次性镜头

- 持续环境效果
- 技能瞬发
- 英雄镜头
- 宣传镜头

### 它是否必须和场景发生真实交互

这会直接决定：
- 材质是否够用
- 是否必须上 Niagara Fluids

---

## 3. 第二步：做技术路线选择

根据参考和目标，把路线分成四类：

### 路线 A：直接材质做

适合：
- 水流表面
- 熔岩表面
- 护盾表面流动
- 能量纹理流动

关键词：
- Flow Map
- UV 扭曲
- Panner
- Normal / Foam / Emissive

### 路线 B：先做流体模拟

适合：
- 火流
- 烟流
- 英雄 splash
- 近景体积效果

关键词：
- Niagara Fluids
- 2D Gas
- 3D Gas
- 2D FLIP
- 3D FLIP

### 路线 C：先模拟再烘焙

适合：
- 高质量流体外观，但正式版本不想实时跑太贵

关键词：
- Bake to Flipbook
- Sprite playback

### 路线 D：混合路线

适合：
- 瀑布
- 熔岩边缘
- 英雄水体

典型结构：
- 主体材质 / mesh
- 次级层 Niagara
- 白水 / 烟 / 火星 / mist 用 flipbook

---

## 4. 第三步：决定是否直接材质做

当出现下面这些特征时，优先考虑直接材质做：

- 最重要的是流向，不是体积
- 主要看的是表面
- 不要求真实碰撞和体积断裂
- 要长期放场景里
- 成本必须可控

### 典型例子

- 河流表面
- 水渠
- 熔岩河
- 魔法表面流动

### 常见做法

1. 准备 mesh
2. 做 UV 规划
3. 加 Flow Map
4. 加 Normal / Foam / Emissive
5. 再考虑要不要 Niagara 二级层

---

## 5. 第四步：决定是否先做流体模拟

当出现下面这些特征时，优先考虑先做流体模拟：

- 需要翻卷感
- 需要体积感
- 需要气体或液体“自然演化”
- 需要真实冲击 / 扩散 / 上升

### 典型例子

- 火把火焰
- 英雄烟柱
- 近景爆炸烟
- 高质量 splash

### 这里的关键原则

不是一上来就决定“最后游戏里实时跑它”，
而是先决定：

**这个外观值不值得先用流体模拟求出来。**

---

## 6. 第五步：决定是否烘成 Flipbook

这一步是生产里最重要的“成本闸门”。

### 适合烘焙的情况

- 实时模拟太贵
- 效果需要大量重复出现
- 效果已经足够稳定，不需要强交互
- 想保留高质量形态，但降低运行成本

### 典型例子

- 火流
- 烟流
- 水花 splash
- 爆炸云团

### 烘焙后的典型路径

1. 用 Fluids 模拟高质量结果
2. 用 Flipbook Baker 烘焙
3. 输出 spritesheet
4. 进入 Niagara Sprite Renderer
5. 用 `SubUV Animation` 播放

### 社区成熟经验

大量成熟项目都会在这里做妥协：

- 英雄级 look 来自流体模拟
- 量产版运行来自 flipbook

---

## 7. 第六步：进入 Niagara

当主资产确定后，再决定 Niagara 怎么承担职责。

### Niagara 最适合做什么

- 播放 flipbook
- 管理粒子生命周期
- 做二级粒子
- 做补充层
- 管理 timing
- 管理平台分版本

### Niagara 不一定要承担什么

- 不一定亲自实时算出所有复杂流体

很多时候，Niagara 在生产中的真正价值是：
- 组织
- 播放
- 组合
- 扩展

### 典型进入方式

#### Flipbook 进入 Niagara

- Sprite Renderer
- 设置 `Sub Image Size`
- 使用 `SubUV Animation`

#### 材质流动进入 Niagara

- 材质本身做主流动
- Niagara 补白沫 / 火星 / 烟雾 / 残留

---

## 8. 第七步：做低配版

低配版不要等到最后爆了才想。

当主方案确定后，就应该立刻问：

- 哪些层是核心识别层
- 哪些层是奢侈层
- 哪些层在移动端可以删

### 常见低配策略

#### 材质层

- 减少采样
- 减少 Flow Map 复杂度
- 减少折射

#### Flipbook 层

- 降低分辨率
- 减少帧数
- 减少同屏数量

#### Niagara 层

- 减少 Emitter
- 减少 Spawn
- 缩短 Lifetime

### 一条很实用的原则

**低配版不是“整体都弱一点”，而是“保留核心层，删掉奢侈层”。**

---

## 9. 推荐交付顺序

推荐的完整交付顺序：

1. 先给参考拆解
2. 再给技术路线判断
3. 再决定主资产来源
4. 再决定是否模拟
5. 再决定是否烘焙
6. 再决定 Niagara 组织方式
7. 最后明确低配路线

---

## 一句话原则

流体生产不是“先开模拟器”，
而是“先做路线判断，再决定哪些部分值得模拟，哪些部分应该烘焙，哪些部分交给 Niagara 组织和播放”。
