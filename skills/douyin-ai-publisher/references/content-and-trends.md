# 内容、热点与复盘

## 长期栏目

当前只以稳定经营账号、积累持续观看的粉丝为目标。下述选题/配比/时段是编辑建议，不是平台算法或已证热门；不默认准备定制单、商业样片或报价。

AI不能单独解释关注理由。先定义观众承诺，如“给疲惫的人建可住进去的童话空间”。作品、图册、制作解析围绕同一承诺，不随机混入财经数字人、明星变脸、工具新闻。已有星座内容可做治愈空间主线、同世界图文、同作品真实问题→修改→结果解析；奶油绘本风格只适用于既有系列及用户明确同方向作品。

主平台与同步平台由用户当前决定记录在运营档案。用户选抖音为主、发布后同步B站时，以抖音反馈主导下一条；同步同一成片前分别核音乐跨平台使用权、标题简介、封面/画幅、分区与AI声明，并查B站既有记录防重。不能把抖音发布表单的跨平台勾选当B站投稿成功，也不因同步自行拉长、重生或统一两平台指标；最终提交仍遵守各自当前分工，不建立无人值守定时发布。

验证停留、收藏、关注与追更的理由：首眼向往/有趣结果、值得再看/保存、知道下一期还有什么、自己的偏好得到后续回应。塑料材质、虚假动态、乱码、机械旁白和重复模板可能损害信任，不能只靠标签修复。制作解析仅在能服务同一观众时少量加入，不为展示接单能力挤占主线。

## 运营档案、待发队列与质量诊断

MyJuBen本地档案为`.codex/session/douyin-publisher/operations.json`；已确认目标优先，栏目/昵称/简介候选不能自动成为用户已选事实。真实账号仍现场核验。队列`content_queue.csv`记录本次选定素材、栏目、媒体/声音/权利核验、待补项与稿件路径；unknown不能标ready，planned不是平台发布状态。不能从整个私密目录补素材。

主页承接准备代表作、认识账号、系列入口三类置顶稿；优先已完成作品，不为填满三条置顶凑更或重发。封面保留一致小系列标记，主文案突出本条真实看点。记录视频/图文的具体问题：最强停留点（画面/声音）→最大流失点→关注理由→优先改动；可以建议修改，不能擅自剪辑或独立生成视频。

评论按喜欢的细节、想看的空间、没看懂的问题归类到`audience_requests.csv`。只取真实留言，匿名记录，不复制无必要的个人信息；合理建议成为备选，制作完成后才能说已采纳。可写回复草稿，发送回复需具体授权。

## 证据分层

研究记录`observed_at / timezone / platform / region / source_url或页面 / source_date / window / exact_label / value / scope`。

- 平台实测：后台指标注明登录可见，公开指标注明公开；等待加载完成。
- 公开案例：原作品/可靠报道与当时截点；报价和商单不等于到账/利润。
- 趋势线索：旧文章/缓存，不能放“今天热榜”。
- 编辑判断：选题、评分、时段；不能称推荐机制。
- 用户决定：本次确认内容，和建议分开。

对标至少保留作品链接、栏目承诺、封面/开场、内容如何兑现、追更原因、已知商业证据/未知部分。学结构，不搬素材、声音、造型、标题或逐帧复刻。

## 当次热点

优先登录创作者平台→当前公开榜/话题页→可靠原始报道：

- https://creator.douyin.com/creator-micro/home
- https://www.douyin.com/hot
- https://trendinsight.oceanengine.com/

猜你喜欢是个性推荐；热门话题的播放量不是当天新增；热点榜单热度不是播放量；活动卡片不是资格证明。不可混算，加载中的0/暂无/空卡不能当最终数据。

抖音指数查询保留平台、地区、词语原文、统计周期，以及搜索指数/综合指数/热点指数的原字段。对比词只在相同窗口与口径内比较；指数均值不等于搜索人数、视频播放或该话题能分到的流量。平台提示暂不支持查询的词记unavailable，不填0。创作指南的垂类消费分析只代表该类目与所选周/月，不能把邻近类目时长结论当本账号最佳时长。趋势报告分清标题年份、实际发布日期、摘要与已读正文范围；旧报告可支持创作方法，不能充当当日热度。

候选核词义、实际作品关联；活动核时限/体裁/入口/组件。填话题时有平台候选就选对应词条，敲井号不等于报名活动。即时新闻/短期活动每次提交前再查；普通热点默认24小时内重新查，日期变化重查，这是内部保鲜规则。榜读不到写实时热点未核验，继续用相关常青词。

内部编辑评分：素材匹配0–40、受众0–20、热点意图兑现0–20、证据新鲜0–10、原创空间0–10。素材匹配低于20弃用；总分70以上可用、50–69备选、低于50弃用。侵权、误导、消费灾难或无关联直接排除，热度不抵消。这不是抖音算法权重。

常用3–5个实质相关词：制作类别＋题材＋系列/情境＋零到一个匹配热点；非官方最优数。`#AI创作 #治愈系 #十二星座庇护所`只是常青示例，按真实作品选，不标已验证热门。

每个候选词写一条“实际兑现证据”：对应哪个可见物件/情境或已听声音、覆盖全片还是一个局部、期望吸引谁。ASMR需以已听审的声音细节为主要价值，白噪音、配乐与环境声不能互相替代；仅有雨窗画面不能承诺听雨。商品/手工/品牌词会吸引相应意图的观众，未实际展示该内容就弃用。填写时从平台候选选择正确词条；复盘同时保存平台实际文案，用户最后审核可能改变已准备的话题，不覆盖旧包或猜测由谁修改。

可以借有内容依据的生活/季节语境；实际有麻糍糖葫芦的新作品才考虑该词，不能给没有食物的海底空间挂上。金价、体育、无关明星事件不因热就进入造梦作品。

## 包装分支

标题说具体情境/选择/结果；工具名在制作解析中才是价值中心。没有步骤不能写完整教程，AI概念图不能写真实房源/实拍。正文一句观看理由＋一两项可见细节＋可选自然讨论，不每条机械提问，不关注交换/点赞转运/虚假福利。下一期承诺需可兑现。

视频：封面取实际质量好的帧，字少可读、避开当前UI遮挡。首两秒吸引力由画面核验，不能靠文案补空片头。剪辑修正与发布包装分别记录。

声音作为观看承诺时，发布包增加`audio_promise`与证据：主动作声/环境/BGM/独白各做什么、关键结果在哪个区间兑现、听审状态和音乐权利。标题承诺“听雨/沉浸式/ASMR”前核是否真正可听且未被音乐或独白遮住；没有直接听审就保持pending，不从ASR、峰值或音乐署名推听感。具体研究与制作交douyin-ai-creator-lab，不能因发布包装擅自重混或生成。

图片：首图独立向往，后图新增差异/细节；A/B/C视觉可辨且正文顺序对应，不凑近乎重复图。不把AI推测反向角度称摄影事实。标题文字实际排版并验字。

无素材：明确要求生成时制作同系列3–6张或合理数量，完成验图后才可发布。不拿别人片截帧充AI原创，不调用视频生成。规划请求可先给制作计划。

口播：用自己实际做过的“为何小屋不治愈”“怎样改掉塑料感”等问题，展示前后与理由。原创数字人/真人都服务信息，字幕据真实声音核对，声音克隆另核授权。

## 复盘

记录状态、发布时间及平台时区、内容柱、时长/图数、首图/开头、文案版本、话题/活动、已知投放。24h/72h/7d对齐作品年龄，不能把2小时和2个月累计量直接比。

视频看2秒跳出、5秒留存、平均观看/完播；图文看划走、平均浏览图数/收藏；共同看分享、作品归因关注、主页访问与具体系列反馈。只用后台实际开放指标；缺失为null/未知，私密`-`不是0。

记录账号总览、单片累计、实时与每日更新的各自截止时间；截止日前未发布的作品不能解释该窗口的净增。页面未显示发布时间时区时保存原文，作品年龄未知，不强算同龄。不同模块的播放、完播、跳出或来源占比可能使用不同分母/更新时间，保留原值，不用一个模块的播放反推另一个模块的人数。来源表未出现某入口不等于该入口流量为0。图表开放门槛只说明数据可见条件，不是流量池规则；同类作者百分位也不能代替观众留存和涨粉判断。

用户手动发布后，实际后台可能已从本地`staged/under_review`变成`published`。按匹配的账号、作品ID、标题/素材和当前页面追加只读观察，保留原准备包与历史，不补造Codex的授权、提交或审核中步骤。helper不支持直接记录这种观察时，可另存核验并明确修正本地状态；不要为满足状态机再次点发布。

点赞率=点赞/播放，分享率=分享/播放，关注转化=**作品吸粉量**/播放，分母0不算；账户粉丝净增不能归因一条作品，总获赞也不是当前公开赞之和。粉丝指数≠总粉丝量。

以同栏目、相似时长、同龄作品中位数为自己的基线，少样本标探索。无固定200/500流量池、万能30%完播或黄金时段。可测试北京时间午间/晚间，须核平台排期时区，用户“今晚”按其时区解释。

每批一个主要变量，给一个保留点和具体改动；同时换画面/标签/时间不能归因标签。无投稿的极小数据不能推限流；先查审核、权限、开头和兑现，不默认删除隐藏/换号/刷视频养号/付费诊断。

MyJuBen用本地`metrics_snapshots.csv`按作品ID追加观察时间、作品年龄、指标原名/单位/值/分母/来源；不可得写空值并注明原因。`experiments.csv`记录主要变量、假设、可比基线、观察结果、保留点和下一条改动，历史累计六条不冒充24h基线。账户净增粉与作品吸粉分开；平台不提供回访指标就不编造，用真实追更反馈作为辅助定性证据。

用户以后明确提出商业目标才另记有效咨询、成交及交付成本；当前没有粉丝数硬门槛或自动转商业日期。不擅自建立定时监控。
