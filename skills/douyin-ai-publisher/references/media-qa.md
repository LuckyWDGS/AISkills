# 成片检查

发布前对每个素材运行一次 `scripts/inspect_media.py`，再结合人工查看做判断。目的是在上传前发现会明显影响观看的问题，让用户决定改还是照发。

```powershell
python -X utf8 <skill>/scripts/inspect_media.py --out-dir <发布目录>/qa <成片.mp4>
```

输出到 `--out-dir`：

| 文件 | 内容 |
| --- | --- |
| `media_report.json` | 参数、hash、响度、黑场、静音、各项检查结论 |
| `<名>_sheet.png` | 关键帧联系表：0s、0.5s、1s、2s、中段、结尾 |
| `<名>_feed.png` | 推荐流预览：把成片放进 1080×1920 手机画面，并标出界面遮挡区 |
| `<名>_cover_<秒>_3x4.png` / `_4x3.png` | 竖、横封面候选（居中裁切） |

脚本只做客观测量。**画面好不好看、开头抓不抓人、声音好不好听，仍需执行者看图、用户听审来判断。**

## 结论等级

- `block`：技术上无法发布，如文件读不出、没有视频流。必须先解决。
- `warn`：会明显影响观看效果。把问题和建议告诉用户，由用户决定修改还是照发；用户选择照发时在发布包记下“已知问题：……，用户决定照发”。
- `info`：参考信息，不需要处理。

执行者不因警告擅自转码、放大、裁切或重剪。

## 检查项与参考值

下面的阈值是编辑经验值，**不是平台规则**；平台的硬限制以 [ui-notes.md](ui-notes.md) 和现场界面为准。

### 画幅与分辨率

| 项目 | 参考 | 说明 |
| --- | --- | --- |
| 画幅 | 9:16 竖屏为佳 | 横屏在推荐流里只占屏幕中间一条（16:9 约占高度的 32%），主体和文字会很小。看 `_feed.png` 判断 |
| 分辨率 | 短边 ≥ 1080 | 720 给 `warn`；不为凑数放大 |
| 帧率 | ≥ 24fps | |
| 编码 | mp4 + H.264/HEVC + AAC | 其他编码给 `warn`，上传后以平台预览为准 |

### 开头 2 秒

- 脚本检测开头 3 秒内的黑场；从 0 秒开始超过 0.5 秒的黑场给 `warn`。
- 执行者看联系表的前 4 帧：**主体（人物、角色、核心物件）在 1 秒内是否出现、是否够大**。只有空镜、加载动画、黑底小字的开头，告诉用户可能导致快速划走。

### 界面遮挡区（推荐流）

`_feed.png` 上半透明红色区域是常见的遮挡位置，是经验估计，以实际预览为准：

- 顶部约 7%：状态栏和顶部标签。
- 底部约 24%：账号名、标题文案、音乐条。
- 右侧约 14% 宽、40%–76% 高：点赞、评论、收藏、分享按钮。

字幕、关键文字和主体脸部尽量不落在这些区域。

### 文字可读性

竖屏 1080 宽时，字幕字高建议不低于约 48 像素；横屏视频在推荐流里会缩到约 56%，原片字幕需要相应更大。执行者在 `_feed.png` 上目测：手机上看不清的文字，不能作为剧情关键。

### 声音

| 项目 | 参考 | 说明 |
| --- | --- | --- |
| 整体响度 | 约 -14 LUFS（-16 ～ -10 都可接受） | 低于 -20 太小声，高于 -9 偏吵，给 `warn` |
| 真峰值 | ≤ -1 dBTP | 超过可能在平台转码后失真 |
| 静音 | 单段 ≥ 3 秒列出；静音合计超过时长 30% 给 `warn` | 刻意留白的作品可照发 |
| 音轨 | 有音轨 | 无音轨给 `warn`，确认是否有意 |

**客观指标不能代替人工听审。** 标题或话题承诺了声音体验（ASMR、听雨、BGM 好听等）时，必须有人实际听过，见[包装](content-and-trends.md#包装)。执行者无法播放声音时，发布包写“声音未人工听审”。

### 图片（图文）

- 格式 jpg / jpeg / png / webp；gif 给 `warn`。
- 单张大小、张数上限和推荐比例见 [ui-notes.md](ui-notes.md#图文上传限制)。
- 逐张人工查看：主体、文字是否乱码、是否几乎重复、裁切是否切到主体。

## 写进发布包

`prefill_release.py draft` 会把报告中的检查结论写入 `release.json` 的 `media_qa`。执行者补充：

- 人工查看的结论（开头、主体大小、文字可读性）。
- 每条 `warn` 的处理方式：已修改 / 用户决定照发 / 不适用。
- 声音听审状态。
