# 新增配方

只有用户要求收录时才将临时生成方案写进库。按索引选分类和未使用 ID，在 `references/recipes/` 新建一个 Markdown 文件，再给索引新增一行；主文件保持不变。

每个配方包含：ID/版本/分类/标签；用户意图与来源说明；逐参考可见要素与不确定项；参考角色；继承清单；新面部结构设计；一份完整正向提示词；可调参数与互斥变体；画幅/裁切选项；质量检查点。按 `parameters.yaml` 记录实际生成，记录实例存入项目而不是技能包。

文本应是从参考推导的版本，不声称获得原始提示词。新增主题不要求沿用军装、运动场或同一位主角。参考和输出的再分发权未明确时，包内只存文字，不带下载图片或私人资产索引。

验证：运行当前 skill-creator 的 `quick_validate.py`；检查索引及相对链接可解析、YAML 可加载、`allow_implicit_invocation` 仍为 false、技能中无本机绝对路径/密钥/私人图片。若用户要求示例，实际加载该配方生成并检查，把失败和限制写入本次记录，不把偶发故障推广为所有平台的永久规则。
