# 样例：无人环境片15秒（豆包Seedance 2.x，带旁白）

演示：观众获得什么、空间地图、一次计划内切镜、一种运镜加终止构图、自然过程有来源、旁白与世界声和配乐分层、尾段声音不淡没。

## 输入

> 暴雨夜悬崖石屋，进门就有人替你生好了火。15秒，绘本风，无人无动物，要中文女声旁白，雨声和BGM结尾不要停。已有石屋外景和室内两张已采用单视图。

## 代码块外：参考计划

```yaml
platform: seedance
seedance_version: 2.x（界面可见；旁白能力按版本表）
generation_mode: multimodal_reference
units:
  - {range: 0–5秒, dominant_spatial_anchor: ENV-cliffhouse-ext}
  - {range: 5–15秒, dominant_spatial_anchor: ENV-cliffhouse-int, note: 计划内硬切，不要求穿门连续}
minimum_reference_set:
  - {id: ENV-cliffhouse-int, role: 室内空间, keep: 门/壁炉/扶手椅/小桌相对位置、绘本笔触, exclude: 后加文字标签}
geometry_status: single_view_only（未验证屋内反向视角，镜头不转向门）
audio_plan: 旁白原生生成；雨声与柴火声为世界声；轻木吉他为观众侧配乐，尾段继续
```

## 复制正文

<!-- lint platform=seedance type=environment duration=15 expect=pass -->
```text
暖色手绘绘本风，柔和的水彩质感，低饱和的米白与琥珀色；画面内没有任何人物和动物，也没有口型。

时间与地点：暴雨夜，海边悬崖上一座小石屋；屋外是深蓝色的雨夜，屋内只有壁炉和一盏油灯照明。
本段观众获得：从风雨里进到一个已经准备好的、可以坐下的位置。
空间地图：石屋木门在画面中央偏左；进门后右侧是壁炉，壁炉前一张旧扶手椅朝向炉火，椅边小木桌上放着一杯冒热气的茶和一条叠好的毯子；窗户在左墙，窗外是雨。门、壁炉、扶手椅三者的相对位置全程不变。

0.0–5.0秒：固定远景，从屋外正面看石屋，雨线斜落在屋顶和门前石阶上，窗户里透出暖光；镜头不动，只有雨和窗内火光在变化。
5.0秒：计划内硬切进屋内。
5.0–11.0秒：屋内中景，镜头位于门边，朝向壁炉；壁炉火苗缓慢跳动，茶杯上的热汽持续向上散开。镜头沿水平方向小幅缓慢向右平移，直到扶手椅和小木桌占据画面右侧三分之二后停住。
11.0–15.0秒稳定尾帧：保持扶手椅、小木桌和壁炉的构图不变，镜头完全静止；火苗、茶汽和窗外的雨继续自然变化，不新增物体、不换场。

旁白：全程温柔、放松的中文女声旁白，画面内没有任何人物和口型。
0–5秒，旁白：「雨下了一整夜。」
5–11秒，旁白：「有人替你把火生好了。」
11–15秒不再新增旁白，只留雨声和柴火声。
声音：屋外段以雨声和风声为主；进屋后雨声变远变闷，柴火噼啪声和茶杯边轻微的热汽声靠近；观众侧配乐是很轻的木吉他，画面内听不见，音量低于旁白，尾段继续，不淡出。
画面连续性约束：全程无人、无动物、无手部；门、窗、壁炉、扶手椅的数量和位置不变；室内地面和扶手椅保持干燥，雨只在窗外和屋外；画面无文字、无水印。
```

## 反例

<!-- lint platform=seedance type=environment duration=15 expect=fail:timecode -->
```text
画面内角色：
- 小女孩：在屋里看书。
0–3秒：镜头缓缓推进到门口。3–6秒：镜头缓缓推进到窗边。6–9秒：镜头缓缓推进到壁炉。9–12秒：镜头缓缓推进到椅子。
小女孩说：“这里真温暖。”加一段旁白。
```

问题：为套人物模板补了小女孩和画内对白；四段都“缓缓推进”，像重复参观；没有写观众获得什么和空间关系；旁白没有归属、语言和“无人物无口型”；只到12秒，没有稳定尾段；雨、火、茶汽这些有来源的自然变化一个都没有。
