# 样例：人物戏15秒（豆包Seedance，标准档）

演示：唯一目标、空间地图、对白回路（开口 → 听者消化 → 回应 → 关系变化）、一次手部插入、稳定尾帧。场景与人物都是示范用的虚构设定。

## 输入

> 母亲坐一小时公交给出租屋里的女儿送汤，女儿嘴上嫌她多事，最后还是接了。15秒，豆包Seedance，有两人身份图和一张楼道门口图。

剧本层先过门：

```yaml
trigger_evidence: 母亲记得女儿上周电话里随口说想喝排骨汤
private_judgment: 女儿觉得母亲跑这么远很辛苦，自己却帮不上，心里愧疚
subtext: “不用跑这一趟”下面是心疼，不是嫌弃
spoken_intent: 女儿想让母亲以后别再折腾
listener_processing: 母亲听出语气冲，笑容僵一下，但没收回保温桶
emotional_delta: 女儿伸手接过，嘴硬没有升级成争吵，两人都松下来
```

## 复制正文

<!-- lint platform=seedance type=character duration=15 expect=pass -->
```text
画面内角色：
- 母亲：约55岁中国女性，齐耳短发微卷，深红色针织开衫、黑色长裤，双手提一个旧的不锈钢保温桶；本段先开口，发起交流。
- 林晓：约27岁中国女性，黑色长发随意扎起，浅灰色家居卫衣，左手扶着半开的房门；本段先防御，后接过保温桶。
画外声音或对象：无。
不出场人物：林晓的室友、邻居、快递员和任何路人；楼道里没有其他人出现或发声。

时间与地点：冬天工作日晚上八点，老式居民楼四层出租屋门口，楼道顶灯是偏暖的白光，门内透出客厅的冷白光。
本段唯一剧情目标：林晓嘴上嫌母亲多事，最后还是接过保温桶；本段不进入屋内，不谈其他家事。
空间地图：房门在画面右侧、向内开，门框是固定参照；母亲站在门外楼道、画面左侧，面向画面右侧的林晓；林晓站在门内、画面右侧，身体半挡在门缝里，面向母亲；两人相距约一臂；镜头位于楼道一侧，与两人连线平行，全程不越轴。保温桶只有一个，起初在母亲双手中。
全局保持：两人外观、服装、站位、楼道灯光和保温桶唯一性全程不变；画面只有这两个人。

0.0–4.0秒：
镜头：固定中景，侧面平视，两人上半身和门框同时在画面内。
动作：母亲把保温桶往前递到两人中间，停在胸口高度；林晓的手仍扶着门，没有伸手。
对白：母亲看着林晓的脸，用带点讨好的普通话说：“你上回说想喝排骨汤，我就炖了点。”林晓闭嘴听着，视线落到保温桶上。

4.0–8.0秒：
镜头：保持固定中景。
动作：林晓把视线从保温桶移回母亲脸上，吸了一口气，扶门的手指收紧。
对白：林晓面对母亲，声音压低、语气有点冲：“我都说了不用跑这一趟，这么远。”母亲没有收回保温桶，嘴角先僵了一下，又笑着点头。

8.0–11.5秒：
镜头：在8.0秒做一次计划内硬切，切到两人之间的手部近景：画面左侧是母亲的双手和保温桶，右侧是林晓的右手；门框边缘留在画面右侧作参照。
动作：林晓的右手从门边松开，伸过来握住保温桶提手；两人的手同时在提手上停了一下，母亲随后松开双手，保温桶完全落到林晓手中并保持不动。

11.5–13.5秒：
镜头：在11.5秒硬切回第一镜相同的固定中景，站位不变。
动作：林晓把保温桶拿在身前，低头看了一眼，没有再说话；母亲双手空着垂在身侧，肩膀放松下来。

13.5–15.0秒稳定尾帧：
保持同一中景，两人站位、保温桶位置和灯光都不变；只有自然呼吸，林晓的视线停在保温桶上，母亲看着林晓。不新增对白、动作、人物或运镜。

声音与对白：只有上面两句普通话对白，母亲先说、林晓后说，口型同步，不重叠；其余时间只有楼道底噪、保温桶提手的轻响和衣料声。
画面连续性约束：画面始终只有母亲和林晓两人；保温桶只有一个；楼道和门上没有可读文字、门牌或广告；不越轴、不换场、不进入屋内；避免运动模糊、重影、手指畸形和面部变形。
```

```text
@图1是妈妈，@图2是女儿。承接上一段，妈妈来送汤。
妈妈（S1）说：<d>[Chinese] 你上回说想喝排骨汤。</d> 她看着对方，对方不说话，她又往那里走，她把汤给她。
0–5秒：电影感、高级感、氛围感拉满，镜头缓缓推进。
5–12秒：女儿接过汤，转身进屋，镜头环绕，然后切到厨房她打开盖子。
```

问题：上传编号和“承接上一段”进了复制区；Seedance稿混入H3的`(S1)`和`<d>`；没有角色清单，“她/对方”指代不清；只写到12秒，没有稳定尾帧；一个段落塞了进屋、换厨房、开盖三件事和环绕运镜；女儿只有动作，没有回应，关系没有变化。
