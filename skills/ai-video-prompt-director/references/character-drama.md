# 人物戏写作

适用于有可见人物、对白、关系或动作交互的段落。无人环境片读[环境片参考](environment-pilot-and-review.md)，不为套本页模板补造人物、嘴型或关系戏。本页以15秒单段为例；其他时长按同样字段等比展开，时长默认值见[项目偏好](project-preferences.md)。

## 一、先过剧本层，再写镜头

本Skill只在故事、人物和导演选择已经成立后负责编译。不能用“电影感、真实、治愈、情绪拉满”补编剧缺口。

- 先写人物当下知道什么、想让谁做什么、害怕承认什么，以及这次交流或行动让关系改变了什么。
- 对白要有具体对象、当场目的、潜台词和听者处理；随机眨眼、点头、走路和看手机不能冒充表演。
- 视觉细节来自人物处境、地点使用痕迹、时间、地域或动作；每个镜头只保留一个真正需要观众看见的重点。
- **去掉镜头术语测试**：只剩台词、停顿和反应时，人物不像彼此认识或互相影响，就回剧本层重写，不继续加提示词。
- 连续段落不要无意识复用“同一机位、同一左右站位、同一环境声、轮流说话”；下一段要有注意力、行为或关系上的真实变化。
- 尾帧优先停在有余味的具体状态：未松开的手、没有收回的目光、被打断的动作、已改变归属的道具；不总是“呼吸、眨眼、冻结”。

### 因果与认知门

任何动作、质问、决定或情绪爆发进入时间码前，先写通这条链：

```text
触发证据 → 人物实际知道什么 → 当前具体目的 → 采取什么行动 → 期待谁/什么回应 → 失败后产生什么结果
```

- 人物不能根据尚未看见、听见、被告知或合理推断的事实行动。缺证据或认知标`causal_motivation_gap`。
- 台词服务人物当下目的，不替编剧解释剧情。像剧情摘要、无来由发问或没有实际诉求时标`human_dialogue_logic`并重写。
- 情绪强度由可见失败累积触发：证据出现、尝试沟通、无人回应、结果恶化，随后才提高音量或爆发。不先安排愤怒再倒推理由。
- 画外对象可以承担已确认的因果，但要通过视线、手势、已知前段事实或画内台词让观众读懂，不能只写在导演说明里。

例：人物不能一到停车区就喊“谁的三轮车”。完整链是：看见自己的车被剐蹭 → 已从监控确认是眼前三轮车 → 想找车主协商 → 先看受损车、再看三轮车 → 朝能听见的区域说明原因并找车主 → 无人回应后再下一步。车与三轮车同画面会融合时，车可作画外因果对象，但“撞了我的车”“出来处理”不能从台词里删掉。

### 人味与情绪颗粒度门

普通双人生活戏、关系戏和共同决策戏，再填：

```yaml
thought_trigger: 此刻让人物心里动一下的具体人、话、声音或物
private_judgment: 人物实际怎么理解这件事；尚未说出口的判断
subtext: 这句话下面真正担心、试探、体谅、嘴硬或期待的是什么
spoken_intent: 人物现在开口想让对方知道、回答或做什么
listener_processing: 听者先听见什么，停顿/视线/呼吸如何变化，再怎样回应
embodied_detail: 与思考绑定的一个身体或道具动作，不是随机动画
emotional_delta: 交流后人物或关系比开口前改变了什么
```

- 优先形成一次完整交流回路：A有触发地开口 → B有可见消化 → B回应、追问或有意义地沉默 → 关系产生一个变化。只有“一句说明＋对方机械点头”标`dialogue_underwritten`。
- 听者不是背景：台词之间留出视线回到说话人、吸气没立即回答、手停住又收回等处理过程。没有时标`listener_reaction_missing`。
- 微动作由思考驱动：犹豫才停手，试探才观察，松下来才呼气，嘴硬才避开视线。删掉后不影响思考、关系或信息的动作就是动画填充，删掉。
- 沉默要写明为什么不说、听见了什么、沉默后关系怎样变。没有原因和结果标`human_presence_missing`。
- 15秒生活对话常可容纳2–4句短自然话，这是预算参考不是配额；纯动作、危险、驾驶、哭泣或已说清目的的镜头可以少说。
- 本应当场说出口的情绪不偷换成内心独白。

不合格：伴侣说“去大同吧”，程序员点头，两人转身。
合格：伴侣先看被挡住的路线，压住失望后试探“那要不换个地方？”；程序员听出她不是在责怪自己，肩膀松一点，明确回应；伴侣确认后才转身。

## 二、复制正文的固定开头

复制区从三组清单开始（例外：H3全参考原生稿从`subject_definitions`开始，见H3适配器）：

```text
画面内角色：
- 程序员：约28岁中国男性……；本段动作/对白职责……
- 普通同事：成年中国男性……；本段动作/对白职责……
画外声音或对象：家人，只通过已接通电话声音出现，不露脸。
不出场人物：老板、女性HR、其他同事、客户、伴侣和清晰路人。
```

- 只列本段真正需要看到、听到或作为明确行为对象的人物；画外声音不写成画面角色。
- 两个及以上可见角色一人一行（`- 角色名：身份与本段职责`），这一行就是人工核对人数、绑定参考图的最小单元。
- 每个画面人物给稳定身份、年龄段、外形、服装和本段职责；不在同一提示词里用“他、她、对方”替代角色名。
- 写明谁发起动作、谁接收、谁在听、谁不说话；多人只保留剧情必须的人数。
- 不出场人物写明不出现、不发声，防止模型补入老板、家人、伴侣、清晰路人或拥挤人群。

## 三、15秒写作流程

### 0. 主交付与失败降级

用户要“一个15秒视频”时，复制正文本身连续覆盖`0.0–15.0秒`。`SHOT/UNIT/BRIDGE`是规划和风险审计层，不是默认生成任务数；不能把`0.0–2.8秒`等内部片段分别交成主提示词。只有完整版本因口型、人数、物体融合或模型能力有明确风险时，才在代码块外另给`fallback_split`，写清成片时间、职责和剪辑端点。

用户委托制作影片时，可一开始按空间变化、平台上限或剪辑意图规划多个UNIT，不必先浪费一次整片生成。

### 1. 时空和唯一目标

角色清单后，一两句建立时间、地点、光线和本段唯一目标，例如“月底最后一个工作日下班后，程序员站在公司玻璃门外，拿出手机但尚未拨通；本段不进入家庭电话”。不写“承接上一帧”“接上一段”“第三集第四段”等管理语句。只有用户提供真实首帧且要求严格承接时，才把首帧事实写成当前画面外观。

### 2. 全局锁定

只锁本段需要的：人物外形与服装、临时配角在本段是画内/画外/不出现、具体场景（不用“某处”）、道具由谁持有/从哪拿出/何时交接/最后停哪。无品牌物品不出现Logo、价格、订单号、二维码或可读文字。跨镜头保持脸型、发型、身形、核心服装、道具状态、光线方向和色调。

### 3. 按时间码逐块写

```text
时间码：0.0–3.0秒
镜头：景别、机位、角度、构图、焦点和唯一主要运镜。
画面人物与站位：谁在画面左/右/前/后，面对谁，距离。
动作：起点 → 一个主要动作 → 可见结果；写清手和道具归属。
视线与表情：看向谁或什么；表情用眼神、嘴角、肩膀、呼吸、吞咽表现。
场景与道具：只保留必要元素与道具状态。
声音与对白：说话人 → 听话人：台词；其他人是否闭嘴倾听。
```

动作必须有终点：不写“走过去”，写“从左侧工位站起，走到右侧同事桌边并停住，双脚不再移动”。递接写“拿住—伸出—接触—释放—保持”。一个镜头一个主要交互；复杂交接、遮挡、转身或越轴拆更窄的时间块或明确硬切。

### 4. 对白、心声与声音归属

- 画内对白：“程序员对普通同事说：‘今天是我最后一天了，给你买杯奶茶。’普通同事看着程序员回答：‘怎么突然请我喝奶茶？’”绑定说话人和听话人，自然普通话，口型同步。
- 台词要短，留出动作建立、听者反应和尾帧。不让两人同时长篇说话，不用未命名的“画外人”发声。
- 动作不足以让观众理解目的时，优先加一句短画内对白或一条第一人称心声，不为热闹加台词。
- 内心独白写明“程序员第一人称内心独白；画外心声，不是画内对白；程序员嘴唇闭合不做口型；其他人物不说这句话”。平台原生音频不支持“闭嘴出声”时，按平台适配器改成画内低声自言自语或`post_audio`。
- 电话场景写清声音归属：“家人通过手机听筒对程序员说……；家人不露脸；程序员看向手机并回答……”。未接通时不能生成家人声音或铃声。
- 需要生成声音时正面写“清晰的画内普通话人声，台词完整可辨，口型同步”，并保留纸杯、脚步、衣料、键盘或城市底噪。平台不生成音频时不假装解决，在代码块外标`post_audio`。
- 画外对白与内心独白是两件事：前者是空间里的角色对明确对象说话，后者是心理声部；分别标`dialogue_owner`、`listener`、`sound_source`、`voiceover_owner`和嘴唇状态。

### 5. 剪辑与尾帧

- 镜头变化写“在X秒做一次明确、干净的计划内硬切”，不写“自动变焦到特写”或“无缝变成另一个地点”。
- 15秒段默认固定机位或单向轻微运动；切点只在故事需要时用（常用值见项目偏好）。每个切点前后重写人物、站位、道具和场景。
- 最后至少1.5秒稳定尾帧：只保留自然微动或已完成动作，不新增对白、人物、道具、运镜、拉焦或换场。
- 结尾停在本段目标完成后的可见状态，例如“手机仍未拨通”；不提前写下一剧情。

## 四、信息密度与复杂度预算

稳定性和信息密度是两种预算，不能为防乱跳让三个时间块都只是“人物站着”。

**信息密度**

- 每段先写动作脊柱：意图 → 准备 → 执行 → 可见结果 → 反应/下一决定。
- 15秒内以3–4个有意义的`story_beat`为目标（非硬配额）。每个约1.5–3秒的时间块至少新增一种`information_delta`：动作结果、道具状态、关系信息、情绪变化、因果线索或声音意义。人物改变理解、听出潜台词、犹豫后改口、从防御转为信任，也算有效增量，且优先于加新镜头。
- 连续两块只有“继续看/站/走”标`low_information_density`，合并、压缩或补有结果的微动作；纯停顿要写触发原因和结束时的变化。
- 同一地点不等于低密度：可用稳定的微地理路线（入口/桌边 → 关键道具 → 手部或屏幕证据 → 反应 → 结果），每次景别变化服务一个具体信息。
- 没有画内对白且观众无法理解“为什么做”时，默认提出一条2.0–3.5秒的第一人称心声候选，只说一个短意图，不复述画面。不加时记录原因；分镜必须明确“有声对白 / 第一人称心声 / 无语言声音”之一。
- 审查尺：0–3秒建立并给钩子；3–8秒完成主要动作；8–11.5秒结果或反应；11.5–13.5秒关系/内心意义；13.5–15秒稳定尾帧。是检查尺，不是机械切五镜。

**复杂度预算**：一条15秒任务默认最多一个主要空间、一组稳定人物、一条主要镜头路径、一个主要道具关系、一个情绪变化、不超过两次有`cut_reason`的硬切。为达到密度必须引入第二地点、第二组人物或两条以上复杂动作链时，先拆UNIT或改后期剪辑；“高密度”不是“高复杂度”。迭代时一次只加一个变量（主体动作、镜头、环境、声音或风格）。

## 五、正文密度与删减顺序

精致不等于更长。优先保留：角色归属、站位、动作终点、视线、道具持有、声音归属、硬切点和稳定尾帧。压缩时依次删：

1. 重复的“电影感、真实、高清、自然、连贯”等形容词；
2. 多个时间块重复的背景形容词；
3. 重复的禁止项，合并为末尾一段；
4. 与本段目标无关的风格和心理解释。

不删人物名称、左右/前后位置、动作起点和结果、说话人与听话人、嘴唇状态、计划内硬切和稳定尾帧。

有主空间锚点时，只把锚点中已核验的可见事实作为起始状态，重点写后续动作，不重述一套与锚点冲突的脸、背景和构图。没有可靠锚点时，先用一两句建立独立的起始状态，不要求模型猜“上一段最后是什么样”。

## 六、推荐复制模板

```text
画面内角色：
- 角色A：……
- 角色B：……
画外声音或对象：……
不出场人物：……

时间与地点：……
本段唯一剧情目标：……
空间地图：固定参照……；镜头朝向/轴线……；人物屏幕位置/深度/身体朝向/视线目标……；对象数量/固定或移动状态/路线/结束位置……
全局保持：人物外观、画面人数、空间、光线、轴线、道具归属和焦点稳定。

0.0–X秒：
镜头与站位：……
本时间块新增信息：……
动作：意图 → 准备 → 执行 → 可见结果 → 反应……
视线与表情：……
声音与对白/内心独白：说话人 → 听话人；朝向、视线、声源区域和嘴唇状态……

X秒：计划内硬切：切前状态 → 切后状态；只写必要变化。

X–13.5秒：同样字段。
13.5–15.0秒：固定尾帧；只保留自然微动，不新增信息。

画面连续性约束：角色、道具、文字、人物数量和换场约束集中写一次。
```

输出前两遍检查：第一遍看观众能否懂“谁对谁做什么、为什么”；第二遍看模型是否只需执行一个空间、一条镜头路径和一条动作链。第二遍不通过先减事件、角色或运镜。完整示例见[examples/character-drama-15s.md](../examples/character-drama-15s.md)。
