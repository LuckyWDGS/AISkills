# 无人环境片：导演合同与实片反馈

适用庇护所、房间漫游、治愈童话等以空间体验为主的片段；采用何种画风、是否有人/动物、旁白与配乐均取当前项目选择。本文不把某座金牛房间、四镜、27秒或奶油绘本设为全局默认。

## 先明确观众要得到什么

把主题转成具体可感的生活体验：从哪里能抵达、进入后哪里安全干燥、有什么可使用、最后愿意在哪里停留。可选的“外部处境→室内用途→停留位置”是一种观看进程，不是固定镜数。每个镜头应给新用途、空间认识或情绪落点，不靠随机换色和连续推近填时长。

无人也要有目的和可见结果。例如镜头发现已备好的食物、热源与空座，结果是观众理解“今晚可以安顿下来”；不需要添加人物走动、自动取物或虚构手部来满足角色动作脊柱。只有人物戏才使用说话人—听话人回路；画外旁白不生成可见嘴或新角色。

## 参考分工与静态检查

- 美术基准负责材质、色彩、形体语言，不自动负责其他房间布局。主视图采用、全系列风格采用、新视角候选、全屋几何锁定分别登记。
- 每个UNIT选唯一最高空间锚点，按该视图写门、窗、柜、座、通路、深度和最终构图。另一张完整场景即使同画风也可能竞争，不靠追加文字让两张矛盾空间同时成立。
- 新视角先核门窗数量/位置、内外对应、家具轮廓和可行路线。风格呼应但几何未证实时，限制到可见区域或用planned_cut；不声称连续穿门、同一空间重建完成。
- 输入用无字单视图，人审多格板和后加标签版不直接上传。错误图标superseded并指出替代文件；实际尺寸、裁切区域、是否缩放写入登记，不凭请求值称9:16/2K。
- 静态先过向往感与构图：居住落点可读、路线不压住重点、雨外干内有边界。动态来源需在图中成立，例如窗外雨、确有热源的茶汽；不在生成时才凭空加入关键道具。
- 每单元只使用本段必要参考。前段实际尾帧可作为事实记录；如果下段是新构图的计划切镜，不为“连贯”强塞它与新主图竞争。普通参考不自动升级硬首尾帧或resume。

## 可执行的镜头合同

将管理表放复制正文外；正文保持用户已选格式，自然中文或平台原生格式均需包含实际语义：

| 项目 | 写清什么 |
|---|---|
| 可见主体与声源 | 是否无人/无动物；旁白归属、语言和是否存在画内对白 |
| 空间 | 固定结构、观察方向、允许看见的区域、路线边界 |
| 观众获得 | 本段新增的用途/信息/感受，为什么现在展示 |
| 相机 | 一种主要运动、方向、必要幅度、终止构图；固定时也写参照物 |
| 自然过程 | 有来源、局部可读的雨/汽/火等；结构稳定但时间仍流动 |
| 切点 | cut_reason及切前/切后信息；未知通道用计划剪切 |
| 声音 | 旁白、世界内环境与观众侧BGM分别安排，句子只写一次 |
| 收尾 | 主要构图稳定、已有自然动态可延续、最后一句结束后的留白 |

运镜与内容变化分开预算。连续几段都推到近景时，先重分信息职责，选择固定/小幅变化或更早剪出，不给每段都写“缓缓推进”当导演设计。停止运镜不等于停止雨滴、蒸汽、光的合理变化。

旁白陪观众看当前场景，用宽语义阶段安排完整短句，不逐字卡时间，不把全部台词挤进开头。尾段停止新旁白是否同时渐弱音乐，由当次声音目标决定；用户要雨声/BGM继续时不能照人物悬念戏模板把总混音淡没。相同声音描述不能保证跨单元同一音色或旋律。

## 同一旁白的声音身份

跨UNIT重复相同声线描述不会锁定同一个声音。用户指出分段音色不同后，优先保留画面，用当前可用的固定voice_id或明确声音参考建立独立旁白源；短片可一次说完全部文案，再按自然句间对齐各镜头。视觉单元边界与配音生成边界分别设计，原始完整take留存，选型参数与实际听感分开登记。

先确认实际语种、台词和专名，再剪切配音。目录标签与已提交的语言参数均不能替代输出检查；ASR辅助核句和粗定位，精确切口仍保留辅音/气口/尾音余量。听审失败与工具语言失败分开记，不把重新配音的固定声音ID当作用户已喜欢的声线。

含旧旁白的原生混音不能直接当新配音底声；先获得真实分轨，或从语句外窗口/独立素材重建环境与音乐。保留末句后的雨声/房间声，不为了统一声音重新生成全部画面。固定声音身份、响度接近与ASR核句分别只解决相应问题，仍要听普通话、自然度、跨句声线、背景循环和残留旧声；未听不得宣称通过。

## 按真实原片做决定

记录以下四列，不能只用“生成成功/失败”：
`requested`（设计）→ `observed`（实际与查看范围）→ `retained`（保留区间及理由）→ `unresolved`（偏差与下一步）。

| 实际表现 | 优先处理 |
|---|---|
| 推近超程，前半仍能说明用途 | 在重点离开画面前剪出，保留原片；不称终点停机已实现 |
| 室内建立后半变成下一镜相同窗座 | 删除重复区间或重分下一镜职责；不要为原定片长保留 |
| 请求固定，实际中段推/横漂，末段才稳 | 分开记全段与末段结果；可保留自然稳定尾段，不能写全程固定通过 |
| 雨/茶汽全冻结，只剩数字推镜 | 回到自然过程/有效素材检查；不把冻帧拉长当治愈 |
| 门窗错位、穿玻璃、家具融合或关键物凭空移动 | 修参考竞争/空间合同，必要时有限返修；不靠叠化遮错 |
| 只有声音或一处读音有问题 | 先定位、听辨并考虑修声音，不自动重抽已可用画面 |

当用户委托实际成片，按有效区间与语句决定时长；生成秒数是素材预算，不是最终镜头配额。精简后仍须兑现观看承诺；用户要求精确总长时，在该约束内重排或补有明确用途的内容，不随意缩短。可用片段剪辑保留与“原提示词全部服从”是两种状态。

硬切不是天然生硬，也不是天然连贯。切点附近检查注意力位置、构图/尺度跳跃、运动方向、状态与声桥；根据真实端点选择planned_cut、动作匹配或插入。没有可行路径时不要求模型编造一镜到底；叠化只在有叙事意图时使用。

## 验收范围与反馈

先审静态美术，再审动态/空间和完整体验；技术解码、画面采样、连续观看、直接听审、用户评价分别留状态。检查开头、关键变化、末帧及切点邻近帧；高速变化和可疑段补密集/连续检查。提示词写了“固定”“无人”“末2秒停住”不证明实际满足。

声轨存在、RMS/峰值、ASR可帮助排查技术问题，不能证明雨声层次、配乐衔接、声线统一或自然语气。ASR近音词不稳定时记待听辨，不凭预期文字补正确字幕；无法直接听音则listening_pending。另一部已被用户认可的音乐不构成本片听审。

首片交付后收集具体体验：是否想进入/留下、何处重复、哪次切换突兀、旁白是否舒服、结尾是否恰当。仅凭用户说“还可以”可记总体认可，不能扩大为每项声音通过、全系列锁定或发布授权。用户要先一集再决定其余时，后续集数等待这一步的决定。
