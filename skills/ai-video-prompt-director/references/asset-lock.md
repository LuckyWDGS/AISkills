# 视觉资产锁定：设计了，就负责锁定

当本Skill或执行代理为剧情新增会反复出现、会转身/反打、会被交互或承担证据的角色、固定场景、车辆和关键物体时，不能只写文字设定就交“生产就绪”的视频提示词。项目有自己的资产锁定规范（例如`视觉资产锁定与三视图规范.md`）时以它为准；没有时按本页。

## 流程

1. 建立`CHAR-*`、`ENV-*`、`PROP-*`或与项目兼容的稳定ID和文字brief。
2. 用当前可用的图像Skill生成候选参考套图并做跨视角验收：
   - 角色：正面 / 严格侧面 / 背面；
   - 固定场景：主建立 / 反向 / 路线视角（场景不是人物，不机械套“正侧背”）；
   - 车辆或关键物体：前 / 严格侧 / 后，加必要的交互细节。
3. 保存源参考、候选套图和干净单视图，登记来源、职责、版本、状态、实测像素和SHA-256。
4. 用户确认前标`pending_user_confirmation`，不能把AI推断的脸、鞋、背面、门窗或物体结构写成用户事实。
5. 用户确认后才升级为`locked`，再从资产包里为当前UNIT选最小干净参考，不默认上传多格设定板。

## 边界

- 用户只有一张真实地点或物体照片时，未拍到角度的AI扩展只是派生候选。精确结构影响剧情时，先请用户补拍，或调整镜头避开未知区域。
- 风格一致、单个视角采用、跨视角结构一致分别记状态。新视角像同一画风，不证明门后布局相同；未知路线用计划剪切或限制在可见区域。
- 画外声音角色、一闪而过的模糊路人和无剧情作用的普通小物不强制生成完整套图。
- 人审多格板和后加标签版不直接上传；错误图标`superseded`并指出替代文件。
- 资产未完成锁定时，交付里明确标“非生产就绪”，可以交受限试生包（镜头只在已验证视角内）。

## 分工

参考图片/设定资产和视频执行分开判断：按当前授权准备必要图片；用户负责视频时交提示词；已授权执行代理按指定路线生成与剪辑时完成该范围，不反复要求重新授权同一件事。提示词设计本身不授权视频提交，也不自动恢复暂停中的其他路线。
