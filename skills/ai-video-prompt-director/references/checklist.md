# 交付前自审

按任务类型只取适用组。标`[lint]`的项由`scripts/lint_prompt.py`自动检查，先跑脚本，人工只看其余项。平台专属检查在各自适配器末尾，不在这里重复。

## A. 所有任务

- [lint] 复制区没有`@图`、上传顺序、文件路径、稳定资产ID、集数段号、“上一段/下一段”或验收记录。
- [lint] 时间码从0.0秒连续覆盖到要求的时长，没有缺口或倒退；最后至少1.5秒稳定尾帧。
- [lint] 字数在当前入口上限内；没有混入另一平台的语法。
- [lint] “电影感、高级、震撼、氛围感”等空泛词没有堆叠。
- 本段有唯一目标；没有把新地点、新时间或新人物藏在动作里。
- 有且只有一个主空间锚点；参考是最小集合，每份一个主要职责，写了保留与排除。
- 每个动作有起点和可见结果；每个切点有`cut_reason`和切前/切后信息。
- 声音三类（旁白 / 画内对白 / 内心独白）没有混写；能力未核的已标`post_audio`。
- 设计意图、实际输出和用户确认分开表述；没有把“写了固定”说成“已经固定”。

## B. 人物戏

- [lint] 复制区从`画面内角色：`开始，多角色一人一行；有“画外声音或对象”和“不出场人物”。
- [lint] “他、她、对方、那里”等指代不过多（脚本只计数，人工判断是否造成歧义）。
- 空间地图写了固定参照、屏幕位置、深度、轴线、身体朝向、视线目标和物体路线；每个物体有唯一数量、固定/移动状态和结束位置。
- 每句对白绑定唯一说话人和听话人、朝向、视线和声源区域，有足够口播时间；内心独白标了第一人称、归属人物和嘴唇闭合。
- 关键行动和台词通过因果与认知门；双人/关系戏通过人味门。不通过就标`causal_motivation_gap` / `human_dialogue_logic` / `dialogue_underwritten` / `listener_reaction_missing` / `human_presence_missing`，先修剧情再润色。
- 约3–4个有效信息增量；没有连续两个时间块只重复同一状态（否则标`low_information_density`）。
- 无画内对白时，观众能理解行为目的，或已加入一条短心声，或记录了不加的原因。
- 新增需锁定的角色、场景、车辆或关键物体时，资产已锁定，或已明确标为非生产就绪。
- 角色数量、左右站位、道具持有状态和光线方向在切镜前后一致。
- 每个微动作能回答“为什么此刻这样动”。

## C. 环境片

- 写清画内是否有人/动物、旁白归属和语言、是否存在画内对白；没有为套模板补造人物或嘴型。
- 每个镜头给观众新的用途、空间认识或情绪落点，不靠连续推近或随机换色填时长。
- 一种主要运镜、方向、必要幅度和终止构图；固定时也写参照物。连续几段都推近时，已重分信息职责。
- 自然过程（雨、汽、火）有可见来源且局部可读；关键道具在主图里已经存在，不在生成时凭空加入。
- 新视角的门窗、家具和路线已核；未知通道用计划剪切。
- 旁白、世界内环境声和观众侧BGM分别安排，句子只写一次；尾段是否淡出由当次声音目标决定。
- 物件小事件已按实图初态写变化（已有火苗就写变亮），不要求倒退重来。

## D. 修订轮

- 先判断主问题属于哪一层（参考 / 空间 / 动作 / 镜头 / 声音 / 平台语法），本轮只改这一层，保留上一版。
- 能靠剪辑保留的有效区间没有被整段重生；不能靠剪辑掩盖的因果缺口没有被剪掉了事。
