# 参考与空间

适用于所有带参考素材的任务和所有出现空间错误、参考串场、切镜跳变的修订。默认`generation_mode`见[项目偏好](project-preferences.md)。

## 一、多参考不是越多越稳

场景图、人物图、对象图、动作图、风格图、参考视频和参考音频可能同时存在。空间错误先按参考竞争诊断，不先加长提示词。

### 1. 只选一个主空间锚点

每个UNIT只允许一个`dominant_spatial_anchor`，负责最终构图、主体数量、相对位置、镜头朝向、路线和纵深。按本段目标选择：

- 需要复用真实连续画面时：上一段真实事实帧或干净的同场景合成图；
- 需要建立新地点时：没有文字/多格布局的真实场景图或干净场景动作图；
- 没有可靠图片时：用完整的文字`space_map`作主锚点，不用多张彼此不同的场景图共同投票。

其他参考只支持身份、局部外观、动作节奏、风格或声音，不能再定义整张构图。两张图都想规定人物左右、车辆距离或镜头角度时，保留与本段目标最接近的一张，另一张删除或裁成只含其职责的局部。

### 2. 最小参考集合与一参考一主要职责

按“没有它会不会丢剧情事实”筛选：

| 参考类型 | 唯一主要职责 | 默认是否需要 | 常见污染 |
|---|---|---|---|
| 场景/连续性锚点 | 空间、构图、路线、纵深 | 每个UNIT最多一个 | 把路人、文字、车辆位置带成剧情事实 |
| 角色身份 | 可见角色的脸、发型、身形、服装 | 只给可见且身份关键的角色 | 多人拼图复制出多人；背景改写场景 |
| 对象身份 | 车辆或关键道具的外形 | 外形对剧情重要时 | 抢占构图、复制对象、两物体融合 |
| 动作/参考视频 | 动作方向、节奏、身体力学 | 文字动作测试失败或动作特殊时 | 把参考里的人物、路线和机位一起带入 |
| 风格 | 色彩、材质、光感 | 空间和动作稳定后才加 | 带入新场景、人物、服装或镜头 |
| 音频 | 音色、对白或声音事件 | 与视觉参考分开登记 | 图片身份被误当声音身份 |

“一参考一主要职责”不表示复合事实帧里只能有一个元素，而是它只有一个最高职责，且没有第二张参考在同一层竞争。

每份参考同时写**保留**和**排除**，例如：“程序员身份图只保留脸、短黑发、细框眼镜和服装；不继承背景、姿势、镜头角度、手中物和其他人物。”

### 3. 参考冲突审计

生成前在代码块外完成；冲突高时先删、裁、换干净图或拆UNIT：

| 竞争组合 | 典型错误 | 处理 |
|---|---|---|
| 场景 × 角色 | 场景路人替换主角、角色背景改写地点 | 场景只留空间；角色图裁成单人干净身份图 |
| 场景 × 对象 | 单独对象图抢占场景位置或彼此合体 | 主锚点统一规定位置；对象图只锁局部外观，非必要删除 |
| 角色 × 动作 | 动作参考的脸、衣服或性别覆盖角色 | 裁掉身份，或只用低身份信息的动作视频 |
| 对象 × 动作 | 搞错谁移动、路线和接触点 | 文字只指定一个运动主体；复杂物理拆前/结果状态 |
| 风格 × 事实参考 | 风格图带入新人物、建筑或道具 | 风格后加、低职责；能用文字表达就不上传 |
| 音频 × 视觉身份 | 画外声变成画内人物，或错人说话 | 单独写音频归属：说话人、听话人、声源和嘴唇状态 |

### 4. 提示词只补参考没说明的变化

重点写动作起点→过程→结果、谁看谁、谁对谁说、对象沿哪条路线移动、镜头怎样观察、结尾停在哪里。不重复描述参考已锁定的脸、背景和风格，也不试图用更长文字同时服从两张矛盾的图。

使用真实地点图片时，只有它被选为主锚点，空间地图才按其可见结构写；照片里的路人身份、站牌文字、广告不进入剧情事实。

### 5. 硬首尾帧是例外

硬`first_frame/last_frame`只在用户本次明确选择时使用，之后才做接口互斥和端点兼容检查（同空间、同人数、相近轴线/景别、相邻动作）。没有明确选择时，首状态、尾状态和稳定尾帧只是导演/剪辑合同，上一段真实尾帧只作普通参考或剪辑事实。

## 二、空间调度

每个新SHOT/UNIT都写清“对着谁、在哪里、怎么过去”。项目有自己的空间调度规范文件时一并读取（见项目偏好）。

### 空间地图

三套关系：

1. **世界坐标**：门、桌、屏幕、车位、立柱、入口等稳定参照；
2. **屏幕坐标**：画面左/右、前/后、深度层，以及镜头在轴线哪一侧；
3. **关系坐标**：谁面对谁、谁看向谁、谁发起动作、谁接收结果、声音从画内还是哪一侧画外来。

“旁边”“那里”“走过去”“对着画外”都不能单独作为空间指令。人物和道具写成“唯一身份＋世界位置＋屏幕位置＋朝向＋视线目标＋动作路线＋结束位置”；车辆等实体再写数量、独立轮廓、固定/移动状态和间距。

### 对话与视线

画内对白：说话人 → 听话人 → 身体朝向 → 视线目标 → 台词 → 听者反应。画外对白：声音来源区域 → 听话人 → 听话人视线转向。先用主镜头建立地理关系再做反打；同一对话组默认保持180度轴线同侧，越轴用中性角度、可见运动或计划内硬切重新定向。

### 物体与碰撞

碰撞、物体消失、遮挡换手等先拆成“接触前稳定关系 → 动作/接触过程 → 结果证据”。不稳定时默认`split_UNIT + planned_cut + post_edit`：例如汽车静止、三轮车沿明确路线移动，接触由遮挡/声音/剪辑连接，下一镜单独展示车损。不要在一个任务里同时要求风、车辆接触、车损变化、监控文字和对白。

### 切镜平滑

平滑来自端点匹配和声音桥接，不来自模型自动换镜。用`same_frame_handoff`、`match_on_action`、`planned_cut`或`cutaway_insert`明确边界；换地点、换轴线、换主体数量、换景别家族或防止实体融合时，优先计划内剪辑。每个切点写`cut_reason`和切前/切后信息。

## 三、镜头与画面稳定

- 每个镜头写景别、角度、视线轴、焦点和一条主要运镜；主体动作复杂时镜头固定，镜头运动复杂时主体只做一个清晰动作。
- 运镜按“类型＋方向＋必要的幅度＋必要的速度＋最终构图”写；中等幅度/正常速度无叙事价值时省略。“高级运镜、电影感、丝滑转场”不是指令，不同时堆推、拉、摇、移、环绕和拉焦。
- 人物关系优先中景、中近景和手部插入，锁定左右位置、面对方向和轴线。
- 正面写“主体清楚、焦点稳定、动作连续、帧间清晰”；禁止项（运动模糊、拖影、重影、融帧、脸部变形、手指畸形、随机换场）末尾集中写一次。
- 不让模型承担精确合同、代码、联系人、字幕、价格、Logo或二维码。除非文字是已核验的剧情证据，否则写成不可读色块、无品牌文件夹或纯色纸杯。
- 不用梦境溶解、闪回叠影、自动蒙太奇解释心理；把心理翻译为停顿、视线、呼吸、肩膀和手部动作。

## 四、失败降级顺序

先查输出到底服从了哪份参考 → 删除或裁掉竞争参考，重新指定唯一主锚点 → 减少事件和人物 → 固定镜头 → 拆分交互 → 把景别或地点变化改为计划内硬切 → 把不可靠的文字/音频/字幕移出模型职责。不要只继续堆“电影感、真实、连贯、高清”。
