# 项目偏好与项目文件

本Skill的通用规则只写“怎样让模型执行得准”。下面这些是此前项目里用户明确选择或验证过的偏好，作为**可覆盖的默认值**：当前项目有自己的规范文件或用户本次另有要求时，以项目和用户为准。不要把某个项目的画风、片长、切点或配乐扩成所有项目的规则。

## 默认值

| 偏好 | 默认 | 覆盖方式 |
|---|---|---|
| generation_mode | `multimodal_reference`；起始图、结束图、上一段尾帧都先当普通参考、连续性事实或剪辑端点 | 用户对**本次任务**明确说“用硬首尾帧/首尾帧模式”。仅说“参考这两张图”“保持开头结尾”不算 |
| 生成单元时长 | 人物戏单段15秒；完整时长请求时主复制正文覆盖0.0秒到结束 | 用户指定时长；平台确认支持更长且“切开反而更伤”时（见Seedance适配器30秒节） |
| 复制正文字数 | 不超过7000中文字符；2500–5500字不是填字目标，简单环境镜头可以更短 | 当前入口的实际上限；H3原生六段另按官方约350–500英文词的`detailed_description` |
| 稳定尾帧 | 最后至少1.5秒固定稳定，不新增对白、人物、道具、运镜或换场 | 用户对尾段另有声音或动作安排（例如雨声/BGM继续） |
| 15秒切点 | 需要时常用5.5秒和10.5秒；默认最多两次计划内硬切 | 只在故事需要时用，不为凑数量切 |
| 复制格式 | 人物戏从`画面内角色：`开始，一人一行 | 用户为某系列选定的格式（例如“美术前缀＋连贯段落”）只沿用到其指定范围 |
| 参考编号 | 复制区不写`@图`、上传顺序、临时编号 | 用户明确要求一体化提示时 |

## 连续短剧的统一音乐母题（某短剧项目验证过的做法）

多个15秒段分开生成时，每段各配BGM容易对不齐。曾采用的做法：给整集或整季定一个母题，只锁四个不变量——调性（常用小调）、速度（约60–72 BPM）、主乐器（如音色偏旧的钢琴）＋很轻的铺垫（低音弦乐/合成器长音）、留白密度（音符稀疏）。

- 每段按剧情走情绪曲线：留白建立 → 轻紧张动机 → 悬置 → 高点 → 淡出；结尾停在未解决单音/低鸣，约1–1.5秒淡出，不硬切。
- 下一段用同一母题从轻处重新进入，情绪切换只靠声部变化，不换主乐器和调性。
- BGM是观众侧配乐，画面内人物听不见；音量低、不盖台词，不做满铺或史诗感。
- 手动配乐对不上节拍时，常见原因是选了满铺/带鼓点的音乐；稀疏、留白、慢速的更容易卡点。

这些具体数值是该项目的选择，不是新项目默认；环境片、治愈片等按当次声音目标重新决定。

## 项目文件（存在才读，不存在不报错）

继续某个内容项目时，按顺序查找并读取存在的文件；路径是此前项目的约定，新项目可能没有：

1. 项目根目录的`AGENTS.md`/`CLAUDE.md`与当前进度入口（例如`04_进度管理/当前进度.md`、`00_项目总览.md`）。
2. 项目级创作规范（例如`剧本库/00_共用创作规范/人味化创作与提示词标准.md`）、`AI镜头可生成性与风险清单.md`、`空间调度与连续动作规范.md`。
3. 新增角色、固定场景、车辆或关键物体时：项目的资产锁定规范（例如`视觉资产锁定与三视图规范.md`）和`参考图注册表.md`。
4. 人物戏：人物锁定与人物关系文件；环境片：相应美术、环境和观看目标，不补造人物文件。
5. 当前集的场次文件、原始剧本相关段落和最新已完成分镜。

找不到项目规范时，直接使用本Skill的参考文件（[人物戏写作](character-drama.md)、[参考与空间](spatial-and-reference.md)、[视觉资产锁定](asset-lock.md)），不要因为缺文件就退回一句话概述式提示词。

原始剧本只作事实来源；改写的对白、镜头安排和AI约束写入派生分镜，不覆盖原始剧本。
