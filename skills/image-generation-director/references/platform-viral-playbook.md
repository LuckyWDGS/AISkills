# 平台热图与爆款图文方法论

目标：当用户想做抖音、小红书、TikTok 的高点击图片、图文封面、九宫格、旅行日记、穿搭清单、生活方式热图时，先像内容导演一样拆解平台语境，再把趋势语言翻译成可执行的 prompt。

重要边界：不要声称永远知道当前抖音、小红书或 TikTok 的实时趋势。平台热点、流量口味、热门模板、音乐梗、城市热点、商品热词会快速变化。当用户问“现在什么最火”“哪个流量高”“今天抖音热门怎么做”“照最新爆款来”时，需要先查当前平台、榜单、搜索结果或用户给的参考链接/截图，再输出策略。稳定经验可以作为分析框架，但不能替代实时平台验证。

## 1. 平台差异

### 抖音

抖音的图片和图文内容更依赖“第一眼停留”。封面要在很短时间内给出强信号：人物情绪、强标题、现场冲突、真实生活细节、城市地标、商品结果或前后对比。

常见高流量方向：

- 人物强情绪：惊喜、松弛、崩溃后自救、旅行兴奋、下班后的真实疲惫、变美后的自信。
- 真实现场感：街边、便利店、奶茶店、咖啡店、地铁口、商场扶梯、酒店房间、民宿窗边、夜市摊位。
- 城市与旅行地标：明显城市天际线、车站、机场、桥、塔、海边、公路、老街、地铁站牌、热门街区招牌。
- 快速结果：前后对比、改造前后、妆前妆后、穿搭前后、房间整理前后、旅行路线图前后。
- 大标题但不遮主体：标题可以强，但要放在天空、墙面、地面、留白区，不压脸、不压产品、不压人物动作。

抖音 prompt 重点：

```text
强第一眼主体，近景人物情绪或明确结果，9:16 竖图，手机真实拍摄感，现场光，轻微动态模糊，真实生活背景，标题区域留白，主体不被文字遮挡，适合短视频封面
```

### 小红书

小红书更重“可收藏、可模仿、可审美”。图像既要好看，也要有信息秩序。高流量图经常像一个能保存的清单：穿搭公式、路线攻略、拍照机位、奶茶测评、咖啡店打卡、便利店好物、城市周末计划、妆容步骤、家居改造。

常见高流量方向：

- 可收藏信息密度：清单、编号、箭头、贴纸式小标签、路线、价格、品牌、地点、步骤。
- 生活方式现场：咖啡杯、奶茶袋、便利店货架、地铁票、旅行小票、相机、耳机、帆布包、桌面物件。
- 穿搭清单：上衣、裙子、裤子、鞋、包、配饰分区展示；真人上身加单品平铺。
- 九宫格叙事：第一张封面抓人，后面按步骤、细节、对比、避坑、清单展开。
- 真实但干净：不追求过度商业棚拍，而是“像朋友拍的，但审美很好”。

小红书 prompt 重点：

```text
小红书生活方式图文封面，4:5 或 3:4，真实自然光，干净背景，主体有审美秩序，保留标题和标签留白区，信息点像可收藏笔记，真实物件细节，温柔但不廉价
```

### TikTok

TikTok 的图像封面和照片帖更依赖全球化的第一眼识别：强对比、夸张结果、人物动势、街头真实感、旅行地标、情绪瞬间、反差故事。文字通常要更短、更粗、更直白，画面语言要跨文化易懂。

常见高流量方向：

- Before/After：改造、旅行前后、房间前后、穿搭前后、健身前后、产品使用前后。
- POV 与现场感：像第一人称生活片段，路边、车窗、地铁、海滩、音乐节、夜晚便利店。
- 人物动势：回头、奔跑、抬头看城市、拿着饮料笑、在镜子前整理穿搭。
- 地标与氛围：纽约街头、东京便利店、巴黎街角、首尔咖啡店、海岛日落、洛杉矶车窗。
- 视觉梗：超大物件、极简对比、同一角度重复、快速变装的首帧。

TikTok prompt 重点：

```text
viral TikTok cover photo, strong hook, bold readable headline space, candid lifestyle photography, real street scene, expressive adult subject, dynamic pose, high contrast, clean composition, no clutter over the face
```

## 2. 高流量图片常见特征

### 第一眼钩子

第一眼必须回答一个问题：为什么要停下来？

可用钩子：

- 结果钩子：变好看了、变贵了、变瘦了、房间变干净了、路线更省钱了。
- 情绪钩子：她突然笑了、他愣住了、旅行到达那一刻、下班后的崩溃和自救。
- 反差钩子：普通人到精致感、白天到夜晚、素颜到妆后、乱房间到杂志房间。
- 场景钩子：城市地标、巨大落日、机场出发、便利店深夜灯光、奶茶店排队现场。
- 信息钩子：3 个机位、5 套穿搭、7 家咖啡店、24 小时路线、别再这样拍。

Prompt 写法：

```text
封面第一眼有明确钩子：{结果/情绪/反差/场景/信息}，主体位于画面中心偏上，脸部和关键物体清晰，背景提供真实语境但不抢主体
```

### 人物情绪

人物越像真实瞬间，越容易让用户代入。不要只写“美女”“帅哥”，要写情绪和状态。

可用情绪词：

- 松弛：自然微笑、低头整理头发、坐在窗边喝咖啡。
- 兴奋：刚到目的地、举起奶茶、回头看朋友、打开酒店门。
- 自信：穿搭完成后照镜子、走过斑马线、站在城市夜景前。
- 疲惫但真实：下班后便利店、凌晨车站、旅行归来整理行李。
- 温暖亲密：朋友合照、情侣散步、家庭餐桌、宠物贴近主人。

成人边界：

- 成人人像默认写明 `成人 25+`。
- 保持非露骨、非裸体、非性行为、非未成年感。
- 即便用户想做“性感”“吸睛”，也转成 `成熟、时尚、克制、自信、穿搭展示、生活方式摄影`。

Prompt 写法：

```text
一位成人 25+ 的人物，真实自然的{情绪}，动作是{具体动作}，表情有生活感，不夸张摆拍，不儿童化，不露骨
```

### 真实现场感

高流量图常有“我也在现场”的感觉。现场感来自不完美的真实细节，而不是脏乱。

现场元素：

- 光：便利店冷白灯、咖啡店暖灯、黄昏逆光、车窗反光、霓虹灯。
- 物：奶茶杯、咖啡杯、购物袋、小票、行李箱、雨伞、耳机、相机、车票。
- 环境：排队的人、菜单牌、街边路牌、地铁站名、玻璃窗、柜台、货架。
- 质感：轻微颗粒、手机拍摄感、胶片色彩、自然阴影、真实皮肤纹理。

Prompt 写法：

```text
真实现场感，像朋友用手机或小相机记录，保留生活物件细节：{物件列表}，环境有{灯光/招牌/人群/货架}，但画面干净可读
```

### 旅行与城市地标

旅行热图要让用户一眼知道“在哪”和“为什么想去”。地标不一定要完整，但要有识别点。

Prompt 写法：

```text
城市旅行图文封面，人物站在{地标/街区/车站/海边}前，背景有清晰地点线索，行李箱/相机/咖啡杯增强旅行感，9:16 或 4:5，标题留白在天空或墙面区域
```

### 奶茶、咖啡、便利店

这类场景适合做生活方式、城市日记、约会、夜晚疗愈、打卡合集。

Prompt 写法：

```text
奶茶店/咖啡店/便利店真实现场，成人 25+ 人物拿着{饮品/商品}，柜台、菜单、货架、包装袋、小票可见，灯光真实，色彩有食欲，画面适合小红书图文封面
```

### 穿搭清单

穿搭热图要避免只拍人，要展示“公式”。图片要能回答：上衣是什么、下装是什么、鞋包怎么配、适合什么场景。

Prompt 写法：

```text
穿搭清单封面，成人 25+ 模特全身展示，服装层次清楚，旁边有单品平铺区或小标签留白区，强调材质、版型、鞋包配饰，背景干净，适合收藏
```

### 前后对比

对比图最怕左右不一致导致看不懂。要锁定同一个人物、同一角度、同一空间或同一物品。

Prompt 写法：

```text
前后对比图，左右分屏，同一人物/同一空间/同一产品，同一机位和光线基础，左侧是{before 状态}，右侧是{after 状态}，变化一眼可见，文字区域在上下留白，不遮主体
```

### 九宫格

九宫格不是九张随机图，而是一个信息路径。

推荐结构：

1. 封面：最大钩子和结论。
2. 总览：路线/清单/风格总图。
3. 细节 1：人物或产品近景。
4. 细节 2：场景或材质。
5. 方法：步骤、机位、搭配公式。
6. 对比：前后、好坏、不同选择。
7. 避坑：错误示例或不推荐。
8. 收藏点：地图、价格、清单、参数。
9. 收尾：情绪照、结果照、品牌/账号记忆点。

Prompt 写法：

```text
九宫格图文系列，保持同一人物、同一色彩系统、同一地点或主题。第 1 格强封面，第 2 格总览，第 3-6 格展示细节和步骤，第 7 格避坑或对比，第 8 格可收藏清单，第 9 格情绪收尾
```

### 强标题但文字不压主体

图像生成模型常把文字画坏。除非用户明确要图片内真实文字，否则更稳的做法是：生成有留白的干净图，再由排版工具或后期加字。

Prompt 写法：

```text
画面上方/左侧/右侧保留干净留白给后期标题，主体脸部、产品、手部不被文字遮挡，不生成乱码文字，不生成水印，不生成 logo
```

## 3. 搜索/浏览时看什么

当用户要求“看现在平台热门”“照爆款做”“流量高一点”时，先做当前平台搜索或让用户给参考截图。搜索时不要只看点赞数，要拆结构。

### 搜索关键词

按平台和用途组合搜索：

- 抖音：`城市名 + 拍照机位`、`穿搭 + 季节`、`奶茶 + 新品`、`便利店 + 好物`、`旅行 + 路线`、`前后对比 + 改造`。
- 小红书：`小红书封面 排版`、`九宫格 穿搭`、`城市周末攻略`、`咖啡店 打卡`、`便利店 好物清单`、`旅行日记 模板`。
- TikTok：`viral photo carousel`、`before after cover`、`travel photo dump`、`outfit carousel`、`coffee shop aesthetic`、`city night photo dump`。

### 看图像结构

逐条记录：

- 第一眼主体是什么：脸、产品、地标、标题、对比、价格、路线。
- 主体占比：人物是半身、全身、特写，产品占画面多少。
- 画幅：9:16、4:5、1:1、横版还是竖版。
- 标题位置：上方、左侧、右侧、底部、贴纸区，是否遮挡主体。
- 情绪动作：笑、看镜头、回头、走路、拿饮品、开箱、对镜自拍。
- 场景道具：奶茶杯、咖啡、便利店货架、行李箱、路牌、城市天际线。
- 信息密度：是否有编号、箭头、标签、清单、地图、价格。
- 真实程度：手机感、胶片感、棚拍感、AI 感、后期过重程度。
- 评论动机：用户在问链接、地点、价格、教程、路线，还是只夸好看。

### 看系列逻辑

如果是图文/轮播，记录：

- 第 1 张为什么能停留。
- 第 2 张是否兑现承诺。
- 中间是否按步骤展开。
- 最后一张是否有收藏、关注、购买、评论动机。
- 整组是否统一色调、人物、地点、标题样式。

### 看风险

不要照搬：

- 明显未经授权的明星/IP/品牌 logo。
- 露骨、未成年感、擦边校园化、性暗示强的成人内容。
- 误导性夸大结果，如不真实医美、夸大减肥、虚假收益。
- 平台当前可能限流的敏感词或争议表达。

## 4. 把趋势转成 prompt

### 步骤

1. 抽象趋势，不复制具体作品。
2. 保留结构：画幅、主体占比、标题留白、动作、场景、信息密度。
3. 替换成用户主题：产品、城市、人物、穿搭、节日、品牌调性。
4. 加平台字段：抖音停留、小红书收藏、TikTok viral cover。
5. 加安全与质量字段：成人 25+、非露骨、无水印、无乱码、主体不被文字压住。

### 转换模板

```text
平台：{抖音/小红书/TikTok}
用途：{封面/九宫格/商品图/旅行图文/穿搭清单/前后对比}
趋势结构：{第一眼钩子 + 画面构图 + 信息密度 + 情绪动作}
用户主题：{具体主体}
画面 prompt：{主体、年龄边界、场景、动作、构图、光线、风格、留白、质量}
```

### 示例：小红书咖啡店打卡

```text
小红书咖啡店图文封面，成人 25+ 女生坐在临街咖啡店窗边，手边有冰美式、纸袋、小票和相机，窗外有城市街景和行人虚化，真实自然光，暖白色室内灯，4:5 构图，人物半身清晰，桌面物件有可收藏生活方式信息感，画面上方保留干净标题留白，不生成文字，不生成水印，真实皮肤质感，像朋友用相机记录的高审美生活照。

```

### 示例：抖音城市旅行封面

```text
抖音旅行图文封面，成人 25+ 人物拖着小行李箱站在城市地标前，刚到目的地的兴奋表情，回头看镜头，背景有清晰地铁站牌和城市天际线，9:16 竖图，手机真实拍摄感，黄昏逆光，人物占画面 45%，上方天空留白用于后期强标题，第一眼有出发感和地点识别度，不生成文字，不生成水印。
```

### 示例：TikTok before/after 穿搭

```text
viral TikTok before after outfit cover, split-screen composition, same adult 25+ model, same mirror angle and bedroom background, left side casual plain outfit, right side polished city-date outfit with coat, bag and boots, dynamic confident pose, high contrast, clean headline space at top, realistic candid photography, no generated text, no watermark, non-explicit fashion styling
```

## 5. 快速诊断清单

生成前检查：

- 是否说明当前趋势需要实时查证？
- 是否明确平台和用途？
- 是否有第一眼钩子？
- 是否有人物情绪、真实现场或清楚结果？
- 是否锁定画幅和标题留白？
- 是否避免文字压住主体？
- 是否把“爆款感”翻译成结构，而不是空喊爆款？
- 成人人像是否写明 25+、非露骨、非裸体、非性行为？
- 是否给出正向边界，处理文字留白、logo、主体清晰和降低 AI 感？
