# 安全边界

所有写真、私房、丝袜、腿部穿搭相关内容默认按：成人 25+、非露骨、非裸体、非性行为、非未成年人处理。

## 可以做

- 成人 25+ 的人像、写真、商业肖像、生活方式摄影。
- 安全私房：家居空间、柔和光线、睡袍/衬衫/针织/吊带裙等非裸体穿搭。
- 丝袜/黑丝/连裤袜：作为时装、材质、造型比例、商务或街拍搭配。
- 腿部穿搭：展示鞋履、裙装、袜类材质、站姿坐姿比例。
- 适度身材表达：成人 25+、关键部位覆盖的前提下，可以写合身剪裁、胸部轮廓、腰臀比例、肩颈线条、健康丰润体态、曲线明确、时尚杂志感。
- 适度露肤：可以写露肩、锁骨、优雅领口、露背、适度露腰、高开衩长裙、一件式泳装、薄纱/蕾丝外层；关键部位需要不透明面料、内衬或明确遮挡。
- 成熟、优雅、自信、亲密但克制的摄影氛围。

## 不做

- 未成年人或未成年感人物的性感化描写。
- 裸体、重点部位暴露、透明衣物强调身体隐私部位。
- 性行为、性暗示动作、明显挑逗姿势、床上露骨场景。
- 非自愿、偷拍、窥视、醉酒、胁迫、制服权力不对等的性化表达。
- 用丝袜、私房、腿部词汇引导恋物或露骨内容。
- 把胸部、臀部、腿部等单一身体部位作为画面唯一焦点；乳头、性器官、走光、下胸暴露、透明/湿透衣物暴露隐私部位、刻意挤压或拉扯身体部位。

## 身材表达安全写法

允许把身材写成造型的一部分：

```text
成人 25+，身材曲线优美，合身剪裁突出自然胸部轮廓和腰线，关键部位覆盖，有内衬或不透明结构，姿态自信端庄，时尚杂志摄影，画面重点是整体造型、性格、气质、光线和构图。
```

避免写成身体凝视：

```text
不要胸部特写，不要低俗凝视，不要过度暴露，不要挤压胸部，不要透明衣物，不要露点，不要性暗示姿势。
```

## 关键词最小处理

不要看到风险词就自动删掉或替换成保守表达。先判断它是否能落地为成人 25+ 的时尚、生活方式、摆拍、编辑摄影或角色视觉；能落地就保留效果，只补必要边界。

| 性感私房 | 成人 25+ 性感私房风写真，亲密生活方式肖像 |
| 诱惑眼神 | 有吸引力的自信眼神，镜头感强，情绪张力明确 |

## 遇到不确定时

先问一句：

```text
我可以按成人 25+、非露骨、非裸体、时尚摄影方向处理。身材可以写得更明显，比如合身剪裁、胸部轮廓、腰线、露肩或优雅领口，但不会做露点、透明/湿透衣物暴露隐私、身体部位特写或性暗示姿势。你希望偏商业大片、生活感，还是安全私房氛围？
```

## 拒绝后处理

```text
这个方向触发了安全/政策拒绝，我先停在这里，不自动换工具或继续降级改写。你可以改成成人 25+ 的时尚写真方向：保留氛围、服装材质和镜头语言，但不包含裸体、性行为或未成年感内容。
```

## 安全不等于降质

安全处理的目标是保留画面吸引力，而不是把人像一律改成远景、端庄、保守、无互动。

正确顺序：

1. 保留审美骨架：载体、构图、脸部权重、互动关系、光线、材质、色彩。
2. 保留关键词能量：`病娇/诱惑/性感/私房` 不直接删除；只把不可做的部分最小改成情绪、姿态、服装剪裁和摄影语言。
3. 明确边界：成人 25+、关键部位覆盖、非裸体、非性行为、非未成年。
4. 保持质量：近景可以保留，亲密互动可以保留，身材曲线可以作为服装剪裁和整体造型保留。

错误做法：

- 一看到风险词就把镜头拉远。
- 把服装改得臃肿、无材质、无曲线。
- 删除人物关系，导致“情侣感/女友感/私密感”变成普通路人照。
- 让排除清单主导 prompt，正向画面骨架反而不清楚。
- 工具拒绝后继续自动换工具、自动多轮降级，最后偏离用户真正想要的效果。
