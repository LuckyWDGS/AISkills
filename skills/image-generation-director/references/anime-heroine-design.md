# 动漫女主与原创二次元角色 Prompt 参考

用途：为 `image-generation-director` 处理好看的动漫女主、原创二次元女主、玄幻女主、都市奇幻女主、成人校园风女主、头像、海报、角色设定图和动态首帧。

## 总原则

- 默认主体：成人 25+ 女性角色，成熟面部比例，非儿童化、非未成年。
- 默认内容：非露骨、非裸体、非性行为；不写未成年性感化，不写高中生/JK/萝莉/儿童化性感。成人女主可以有成熟曲线、强气场、合身战斗服或时装剪裁，但关键部位覆盖，不做身体部位特写。
- 原创优先：可以拆解某类 IP 的气质、构图、色彩、角色功能，但最终 prompt 必须改写成原创角色。
- 商用避险：避免使用具体 IP 名、角色名、logo、校徽、队徽、品牌标识、标志性服装或高度近似造型。
- 风格改写：把“像某角色/某作品”改成可执行视觉语言，例如发色、轮廓、服装层级、世界观、镜头、色调、情绪。
- 一致性：系列图要锁定角色身份、发型、瞳色、核心服饰、标志性道具和色彩系统。

## IP 灵感拆解与原创化

当用户提到具体 IP、角色或工作室风格时，用这个流程：

1. 拆气质：勇敢、冷静、甜酷、神秘、治愈、女王感、冒险者、学者、守护者。
2. 拆视觉：发型长度、发色范围、瞳色、轮廓语言、服装层次、主色与辅色、武器/道具。
3. 拆世界观：玄幻宗门、都市夜景、魔法学院成人版、赛博街区、神社/图书馆/天台。
4. 去相似：去掉角色名、标志性发饰、logo、专属服装、专属武器、过近配色比例。
5. 重组原创：给新身份、新服饰结构、新道具、新场景、新叙事瞬间。

可用改写句：

```text
不要复刻任何现成 IP 或角色；只保留“清冷、坚韧、带一点神秘感的冒险女主气质”，重新设计为原创成人 25+ 女性角色。
```

## 安全校园风边界

可以写：

- 成人 25+ 大学校园、研究生、年轻讲师、校友返校、艺术学院工作室。
- 西装外套、针织开衫、长裙、衬衫、风衣、学院风大衣、乐福鞋。
- 图书馆、大学咖啡馆、画室、阶梯教室外、校园银杏大道。

不要写：

- 高中生、初中生、JK、萝莉、未成年、儿童化身体或脸型。
- 性感化校服、短裙身体凝视、露骨姿势。
- 让角色看起来未成年但使用成人描述规避。

安全替换：

```text
成人 25+ 大学校园女主，成熟面部比例，学院风长外套和及膝长裙，图书馆窗边，自然读书姿态，清爽但不儿童化。
```

## 动态首帧模板

用于图生视频或视频首帧。首帧要清楚交代人物、空间、运动方向，避免把多个动作塞满。

```text
生成一张原创成人 25+ 动漫女主动态首帧，角色为[身份]，保持成熟面部比例，非儿童化，非露骨。她位于[场景]，正在开始一个明确动作：[转身回望/抬手展开符阵/拔剑前一瞬/推开咖啡馆门/站上列车月台]。

首帧构图：
- 人物位置：[居中/左三分之一/右三分之一]，给运动方向留出空间。
- 动作线：衣摆、发丝、雨滴、光尘或纸页沿[方向]运动，暗示下一秒动作。
- 镜头：中景或全身环境镜头，避免过近脸部特写，背景空间可延展。
- 光线：主光[ ]，轮廓光[ ]，背景光[ ]。
- 连续性：角色发型、瞳色、服装、道具和配色与设定图一致。

画风：高质量动画电影首帧，清晰线稿，细腻光影，轻微运动感但主体不糊，适合后续视频生成，9:16 竖图。
```

## 一致性锁定短句

```text
保持同一原创角色：成人 25+，相同发型、发色、瞳色、脸部轮廓、服装主结构、标志性道具和主色系统；只改变镜头、动作、表情和场景。
```

## 最终检查

- 是否写清成人 25+，且视觉上不儿童化？
- 是否删除具体 IP 名、角色名、logo 和高度近似标志物？
- 是否避免未成年性感化、JK、萝莉、高中生等风险词？
- 角色辨识度是否来自原创剪影、服饰、道具和世界观？
- 是否为后续系列图保留一致性锁定点？
