# 高级案例模式图谱

用途：把公开 prompt 案例库中可复用的视觉机制整理成 `image-generation-director` 的创意模块。灵感来源包括用户点名的 EvoLinkAI README_zh-CN 案例，但不要照搬原 prompt 长段原文；只提炼结构、镜头、构图、材料、正向边界和可扩展玩法。

参考入口：

- `https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts/blob/main/README_zh-CN.md`
- 适用案例：148、149、150、160、163、179、182、214、231、232、259、315、7、130、131、80 等。

## 使用原则

- 先问用途：社媒封面、写真、广告、旅行海报、故事版、贴纸、信息图、视频首帧。
- 再选视觉机制：设备框中框、竖版写实自拍、Y2K 拼贴、旅行水彩、微缩世界、品牌肖像、剪贴簿饮品、手写信息图、贴纸化、关键视觉、故事板。
- 人像默认成人 25+、非露骨、非裸体、非性行为、非未成年感。
- IP/品牌/人物：避免真实品牌 logo、未授权角色名、名人近似、原案例排版复刻。
- 画面文字：除非用户明确要可读文字，否则保留后期排版留白，避免模型生成乱码。

## 1. 老式相机液晶屏截图

可偷的结构：

- 画中画：外层是老式数码相机机身或 LCD 屏，内层是屏幕里的一张怀旧照片。
- 质感：直闪、数码噪点、轻微拖影、早期消费级相机色彩。
- UI：少量拍摄参数、日期、电量、对焦框，服务真实感。
- 场景：便利店、卧室书架、KTV走廊、深夜街角、旅行旅店。

不要照搬：

- 不照搬原图人物、服装和具体时间戳。
- 不让屏幕 UI 大量乱码；文字最好后期加，或只生成简单符号式界面。
- 不把怀旧快照做成偷拍、窥视或未成年感。

可复制模板：

```text
老式数码相机 LCD 屏幕近景，外层能看到黑色相机边框、发光屏幕、少量对焦框和电量图标。屏幕里是一张成人 25+ 人物的怀旧直闪快照：她站在深夜便利店门口，穿宽松白衬衫、深色长裤和复古外套，正回头自然笑，背景货架和霓虹灯轻微虚化。质感为 2010 年前后小数码相机，强直闪、轻微颗粒、轻微运动模糊、真实低照度色彩。整体像真实相机回放画面，非露骨，4:3 或 1:1。
```

## 2. 写实感人物竖版照片

可偷的结构：

- 高级手机前置自拍感，但比普通生活照更干净。
- 9:16 竖版、近景或上半身、温馨室内或生活空间。
- 真实皮肤纹理、轻微噪点、轻微柔焦、自然光和室内暖光混合。
- 人物情绪安静、松弛、自然，不要只写“漂亮”。

安全改写：

- 如果参考案例出现睡裙、肩带、丰腴等容易擦边的内容，不必全部改成保守穿搭；可以保留吊带、缎面、优雅领口、自然曲线和健康丰润体态，但要写清成人 25+、关键部位覆盖、有内衬或外搭、不做拉扯衣物或身体部位特写。
- 身材描述改为自然体态、健康比例、成熟自信、松弛生活感，不做身体部位凝视。

```text
9:16 竖版写实手机照片，成人 25+ 东方女性坐在温馨卧室窗边，上半身近景自拍构图，镜头略微从上方俯拍，人物位于画面中央偏右，视线自然看向窗外，表情安静温柔。穿浅蓝吊带外搭针织开衫和白色长裤，关键部位覆盖，面料有内衬或不透明结构，呈现自然肩颈线条和松弛居家气质。真实 iPhone 前置摄像头质感，轻微噪点、轻微柔焦、自然皮肤纹理，室内暖光与窗光混合，床品、木质床头柜和窗帘背景轻微虚化，干净高级，非露骨。
```

## 3. Y2K 日本街头社论海报 / 拼贴海报

可偷的结构：

- 高街人物主图 + 撕纸拼贴 + 杂志裁片 + 粗颗粒纸张 + 霓虹/路牌/贴纸。
- 颜色可以高对比：银色、黑色、粉色、酸绿、亮蓝、奶油白。
- 文字区用大胆标题块，但人物脸、服装和产品不被压住。
- 适合街头穿搭、音乐封面、潮牌概念、动漫街头女主、城市视觉海报。

```text
Y2K 日本街头社论拼贴海报，成人 25+ 模特穿银灰短外套、黑色长裤和厚底鞋，站在东京风格街角斑马线旁，主体是高街时尚摄影。周围叠加撕纸边缘、杂志裁片、胶片颗粒、喷墨纹理、少量贴纸和抽象涂鸦，背景有霓虹灯、地铁入口、自动售卖机和城市路牌但不出现真实品牌。版式大胆，标题留白在上方和右侧，人物脸部清晰不被遮挡，4:5 竖版，高级杂志视觉。
```

## 4. 水彩旅行海报

可偷的结构：

- 目的地核心地貌或建筑 + 手绘水彩肌理 + 复古海报留白。
- 色彩清爽、纸张纹理、边缘轻微晕染。
- 可以配小型地图、邮戳、车票、当地植物和天气感。
- 适合瑞士、京都、釜山、云南、青岛、厦门、重庆、巴黎等目的地。

```text
水彩旅行海报，主题为[目的地]。画面中央是当地标志性风景：远山、湖面、老街屋顶和晨雾，前景有一位成人 25+ 旅行者背影，穿风衣、背相机包，站在观景台边。手绘水彩和钢笔线稿结合，纸张纹理明显，色彩清爽柔和，留出上方标题区和下方日期区，复古旅行明信片感，3:4 竖图。
```

## 6. 品牌形象肖像

可偷的结构：

- 上传肖像作为身份参考，只保留真实面部特征和气质。
- 品牌气质通过前景花、产品、材质、光线、色彩系统表达。
- 侧脸、低头、逆光、浅景深能做出高级感。


## 7. 沙滩丰腴/泳装时尚

安全定位：只做成人 25+、身体多样性、度假时尚、泳装杂志编辑感。禁止露骨、低俗身体凝视、未成年感、色情姿势。

```text
成人 25+ 女性，身体自然丰润健康，沙滩度假时尚写真。她穿端庄剪裁的一件式泳装或高腰泳装，外搭轻薄不透明白色衬衫，站在黄昏海滩浅浪旁，自然微笑，双手轻扶草编帽。背景有淡粉橙天空、平静海面和椰影，人物位于画面中央，留出少量天空空白。写实商业度假摄影，真实肤色，健康自信，幸福感，非露骨，4:5 竖图。
```

四宫格可用：

```text
成人 25+ 泳装时尚杂志四宫格，每格同一模特但不同镜头功能：1 封面全身，2 面料和配饰细节，3 海边行走动态，4 夕阳收尾肖像。保持端庄泳装、度假编辑摄影、健康自信、非露骨。不要生成乱码文字，保留杂志标题留白。
```

## 选型速查

- 想要真实感：选老式相机 LCD、写实竖版照片、品牌形象肖像。
- 想要潮流感：选 Y2K 日本街头拼贴、日韩时尚 moodboard。
- 想要收藏感：选剪贴簿饮品/咖啡馆、手写信息图、旅行手账。
- 想要奇观感：选微型世界、星河 3D CG、机甲海城关键视觉。
- 想要视频化：选 8/9/25 格故事板、动态首帧、Live Photo。
- 想要商品转化：选饮品剪贴簿、品牌形象肖像、产品流程故事板、9格广告故事版。
