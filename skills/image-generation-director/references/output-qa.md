# 输出质检

用于交付 prompt 或生成图后的快速检查。

## Prompt 交付前

- 意图明确：用途、主体、场景、风格、画幅都写清。
- 必要边界明确：成人 25+、非露骨、非裸体、非性行为。
- 参考明确：需要锁脸、锁服装、锁产品时已要求参考图。
- 构图明确：景别、角度、主体位置、背景关系清楚。
- 质量明确：光线、镜头、质感、正向边界完整。
- 关键词已落地：抽象审美词、风险词、冲突词和过长排雷词没有孤立堆叠；能保留的用户关键词已通过载体、构图、服装、姿态和镜头语言拍实。
- 质量骨架优先：必要边界没有压过载体、裁切、脸部权重、互动关系、光线、色彩和用户想要的效果。

## 图像生成后

- 人物：年龄感成人，脸不崩，手和肢体合理。
- 服装：完整、非透明、符合用户要求。
- 安全：没有裸体、露骨姿势、性行为或未成年感。
- 产品：外形、材质、颜色、比例正确；不乱生成品牌字。
- 风格：符合商业、胶片、影视、生活方式或角色设定方向。
- 画幅：尺寸、留白、主体裁切可用。
- 目标体验：如果有参考图，先比观看体验是否一致，而不是只查元素是否出现。
- 是否过度处理：没有因为边界处理而变成远景、脸小、衣服臃肿、姿态僵硬、互动减弱，或丢掉用户指定的关键词效果。

## 常见问题与修正

| 问题 | 修正词 |
| --- | --- |
| 太像网红滤镜 | 真实肤色、自然皮肤纹理、少磨皮、生活方式摄影 |
| 太露骨 | 克制姿态、完整服装、时尚杂志感、非露骨 |
| 身材不够明显 | 合身剪裁、自然胸部轮廓、腰线清晰、成熟自信、整体造型比例 |
| 身材表达越界 | 保留曲线但取消局部特写、透明衣物、露点、拉扯衣物和挑逗姿势 |
| 脸不稳定 | 锁定参考图、正面清晰五官、自然表情、减少夸张妆容 |
| 手指错误 | 手部自然放松、手不遮挡脸、避免复杂手势 |
| 商品文字乱码 | 不生成文字、无 logo、标签留白、后期添加文字 |
| 风格跑偏 | 增加具体摄影类型、光线、镜头、色彩和场景 |
| 同 prompt 比 ChatGPT 难看 | 先复制参考图的载体、裁切、脸部权重、互动几何、光线色彩；再最小处理真实风险词 |
| 安全后变保守僵硬 | 把边界词后置，把正向主体改成可拍摄的高质量动作、眼神、材质和光线，并保留关键词效果 |
| 手机感不够 | 手机相册截图/低动态范围/轻微过曝/压缩噪声/前景遮挡/狠裁切/非专业随手拍 |

## 迭代话术

```text
这版主体和光线可以保留，问题在姿态偏露骨、服装边界不够明确。下一版建议改成：关键部位覆盖、有内衬或不透明结构、自然坐姿、时尚杂志感、成人成熟气质，画面重点回到脸部、穿搭、光线和整体构图。
```

```text
这版身材表达太弱，可以加强但不越界：保留成人 25+、关键部位覆盖，加入合身剪裁、自然胸部轮廓、腰线清晰、肩颈舒展、成熟自信。可以有露肩、锁骨或优雅领口；不要胸部局部特写、透明/湿透衣物暴露隐私、露点或拉扯衣物。
```

```text
如果要锁定同一个人，需要提供人脸参考图；如果只要同类型气质，我可以继续用文字约束。
```

```text
这版不是元素缺失，而是观看体验错了：它像专业白天街拍，不像手机相册里的夜街近景。下一版先锁：手机相册截图、夜晚商业街、男友白 T 肩膀前景占 30%、脸贴近肩膀、女生脸在上三分之一、美甲手链清楚、冷粉紫夜景手机压缩感。安全边界只保留成人 25+、关键部位覆盖、非露骨、非暴力。
```
