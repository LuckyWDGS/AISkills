# 质量优先 Prompt 修复

用途：当用户发现同一提示词在不同平台生成质量差异很大，或怀疑提示词污染、安全改写导致画面变丑时，先诊断再修复。目标始终是最终图片质量和用户想要的效果，而不是机械堆安全词或主动删掉关键提示词。

## 1. 结论先行

多数“同 prompt 但图变丑”的问题来自四层叠加：

- 生成链路不同：模型、隐藏 prompt enhance、尺寸、seed、质量档、参考图能力、后期增强不同。
- 提示词污染：口语词、情绪词、风险词、冲突词、过长排雷词把模型带向错误画面。
- 安全改写粗糙：平台把亲密、性感、短裙、病娇、私房等词降级成远景、僵硬姿势、保守服装、脸小、互动弱。
- 镜头骨架缺失：没有锁定载体、裁切、主次关系、脸部权重、手部动作、光线、场景深度。

不要把原因简单归为“安全限制”。安全会影响结果，但质量下降通常是因为没有保住载体、裁切、脸部权重、互动关系和关键词能量，或把真正需要处理的风险词处理得太粗。

## 2. 污染词分类

### 低质量污染

这些词会让模型抽象发挥，容易变网红、棚拍、塑料、摆拍：

- `好看`、`高级`、`大片`、`氛围感`、`女友感` 单独出现。
- `极致真实`、`超高清`、`8K` 堆叠但没有镜头和光线。
- `清纯`、`白月光` 但没有年龄、场景、构图和服装边界。

修复方式：把抽象词拆成载体和镜头。

```text
白月光女友感 -> 夜晚手机相册截图，男友第一人称 POV，脸靠近肩膀，侧头看镜头，冷白灯和淡紫粉夜色，真实手机低动态范围。
```

### 安全污染

这些词不是永远不能用，但和短裙、亲密姿态、主观视角一起出现时，容易触发保守化或拒绝：

- `病娇`、`诱惑`、`撩人`、`性感`、`私房`。
- `短裙`、`吊带`、`透视`、`低胸` 与身体局部描述混在一起。
- `清纯少女`、`女友`、`校园`、`JK` 等未成年或学生联想词。

修复方式：保留人格张力和关键词能量，只把真实高风险部分补成成人、情绪和摄影语言。

```text
病娇地看我 -> 温柔依恋、轻微占有欲的恋爱凝视，不恐怖不暴力。
性感短裙 -> 成人 25+ 的甜美夏季白色穿搭，关键部位覆盖，非露骨，重点是脸部情绪、手部互动和手机快照感。
```

### 构图污染

这些问题会让图从“亲密手机照”变成“AI 街拍”：

- 没写画幅或只写 `竖图`，导致模型不懂是手机相册还是摄影写真。
- 写 `walking outdoors` 但没有写前景肩膀、抱胳膊、脸贴近、近距离裁切。
- 写 `cinematic`、`editorial` 太强，模型会走专业大片，丢掉真实手机感。

修复方式：先锁载体，再锁关系。

```text
手机相册截图风格，9:16 超竖屏，上下有白色相册 UI 留白，左侧男友白 T 恤肩膀和胳膊占画面约 30%，女生双手抱住胳膊，脸贴近肩膀，脸在画面上三分之一。
```

### 排雷词污染

排雷清单过长、过猛、互相冲突时，会把模型引向“规避优先”，出现远景、衣服臃肿、脸小、姿态僵硬。

默认不要在可复制 prompt 里另附排雷清单。把会破坏图片质量和安全边界的项改成正向画面语言：

```text
成人 25+，成熟面部比例，白色夏季穿搭覆盖完整，关系是自愿情侣摆拍，画面重点是脸部和抱胳膊互动，近距离手机截图，男友肩膀前景清楚，夜晚商业街，真实手机压缩质感，手部自然，文字与 logo 留白或模糊处理。
```

## 3. 修复顺序

1. 先找目标图的真正优势：载体、画幅、裁切、主次关系、脸部权重、光线、颜色、细节密度。
2. 最小处理污染词：不要孤立堆叠 `性感/病娇/清纯/女友感`，但能保留的关键词要保留，并用成人主体、服装、构图、动作和光线落地。
3. 写质量骨架：画面像什么设备拍的、谁在前景、脸在哪里、手在哪里、背景多虚、色彩是什么。
4. 写最小边界：成人 25+、非未成年、关键部位覆盖、非露骨、非暴力。
5. 正向边界：把质量和必要边界写成要出现的结构，不另附排除块，不把画面降级成另一个概念。
6. 生成后按目标参考图逐项比对，不要只看“有没有元素”。

## 4. 主观视角夜街女友修复模板

```text
手机相册截图风格的真实照片，9:16 超竖屏，像男友手机相册里翻到的一张夜晚情侣随手拍。画面上下有大面积白色相册 UI 留白，顶部有日期时间栏的截图感，底部有相册操作栏留白，不需要真实可读文字。

夜晚城市商业街，人行道，店铺灯光和霓虹招牌在远处虚化，路人自然经过，冷白灯混淡紫粉夜色，真实手机夜景低动态范围，轻微过曝白衣，高光有点溢出，暗部有压缩噪声。

男友第一人称 POV，左侧前景只露出男友白 T 恤肩膀和胳膊，占画面约 30%。一位成人 25+ 女性走在男友身边，甜美清冷的白月光女友气质，白色夏季甜美穿搭，关键部位覆盖，非露骨。她双手抱着男友胳膊，脸轻轻贴近男友肩膀，侧头抬眼看向镜头，温柔依恋、轻微占有欲但不恐怖不暴力。脸部较大，位于画面上三分之一，眼睛是第一视觉焦点。眼角有一颗小痣，长发微乱，手上有精致美甲，手腕有细手链。

真实手机照片，不是专业棚拍，不是时尚大片，亲密、自然、生活化、好看，保留轻微瑕疵和手机快照感。
```

## 5. 质量优先检查

生成后只问一个问题：它是否更像目标图的观看体验？

检查顺序：

- 载体：是否像手机相册截图，而不是干净 AI 图？
- 关系：男友肩膀和胳膊是否形成亲密前景？
- 脸：脸是否足够大，眼神是否是第一焦点？
- 手：抱胳膊、美甲、手链是否清楚且不畸形？
- 光：是否是夜晚商业街冷白/淡紫粉，而不是白天旅游照？
- 裁切：是否有贴身近景和狠裁切，而不是完整环境街拍？
- 安全：是否成人、非露骨、没有未成年或性行为暗示？

如果没有同时满足载体、关系、脸部权重和夜景调色，不要继续微调小饰品；先重写骨架。
