# 丝袜与连裤袜时尚

适用：丝袜、黑丝、连裤袜、长袜、鞋履和腿部穿搭。统一按成人 25+ 的时装材质处理。

## 安全基调

- 成人 25+。
- 丝袜是服装材质，不是露骨或恋物表达。
- 重点写：材质、颜色、透明度、搭配、鞋履、裙装比例、场景。
- 避免：挑逗姿势、隐私部位、床上露骨场景、过度身体特写。

## 材质词

- 黑色半透明连裤袜、哑光黑丝、细腻织纹、轻薄尼龙质感。
- 灰色羊毛连裤袜、咖啡色薄袜、肤色哑光丝袜、白色针织长袜。
- 搭配：西装裙、风衣、乐福鞋、高跟鞋、长靴、针织连衣裙。

## 场景方向

- `通勤时装`：西装外套、铅笔裙、黑色连裤袜、办公室走廊。
- `秋冬街拍`：风衣、短靴、灰色连裤袜、城市街角。
- `杂志棚拍`：极简背景、腿部比例、鞋袜材质细节。
- `生活方式`：咖啡馆、书店、酒店大堂，自然站姿。

## Prompt 模板

```text
一位成人 25+ 女性，时尚街拍穿搭，黑色西装外套、及膝半身裙、哑光黑色连裤袜和黑色乐福鞋，站在城市咖啡馆门口，自然站姿，展示整体穿搭比例和袜类材质。35mm 胶片街拍，柔和阴天光，真实肤色，背景轻微虚化，成熟优雅，非露骨，4:5 竖图，高清细节。
```

## 构图建议

- 全身穿搭：鞋、袜、裙摆和外套都要入画。
- 材质细节：可用局部特写，但保持商品/时装语境。
- 镜头角度：平视或轻微低角度，避免窥视感。
