# 安全私房肖像

适用：成人 25+、非露骨、非裸体的私房氛围人像。核心是光线、空间、情绪和材质，不是暴露。

## 安全定义

- 成人 25+。
- 关键部位覆盖：睡袍、衬衫、针织开衫、缎面长裙、家居套装、吊带外搭衬衫、露肩针织、带内衬的薄纱/蕾丝外层。
- 可有亲密氛围，也可以通过合身剪裁表现成熟曲线、自然胸部轮廓和腰线，但不出现裸体、性行为、透明衣物、露点、身体部位特写或挑逗动作。
- 场景可以是卧室、梳妆台、窗边、沙发，但镜头保持时尚摄影语言。

## 画面方向

- `柔和窗光`：白纱窗帘、暖色房间、安静表情。
- `法式复古`：木质家具、胶片颗粒、缎面睡袍、柔焦。
- `高级黑白`：低对比灰阶、肩颈线条、克制姿态。
- `生活方式`：晨间整理、阅读、倒茶、坐在床边穿拖鞋。
- `曲线克制版`：缎面家居裙、合身针织、优雅领口、露肩/锁骨、自然腰线、关键部位覆盖、姿态自信端庄。

## Prompt 模板

```text
一位成人 25+ 女性，安全私房肖像，穿着不透明的米白色缎面睡袍，坐在卧室窗边的扶手椅上，姿态自然端庄，表情安静自信。柔和自然窗光，浅景深，暖色木质空间，法式复古摄影，高级生活方式杂志质感，画面克制不露骨，4:5 竖图，高清真实皮肤纹理。
```

## 曲线版 Prompt 模板

```text
一位成人 25+ 女性，安全私房肖像，性格安静自信，穿缎面家居长裙和轻薄外搭衬衫，裙身关键部位有不透明内衬，露出锁骨和肩颈线条，合身剪裁呈现自然胸部轮廓和腰线，气质成熟。她坐在卧室窗边扶手椅上，轻微侧身，肩颈舒展，表情安静自然。柔和窗光，暖色木质空间，法式复古摄影，浅景深，真实皮肤纹理，画面重点是性格、气质、服装材质、光线和整体构图，亲密但克制，非露骨，4:5 竖图。
```

## 改写建议

- `性感私房` -> `安全私房肖像、成熟优雅、柔和窗光`
- `床照` -> `卧室生活方式人像、窗边坐姿`
- `诱惑` -> `自信、松弛、镜头感强`
- `睡衣很透` -> `不透明缎面家居服`
- `胸部突出` -> `合身剪裁呈现自然胸部轮廓，关键部位覆盖，画面仍以性格、气质和整体造型为主`
- `身材火辣` -> `成熟曲线、健康丰润、优雅克制`

## 质检重点

- 画面是否像时尚摄影，而不是露骨内容。
- 服装是否明确关键部位覆盖，并说明薄纱/蕾丝/吊带等是否有内衬或外搭。
- 姿势是否自然端庄。
- 身材表达是否来自服装剪裁和整体姿态，而不是局部特写或性暗示。
- 是否写明成人 25+、服装覆盖、自然姿态和克制摄影边界。
