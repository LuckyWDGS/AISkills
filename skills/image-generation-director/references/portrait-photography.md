# 女性写真与生活感人像

适用：成人 25+ 女性写真、生活方式头像、社媒封面、时尚人像。

## 安全基调

- 成人 25+。
- 关键部位覆盖，不裸体，不露点，不露骨；允许露肩、锁骨、优雅领口、露背、适度露腰或有内衬的薄纱/蕾丝外层。
- 氛围可以成熟、温柔、松弛、电影感，但姿态自然克制。
- 重点写性格、光线、构图、服装、场景、情绪和整体比例；可以写曲线与身材优势，但不把身体隐私部位作为焦点。

## 常用风格

- `生活感`：自然窗光、咖啡馆、居家阅读、街角散步、真实肤色。
- `高级写真`：极简背景、柔光、干净妆发、杂志构图。
- `胶片街拍`：35mm 胶片、城市街道、轻微颗粒、真实抓拍。
- `影视感`：低饱和色彩、侧逆光、浅景深、叙事表情。
- `商业头像`：干净背景、正面或 3/4 侧脸、专业亲和。
- `曲线时装`：合身剪裁、自然胸部轮廓、腰线清晰、三分之二身或全身构图，时尚杂志感。
- `性格人像`：先写性格核心，如温柔松弛、自信成熟、甜酷街头、文艺清冷、明亮活力、女王气场。

## Prompt 模板

```text
一位成人 25+ 女性，性格温柔松弛，气质成熟自然，穿合身针织上衣和高腰半身裙，露出锁骨与肩颈线条，关键部位覆盖，剪裁呈现自然胸部轮廓和腰线。她坐在自然窗光旁的咖啡馆，轻微侧身看向镜头，表情放松自信。三分之二身构图，85mm 人像镜头，浅景深，肤色自然，背景柔和虚化，生活方式摄影，高级但真实，4:5 竖图，高清细节。
```

## 姿态词

- 自然站姿、轻微侧身、手扶杯子、整理头发、回眸、靠窗坐姿、肩颈舒展、手扶外套领口、走动回头、重心转移。
- 避免：挑逗姿态、夸张弯腰、强调隐私部位的镜头角度、让胸臀腿成为唯一焦点。

## 补充问题

- 是偏生活感、商业头像、胶片街拍，还是影视感？
- 需要锁定脸、发型、服装或场景参考图吗？
- 用于头像、封面还是全身穿搭展示？
