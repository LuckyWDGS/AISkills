# 图文故事版与动态首帧提示词

目标：把单张图片、九宫格、25 格广告故事版、穿搭故事版、图文故事版，扩展成连续、可执行、可生成的画面方案。适用于静图组图、社媒轮播、广告分镜、商品图文、穿搭合集、Live Photo、实况照片、短视频首帧和图生视频首帧。

核心原则：故事版不是把多个好看的图拼在一起，而是让每格承担一个功能。连续性靠锁定主体、服装、场景、色彩、镜头轴线、动作逻辑和前后帧关系。动起来时，不要只写“动态感”，要写清楚动作、镜头、环境动态、前后帧和循环安全。

## 0. 系统 Imagegen 导演分镜板默认流程

用户偏好：以后做剧本、动态壁纸、图生视频、分镜图，优先产出一张系统 Imagegen / image2 生成的专业导演分镜板，再配一份可复制的视频提示词。不要把本地程序绘制的表格示意图当作主交付物，除非只是内部规划或需要确定性文字。

### 默认三件套

1. 视觉锚点：原图、角色图、首帧图或用户参考图，负责锁定人物、脸、风格、色彩和画面质感。
2. 导演分镜板：用系统 Imagegen 生成，负责表达镜号、时间、连续缩略图、动作、运镜、光影、氛围和循环逻辑。
3. 图生视频提示词：只写参考图角色分工、主体锁定、动作节奏、连续性和禁忌，把每个镜号或时间段拆成可执行动作。视频尺寸、比例、总时长、平台用途等工具设置放在提示词外的“上传/参数建议”里，不在可复制提示词正文里重复。

如果平台是抖音，再追加标题、视频文案、评论引导、封面文字和标签。当前用户偏好是先只做抖音，除非用户重新要求其他平台。

### 交付格式：图片可保存，提示词可复制

用户偏好：以后给用户的图像/分镜/动态壁纸/Seedance 包，要同时给可保存的图片和可一键复制的提示词。

- 图片：最终本地图片必须用绝对路径 Markdown 图片标签嵌入回复，例如 `![图2 动作参考图](D:/.../motion-guide.png)`，并同时列出本地路径。
- 提示词：最终提示词必须放在一个 fenced `text` 代码块里，代码块内只放模型要读的提示词正文。
- 图号绑定：如果提示词引用上传图片，上传说明和提示词正文必须使用同一套 `图1/图2/图3` 编号。
- 文件：有完整交付包时，同时保存 `.txt` 和 `.md`，TXT 放纯提示词，MD 放上传说明、图片路径和复制代码块。
- 线程图：如果用户原图只在当前线程里，没有本地文件，明确说明“图1 是用户上传原图，本地未保存”，再展示本地生成的图2/图3。
- 多段系列视频：默认每段 10 秒，除非用户特别说明时长。交付要分成两层：人类审片层和视频模型上传层。人类审片层可以包含 图文镜头故事版、标题、时间段、镜头说明；视频模型上传层优先使用干净首帧、可选尾帧、无字动作参考。图文故事版默认不作为正式视频参考图上传。
- Doubao/Seedance 图生视频：把“给人看的图文故事版”和“给模型上传的参考图”分开。图文故事版默认只用于人工审片、节奏讨论和提示词绑定；正式上传优先用干净首帧、可选尾帧、无字动作参考。除非用户明确要测试污染，不要把带标题、时间码、分格、边框、路线图或说明文字的故事版作为正式视频参考图。
- 多图上传时，每张图只承担一个窄职责：图1锁主体/主视角/人物身份，图2锁动作参考或场景关系，图3锁尾帧或转场终点。不要让一张图同时承担人物、动作、场景、文字和版式。

### 系统 Imagegen 分镜板提示结构

```text
生成一张专业 AI 视频导演分镜图，画布为{横版/竖版/长图/指定故事版比例}，主题是“{主题}”。画面像一张完整的 storyboard sheet / director board，不是网页表格，不是简单卡片拼贴，而是统一的电影分镜设计稿。

整体布局：上方或左侧有 {6/9/10/25} 个连续分镜缩略图，每格编号清楚，展示同一主体在连续动作中的变化；下方或右侧是导演分镜表，包含镜号、时间、画面缩略图、景别、动作/运镜、光影/氛围、备注等栏位。文字可以作为简短导演标注，排版干净专业。

主体画面：{人物/产品/场景/风格/颜色/关键道具/情绪}。

分镜动作：{按镜号列出每格动作、镜头、光影变化和循环/承接关系}。

视觉要求：要像系统 Imagegen 生成的专业概念分镜板，缩略图有真实画面细节，分镜之间彼此连续，整体统一、有层次、可作为图生视频参考图。
```

### 图生视频提示词模板

上传/参数建议写在提示词外，例如：`尺寸/比例：按工具选择`、`总时长：按工具选择`、`参考图顺序：第1张原图，第2张分镜图`。不要把这些设置性文字重复进下面的可复制提示词，除非用户明确要求一段全量 prompt。

```text
第一张参考图是唯一的主体、构图、风格和画质锚点。严格保持原图主体不变：{身份、脸、发型、服装、构图、色彩、核心道具}。

如果同时上传了分镜图，分镜图只作为动作节奏和时间安排参考，只读取镜号、时间段、动效顺序、光影起伏、镜头/运镜和首尾循环关系。不要继承分镜图的表格、标题、边框、字幕、时间码、黑色版式或重画人物。最终视频画面里不要出现分镜板、文字、UI、九宫格、卡片或表格。

按照分镜图的 {镜号/时间段} 执行：
{0:00-0:01 / 镜头1} {动作、运镜、光影}
{0:01-0:02 / 镜头2} {动作、运镜、光影}
{继续写完}

整体动作节奏：{轻微/中等/强节奏}。镜头语言：{固定/慢推近/横移/环绕/一镜到底}。画面保持{风格、质感、色彩、情绪}，主体身份、服装、场景和镜头轴线稳定。
```

### Seedance / 豆包不一致时的修复流程

如果用户说“和提示词、图片动作都不对”，先做上传角色审计，而不是继续堆文字：

1. 判断入口：`首帧/尾帧`、普通图生视频、还是 `全能参考/多模态参考`。入口不明时，按最保守处理，只上传干净主角/首帧和无字动作参考。
2. 找误导图：视频像风景片、分镜板、标题卡、路线图、景观奇观时，通常是图文故事版或地图类参考权重过高。正式重试先移除这类图。
3. 重做动作参考：无字、近景、主体已经在做目标动作。动作必须发生在画面中心和前景，而不是只写在提示词里。
4. 重写前 1-2 秒：如果想要“游玩/畅游/触碰/互动”，第一秒就要出现伸手、拨水、抓取、推开、滑行、拍水花、碰撞等动作；不要先用三秒展示世界观。
5. 压缩成 3-4 个连续大节拍：设置、进入动作、动作升级、结尾转场。不要把 10 秒写成十个互相独立的硬切镜头。
6. 只在允许镜头切换时使用 `镜头1 / 镜头2 / 镜头3`；需要一镜到底时使用时间段并明确“同一空间、同一方向、不断镜”。

Seedance/Doubao 复制 prompt 的推荐结构：

```text
图1只负责：主体/主视角/身份/服装/固定道具。
图2只负责：无字动作参考/身体与物体互动方式。
图3只负责：尾帧或下一段转场终点，如没有就不上传。

本段目标：一句话说清主体正在做什么，不写营销空话。
连续性：一镜到底或明确镜头边界，主体、道具、空间方向稳定。
时间节拍：0-2s / 2-4s / 4-7s / 7-10s，每段都写主体动作 + 镜头运动 + 环境动态。
画面边界：不继承故事版文字、标题、边框、分格、UI、水印、logo、瓶身标签。
```

如果用户明确要求“图文分镜给 AI 看”，允许生成 AI-facing 图文动作板，但必须降低污染：

- 使用 16-25 格动作采样，不把它当 16-25 个剪辑镜头。
- 每格文字只写短标签：时间、动作动词、镜头/环境 cue，例如 `3.2-3.6s 左右划水｜泡沫卷边`。
- 不写长段说明、旁白、营销标题、剧情解释、表格大段文字。
- 在最终 prompt 中声明：只读取动作顺序和动作标签，不继承文字、编号、边框、分格、表格、UI。
- 同时保留一份纯文本 25 beat prompt，因为图中文字 OCR 不稳定，文本 prompt 才是动作指令的源头。

### 视频尺寸与提示词分离规则

- 视频尺寸、比例、总时长、分辨率、帧率、平台用途属于工具参数或上传说明，默认不要写进可复制的 Seedance/图生视频提示词正文。
- 如果分镜图标题或时间码已经表达节奏，提示词正文可以保留分段时间码来控制动作，但不要再加尺寸/时长/平台用途的包装句。
- 如果目标工具没有独立的尺寸/时长设置，或用户明确要“一键全量提示词”，才在提示词开头用一行简短设置说明，且不要在后文重复。
- 输出给用户时优先分成两块：`上传/参数建议` 和 `一键复制提示词`。代码块里只放模型需要理解的画面、动作、连续性和禁忌。
- 最终回复还要展示可保存图片：把本地生成的分镜图、动作参考图、首帧图或视觉卡片用绝对路径 Markdown 图片标签直接嵌入。

### 文字处理规则

系统 Imagegen 生成的中文小字可作为视觉质感，但不能默认当成最终准确文案。需要发布级文字时，先让 Imagegen 生成无字或少字的高级视觉分镜板，再用后期/PIL/排版步骤叠真实中文标签、时间码和导演说明。

## 1. 9 格图文故事版

9 格适合：小红书九宫格、抖音图文、旅行日记、穿搭合集、店铺探访、产品种草、活动回顾、情侣/朋友生活照。

### 推荐结构

1. 封面钩子：最大情绪、最大结果、最强场景或最强标题留白。
2. 主题总览：地点、路线、穿搭、商品或故事背景。
3. 人物/产品主图：清楚展示主体。
4. 细节 1：材质、表情、手部动作、包装、环境局部。
5. 细节 2：场景氛围、地标、桌面、街景、镜面、灯光。
6. 方法/步骤：搭配公式、路线顺序、使用步骤、拍照机位。
7. 对比/转折：before/after、好坏对比、白天夜晚、室内室外。
8. 可收藏信息：清单、地图、价格、参数、避坑、替代方案。
9. 情绪收尾：结果照、背影、合照、品牌记忆点、下一步行动。

### 每格要素

每一格都要写：

- 格号与功能：封面、总览、细节、步骤、对比、清单、收尾。
- 主体：人物、商品、场景或道具。
- 动作/状态：站、坐、走、拿、回头、开箱、整理、拍照。
- 构图：特写、半身、全身、俯拍、平视、低角度、左右分屏。
- 信息位置：是否需要标题留白、标签留白、编号区。
- 连续性：人物、服装、色彩、场景、道具是否沿用。
- 禁忌：不要文字乱码、不要水印、不要改变人物身份、不要遮挡主体。

### 9 格 prompt 模板

```text
生成 9 格图文故事版，主题是{主题}，平台用途是{抖音/小红书/TikTok/广告提案}。保持同一成人 25+ 主体、同一服装核心、同一色彩系统和真实生活方式摄影质感。每格为独立画面但视觉连续。

第 1 格：封面钩子，{第一眼情绪/结果/地标/标题留白}。
第 2 格：主题总览，{路线/清单/商品/场景总览}。
第 3 格：主体主图，{人物或产品清晰展示}。
第 4 格：细节 1，{材质/表情/手部/包装}。
第 5 格：细节 2，{环境/灯光/地标/桌面}。
第 6 格：方法步骤，{搭配/使用/机位/路线}。
第 7 格：对比转折，{before-after/好坏/白天夜晚}。
第 8 格：可收藏信息，{清单/价格/地图/避坑留白}。
第 9 格：情绪收尾，{结果照/背影/合照/品牌记忆点}。

输出：统一 4:5 或 1:1 画幅，干净留白给后期文字，不直接生成乱码文字，不生成水印或 logo。
```

## 2. 25 格广告故事版

25 格适合：广告提案、TVC 视觉板、商品种草分镜、品牌大片、短视频投放素材、首帧到结尾的完整视觉路线。25 格不要平均用力，要有节奏层级。

### 五段式结构

- 1-5 格：钩子与问题。让用户知道“为什么要看”。
- 6-10 格：场景与需求。展示人物生活状态、痛点、欲望或使用场景。
- 11-15 格：产品/方案出现。展示商品、服务、功能、质感和关键利益点。
- 16-20 格：结果与证明。展示使用后状态、对比、细节、社交反馈。
- 21-25 格：记忆点与转化。品牌氛围、购买理由、收藏理由、结尾情绪。

### 每格字段

```text
格号：
阶段：
画面功能：
主体：
动作：
镜头：
场景：
光线：
道具/产品：
画面文字策略：留白/后期加字/不加字
连续性锁定：
正向边界：
```

### 25 格广告 prompt 模板

```text
为{品牌/商品/服务}设计 25 格广告故事版，目标平台是{平台}，目标用户是{人群}，核心卖点是{卖点}。整体风格为{真实生活方式/高级商业摄影/胶片街拍/干净产品广告/电影感短片}。

连续性锁定：同一成人 25+ 主角，服装为{服装}，主色为{色彩}，产品外观保持一致，场景从{起点}到{终点}，光线从{光线变化}，镜头语言统一，不改变人物身份，不改变产品形态。

1-5 格：强钩子与痛点，分别表现{钩子列表}。
6-10 格：生活场景和需求，分别表现{需求列表}。
11-15 格：产品出现和核心功能，分别表现{功能列表}。
16-20 格：结果、细节、前后对比、使用证明，分别表现{证明列表}。
21-25 格：品牌记忆点、转化动机、收尾情绪，分别表现{收尾列表}。

每格画面都需要：主体、动作、镜头、场景、光线、道具、留白区。不要生成乱码文字、水印、logo；如需文案，保留后期排版空间。
```

## 3. 穿搭故事版

穿搭故事版要展示“为什么这样搭”和“怎么复刻”，而不是只展示漂亮照片。

### 推荐 9 格结构

1. 封面：成套穿搭完成图。
2. 版型：全身正面，比例清楚。
3. 上装细节：领口、袖口、材质、层次。
4. 下装细节：裤型/裙型、垂感、腰线。
5. 鞋包：鞋、包、配饰和色彩呼应。
6. 场景：通勤、约会、旅行、咖啡店、街拍。
7. 动态：走路、转身、坐下，展示真实上身效果。
8. 替换公式：同色系替换、冷暖天气替换、平价替换。
9. 收尾：镜前自拍或街头回头照。

### 穿搭连续性锁定

- 同一成人 25+ 模特。
- 同一脸部身份和发型，除非用户要求换发型。
- 核心服装不乱变：上衣、下装、鞋、包分别锁定。
- 色彩系统不乱跳：主色、辅助色、金属色、背景色。
- 场景有逻辑：家中试穿到出门街拍，或咖啡店到城市街头。
- 身材比例自然，不夸张拉腿，不儿童化，不露骨。

### 穿搭 prompt 模板

```text
9 格穿搭故事版，成人 25+ 模特，主题为{季节/风格/场景}。锁定同一人物、同一发型、同一核心穿搭：{上衣}、{下装}、{鞋}、{包}、{配饰}。真实街拍或小红书生活方式摄影，强调材质、版型、比例和可复刻性。

第 1 格成套封面，第 2 格全身比例，第 3 格上装细节，第 4 格下装细节，第 5 格鞋包配饰，第 6 格场景适配，第 7 格走动动态，第 8 格替换公式留白，第 9 格情绪收尾。画面保留标签和清单留白，不生成乱码文字。
```

## 4. 图文故事版

图文故事版需要区分两件事：图片里是否真的要生成文字。通常更稳的是生成干净画面和文字留白，再在后期用真实字体排版。

### 图文分层

- 画面层：人物、场景、产品、动作、构图、光线。
- 信息层：标题、编号、标签、清单、价格、路线、步骤。
- 排版层：文字放在哪、字号层级、是否贴纸、是否箭头。

如果用户明确要“带字图片”，要提醒模型生成文字可能不稳定；更推荐“图像留白 + 后期真实文字”。

### 图文 prompt 模板

```text
图文故事版，主题为{主题}，画面采用{平台}风格。每格画面有明确主体和信息留白：标题区在{位置}，标签区在{位置}，清单区在{位置}。请生成干净视觉画面，不直接生成文字，不生成乱码，不生成水印。后期文案为：{文案列表}。
```

## 5. 连续性锁定

连续性是故事版质量的核心。多格或动态图生成时，必须把“不变”和“变化”分开写。

### 不变项

- 人物身份：脸型、年龄感、发型、气质、肤色、身高比例。
- 服装：上衣、下装、鞋、包、配饰、颜色、材质。
- 产品：形状、包装、颜色、瓶身、 logo 处理方式。
- 场景：同一房间、同一街区、同一店铺、同一窗边座位。
- 色彩：主色、辅助色、整体冷暖。
- 摄影风格：手机感、胶片感、商业棚拍、电影感、动漫风。

### 变化项

- 动作：拿起、转身、走近、打开、试用、回头、坐下。
- 景别：远景、全身、中景、特写、俯拍、低角度。
- 情绪：好奇、犹豫、惊喜、自信、放松。
- 信息：每格展示不同卖点、步骤或细节。
- 光线时间：早晨、黄昏、夜晚，但要有过渡逻辑。

### 锁定模板

```text
连续性锁定：保持同一成人 25+ 主体，脸部身份、发型、服装、鞋包、产品外观、主色调、场景空间一致。每格只改变动作、镜头景别和信息重点。禁止改变人物年龄感、服装颜色、产品形状、场景位置和整体风格。
```

## 6. 从静图到 Live Photo / 实况照片

Live Photo 的关键不是大动作，而是“静中有一点动”。画面要像照片，但有 1-2 秒的轻微动态。

### 适合的动作

- 头发被风轻轻吹动。
- 咖啡杯热气上升。
- 人物轻微眨眼、微笑、回头。
- 衣摆轻轻摆动。
- 车窗外灯光滑过。
- 海浪、雨滴、树叶、霓虹反射轻微变化。

### Live Photo prompt 字段

```text
静态照片基础：{主体、场景、构图、光线}
轻微动作：{头发/衣摆/手部/表情}
环境动态：{风/雨/热气/车灯/海浪/树叶}
镜头：固定镜头或极轻微推近
循环安全：动作幅度小，可自然循环，首尾帧相似
连续性：镜头轴线稳定，人物身份、服装、场景和画面风格保持一致
```

### Live Photo 示例

```text
一张小红书咖啡店生活照，成人 25+ 女生坐在窗边，手握冰美式，暖白色室内灯和窗外街景反光，4:5 构图，真实自然皮肤质感。动态只包括：头发被空调风轻轻吹动，杯中冰块微微晃动，窗外行人虚化慢慢经过。镜头固定，动作幅度很小，首尾帧几乎一致，可自然循环。人物脸和服装稳定，画面保持干净，文字留给后期排版。
```

## 7. 从静图到短视频首帧

短视频首帧要同时满足两个目标：第一帧能停留，后续动作能顺利开始。不要只追求封面美感，导致视频工具无法动起来。

### 首帧要写清

- 主体姿势是否能接动作：站立、侧身、回头前一刻、手刚碰到产品。
- 镜头路线：推近、拉远、横移、环绕、跟拍、固定。
- 动作方向：向镜头走来、从左到右、抬手、转身、打开门。
- 环境动态：风、雨、灯光、烟雾、水面、人群、车流。
- 下一帧承接：人物下一步做什么。

### 首帧 prompt 模板

```text
短视频首帧，画面第一眼有{钩子}。主体是{主体}，处在{动作开始前一刻}，下一秒将{动作}。镜头计划为{推近/横移/跟拍/固定/环绕}，环境动态为{风/雨/灯光/人群/水面}。构图给后续动作留出方向空间，主体不贴边，关键物体清晰，适合图生视频。禁止跳切、换场景、换服装、变脸、突然改变镜头轴线。
```

### 示例：奶茶店首帧

```text
短视频首帧，成人 25+ 女生站在奶茶店柜台前，刚接过奶茶的一瞬间，脸上有惊喜微笑，下一秒会把奶茶举到镜头前。镜头从中景轻微推近，柜台灯牌和菜单在背景虚化，店员手部刚离开杯子，杯身和包装清晰，9:16 竖图，真实手机拍摄感。环境动态包括杯中冰块轻晃、背景人群轻微移动、灯牌微弱闪烁。不要跳切，不要改变人物脸、服装、店铺场景，不要生成文字水印。
```

## 8. 动起来的提示字段

动态 prompt 需要把动势拆成可控字段。

### 动作

写具体动词，不写空泛动感。

- 走近镜头、回头看镜头、抬手整理头发、打开包装、拿起杯子、转身展示裙摆、坐到沙发、推开门。

### 镜头

镜头动作要和主体动作匹配。

- 固定镜头：适合 Live Photo、产品细节、轻微动作。
- 慢推近：适合人物情绪、商品开箱、封面转视频。
- 横移跟拍：适合街拍、穿搭走路、旅行。
- 轻微环绕：适合产品质感、人物造型，但容易变形，要谨慎。
- 拉远：适合揭示场景、地标、房间改造。

### 环境动态

环境动态让画面活起来，不需要主体做大动作。

- 风吹头发和衣摆。
- 咖啡热气、奶茶冰块、便利店灯光。
- 雨滴、车流、霓虹反射。
- 海浪、树叶、窗帘、云影。
- 人群和背景车辆轻微移动。

### 前后帧

写清开始帧和结束帧，可以减少跳变。

```text
开始帧：人物侧身站在窗边，手刚碰到咖啡杯。
结束帧：人物轻轻拿起杯子看向镜头，身体位置不大幅移动，背景和服装保持一致。
```

### 循环安全

适合做循环的动态要首尾相似。

```text
循环安全：动作幅度小，首尾姿势接近，头发、衣摆、灯光和热气做细微周期变化，不出现明显开始或结束动作。
```

### 不要跳切

```text
不要跳切，不要突然换镜头，不要改变人物身份，不要换服装，不要切到其他场景，不要突然出现新人物，不要大幅改变产品形状，不要文字水印。
```

## 9. 静图到动态图完整模板

```text
基础画面：{主体、年龄边界、服装、场景、构图、光线、风格}
用途：{Live Photo/实况照片/短视频首帧/图生视频}
动作：{主体具体动作，幅度大小}
镜头：{固定/推近/横移/跟拍/拉远/轻微环绕}
环境动态：{风/雨/灯光/热气/车流/海浪/人群}
开始帧：{第一帧姿势和画面状态}
结束帧：{最后帧姿势和画面状态}
连续性锁定：{人物、服装、产品、场景、色彩、镜头轴线}
循环安全：{是否可循环，首尾是否相似}
正向边界：{镜头连续、身份稳定、服装稳定、场景稳定、文字留白、手部和肢体自然}
```

## 10. 质量检查

生成前检查：

- 每格是否有明确功能？
- 9 格或 25 格是否有节奏，而不是平均展示？
- 是否锁定人物、服装、产品、场景和色彩？
- 是否说明文字是后期排版还是图片内生成？
- 如果是剧本、动态壁纸或图生视频交付，是否优先提供了系统 Imagegen 生成的导演分镜板，而不是本地表格示意图？
- 是否在最终回复中嵌入了可保存的本地图片预览，并提供了一键复制的 fenced `text` 提示词？
- 动态是否包含动作、镜头、环境动态、开始帧、结束帧？
- 是否写了循环安全和不要跳切？
- 可复制图生视频提示词是否剥离了尺寸、比例、分辨率、平台包装和总时长等工具设置，只在外部说明或故事版元信息里出现？
- 成人主体是否默认 25+、非露骨、非裸体、非性行为？
- 是否避免让模型把标题压在脸、产品或关键动作上？
