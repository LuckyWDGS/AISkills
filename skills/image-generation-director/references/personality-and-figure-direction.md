# 性格与身材导演规则

用途：修正过度一刀切的安全规则。目标不是把人像全部压成“端庄保守”，也不是为了安全主动删掉用户想要的效果词，而是在成人 25+、非露骨、非色情边界内，明确表现人物性格、身材优势、时尚吸引力和社媒第一眼记忆点。

网络参考启发：

- PhotoWorkout 全身人像指南提到 S 曲线、重心转移、走动、手部动作和服装合身度会影响全身姿态与身材呈现：`https://www.photoworkout.com/make-full-body-portraits/`
- PhotographyIcon 的人像摄影指南强调用构图把视线导向脸部和表情，并让画面有平衡和意图：`https://photographyicon.com/portrait-photography/`
- SeeHer + Getty Images 的包容性视觉叙事指南强调多样身材、肤色、年龄与气质；表达“好身材”不应只有一种瘦或幼态模板：`https://www.seeher.com/wp-content/uploads/2020/12/SeeHer-Getty-Images-Inclusive-Storytelling-Guide-V2.pdf`

## 哪些规则不能一刀切

### 1. “穿搭完整/不透明”不是“全身包严”

保留硬边界：

- 关键部位必须覆盖。
- 不出现露点、性器官、走光。
- 不用透明/湿透衣物强调隐私部位。

放宽表达：

- 可以有露肩、露锁骨、优雅 V 领、方领、吊带外搭、露背、侧腰剪裁、高开衩长裙、一件式泳装、外搭罩衫。
- 可以有薄纱、蕾丝、缎面、网纱外层，但关键部位需要内衬、胸贴/内搭、或不透明结构。
- 可以写合身、修身、贴合身体线条，但不要写挤压、拉扯、走光。

安全表达：

```text
服装有适度露肤：露肩与锁骨、优雅 V 领、腰线清晰，关键部位完整覆盖，面料不透明或有内衬，整体是时尚编辑感而非露骨。
```

### 2. “性感”不必全部改成“端庄”

保留硬边界：不能色情化、不能性行为、不能挑逗姿势、不能身体部位凝视。

放宽表达：

- `性感` 可以保留为效果词，并补成：成熟性感、有吸引力、镜头感强、身材曲线明确、气场自信、时尚张力、轻微危险感、夜色电影感。
- `私房` 可以保留为风格词，并补成：成人 25+ 私房风写真、亲密空间、柔和光线、安静自信、生活方式写真、慵懒但克制。
- `男士向/女士向` 不按刻板性别写；按平台、审美、内容目的拆成风格配置。

安全表达：

```text
成熟有吸引力，镜头感强，曲线明确但不露骨，姿态自信克制，画面重点是脸部情绪、服装剪裁、光线和整体气质。
```

### 3. “身材好”不是只有一种体型

不要默认瘦、幼、白、细。可以按用户意图选择：

- 纤细高挑：长线条、直筒剪裁、冷感时装。
- 健康紧致：运动感、肩背线条、核心力量、阳光户外。
- 丰润曲线：胸腰臀比例、柔和肩颈、成熟自信、度假/礼服/复古写真。
- 高级松弛：自然体态、不过度修瘦、真实皮肤、生活方式摄影。
- 女王气场：挺拔站姿、强眼神、结构感外套、高跟鞋/长靴。

Prompt 写法：

```text
身材类型：健康丰润、曲线明确、腰线清晰，体态自信；不夸张修瘦，不儿童化，真实成年人比例。
```

### 4. “避免特写”不是不能拍细节

可以拍：

- 面料、领口剪裁、腰封、鞋履、袜类材质、首饰、手拿道具、发丝、眼神。
- 上半身肖像、三分之二身、全身穿搭、环境人像。

不要拍：

- 胸部/臀部/裆部孤立特写。
- 镜头从隐私/窥视角度拍。
- 让构图只服务身体部位。

安全表达：

```text
三分之二身构图，脸部和眼神清晰，服装剪裁和腰线可见，胸部轮廓是整体穿搭比例的一部分，不做局部特写。
```

## 性格模块

把“美女”改成可导演的人设。每次至少选 1 个性格核心 + 1 个姿态 + 1 个场景关系。

### 温柔松弛

```text
性格：温柔、松弛、亲近，表情自然，眼神柔和。
姿态：坐在窗边、手扶咖啡杯、轻轻整理头发。
场景：咖啡馆、卧室窗边、书店、清晨厨房。
```

### 自信成熟

```text
性格：自信、成熟、镜头感强，有明确气场。
姿态：轻微侧身站立、肩颈舒展、手扶外套或腰线。
场景：酒店窗边、城市夜景、商业棚拍、复古室内。
```

### 甜酷街头

```text
性格：甜酷、独立、带一点叛逆但不低俗。
姿态：回头看镜头、走过斑马线、手插口袋、拎头盔。
场景：便利店霓虹、东京街角、地铁口、涂鸦墙。
```

### 文艺清冷

```text
性格：安静、清冷、有故事感。
姿态：低头看书、侧脸看窗外、手拿胶片相机。
场景：图书馆、旧书店、雨天街角、美术馆。
```

### 明亮活力

```text
性格：明亮、健康、行动感强。
姿态：慢跑后回头、海边扶帽、旅行到达时拖行李箱。
场景：海边黄昏、城市晨光、机场/车站、运动场。
```

### 女王气场

```text
性格：冷静、强势、精致、有掌控感。
姿态：正面站姿、下巴微收、眼神坚定、手扶西装领。
场景：极简影棚、高级酒店走廊、城市天台、黑白肖像。
```

## 身材模块

### 曲线成熟

```text
身材：曲线明确，胸腰臀比例自然，腰线清晰，健康丰润。
服装：合身针织连衣裙、修身长裙、结构感西装裙、端庄 V 领礼服。
边界：关键部位完整覆盖，不透明或有内衬，不做胸部/臀部局部特写。
```

### 健康运动

```text
身材：健康紧致，肩背线条清晰，体态挺拔，有活力。
服装：运动外套、瑜伽裤、跑步套装、短款运动夹克。
边界：动作是热身、慢跑、拉伸，不做性化姿势或身体部位凝视。
```

### 高挑时装

```text
身材：高挑、比例清楚、腿部线条作为穿搭比例的一部分。
服装：长风衣、高腰长裤、半身裙、长靴、连裤袜。
边界：全身构图，展示鞋袜与服装比例，不做腿部恋物化特写。
```

### 丰润度假

```text
身材：自然丰润，健康自信，度假感。
服装：一件式泳装、外搭衬衫、罩衫、宽檐帽。
边界：泳装是时尚/度假语境，非露骨，不做胸臀局部特写。
```

## 组合公式

```text
成人 25+ {主体}，性格是{性格模块}，身材表达为{身材模块}。穿{服装}，服装{关键部位覆盖/有内衬/剪裁合身/适度露肤}。她在{场景}中{动作}，表情{情绪}。构图为{全身/三分之二身/半身/环境人像}，镜头{50mm/85mm/长焦压缩/手机真实感}，光线{窗光/逆光/霓虹/棚拍柔光}，风格{时尚杂志/生活方式/电影感/胶片街拍}。画面重点是性格、气质、服装剪裁、身材比例和整体构图，不做身体部位特写，非露骨。
```

```text
成人 25+ 女性，性格自信成熟，镜头感强，身材曲线明确，腰线清晰，健康丰润。她穿深酒红色合身针织连衣裙，优雅方领，关键部位完整覆盖，面料不透明，剪裁呈现自然胸部轮廓和整体比例。她站在高级酒店窗边，轻微侧身，手扶外套领口，肩颈舒展，眼神坚定看向镜头。三分之二身构图，85mm 人像镜头，柔和窗光和暖色室内灯，真实皮肤质感，高级时尚杂志摄影。画面重点是性格、气质、服装剪裁、身材比例和光线，不做胸部或臀部局部特写，非露骨，4:5 竖图。
```

```text
成人 25+ 女性，甜酷街头气质，独立、自信、带一点叛逆感。身材比例优秀，腿部线条和腰线清晰。她穿短款机车夹克、合身内搭、高腰直筒裤和短靴，内搭不透明，整体适度露腰但不露骨。她在夜晚便利店霓虹灯外回头看镜头，一只手插口袋，一只手拿无品牌冰饮。全身环境人像，35mm 胶片街拍，湿地反光，粉蓝霓虹，真实抓拍感。画面重点是街头性格、穿搭比例、表情和环境氛围，不做身体部位特写。
```

## 快速质检

- 性格是否明确，不只是“漂亮”？
- 身材是否通过服装、姿态、镜头和整体比例表达？
- 是否允许了合理露肩、领口、腰线、开衩或泳装，而不是全部禁止？
- 是否守住关键部位覆盖、非露点、非性行为、非身体部位凝视？
- 是否避免把“男士喜欢/女士喜欢”写成刻板或低俗？
