# 身材突出与适度露肤边界

用途：当用户希望“身材好一点”“胸部可以突出”“曲线明显”“适当露肤”“更有吸引力”时使用。目标是成人 25+ 的时尚、写真、商业、度假或角色视觉，不是露骨色情。

## 核心原则

- 主体必须是成人 25+，视觉上也不能儿童化。
- 可以突出身材，但必须通过服装剪裁、姿态、镜头、光线、整体造型来表达。
- 胸部、腰臀、腿部可以作为穿搭比例的一部分；不能成为单独的身体部位特写或低俗凝视。
- 保持关键部位覆盖；可以有露肩、锁骨、优雅领口、露背、适度露腰、高开衩长裙、一件式泳装、薄纱/蕾丝外层，但关键部位需要不透明面料、内衬或明确遮挡。
- 不写露点、性器官、走光、透明湿身、性行为或明显挑逗姿势。
- 输出语言要偏“时尚杂志、商业摄影、健康自信、成熟优雅”，避免“诱惑、福利、挑逗、擦边、越少越好”。

## 可以写的表达

### 身材与曲线

```text
身材曲线优美，比例优秀，健康丰润，腰线清晰，肩颈线条优雅，体态自信，成熟有魅力。
```

### 胸部与上身

```text
合身上装突出自然胸部轮廓，优雅领口，胸线作为服装剪裁的一部分，上半身比例清晰，画面重点仍是脸部、气质、穿搭和光线。
```

### 服装

```text
合身针织上衣、修身连衣裙、高腰半身裙、端庄 V 领礼服、方领上衣、露肩针织、露背长裙、剪裁清晰的西装裙、缎面家居服、吊带外搭西装、一件式泳装、外搭衬衫或罩衫。
```

### 姿态

```text
自然站姿，轻微侧身，自信回眸，手扶帽檐，整理外套，坐在扶手椅上，肩颈舒展，体态挺拔。
```

### 摄影语言

```text
时尚杂志摄影，商业写真，生活方式人像，度假编辑大片，优雅私房肖像，柔和窗光，浅景深，真实皮肤质感，成熟克制。
```

## 不写的表达

- 胸部/臀部/腿部单独特写。
- 露点、性器官、走光、透明衣物、湿透衣物强调隐私部位。
- 过度低胸、刻意挤压胸部、拉扯衣物、舔咬、床上挑逗、跪趴等明显性暗示姿势。
- 未成年人、学生制服性感化、JK/萝莉/儿童化脸型和身材。
- 偷拍、窥视、醉酒、胁迫、非自愿场景。

## Prompt 模板：成熟曲线写真

```text
一位成人 25+ 女性，成熟自信，身材曲线优美，穿合身深色针织连衣裙，优雅方领，剪裁突出自然胸部轮廓、腰线和整体比例，关键部位完整覆盖，面料不透明。她站在城市酒店窗边，轻微侧身看向镜头，姿态端庄自然，肩颈舒展。柔和窗光与暖色室内灯混合，85mm 人像镜头，浅景深，真实肤色和皮肤纹理，高级时尚杂志摄影，画面重点是性格、气质、穿搭、光线和整体构图，非露骨，4:5 竖图。
```

## 质检标准

- 是否明确成人 25+？
- 是否通过服装剪裁和姿态表现身材，而不是身体部位凝视？
- 胸部突出是否仍有关键部位覆盖、内衬或不透明结构？
- 画面是否还有脸、气质、穿搭、光线、场景，而不是只剩身体？
- 是否用正向边界写明成人成熟形象、覆盖结构、整体构图和时尚语境？
