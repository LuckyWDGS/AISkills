# 人物三视图与面部同图标准

版本：1.0 · 2026-09-14 · 后续人物身份板规则

## 适用条件

仅当当前任务需要制作或修订**人物全身三视图、人物转面图，或含三视图的身份设定板**时启用，包括项目规则已要求给新增身份关键角色制作三视图的情况。单张头像、普通人物写真、单幅角色立绘、仅服装/道具细节、车辆三视图、环境图和无人视频不因此增加三视图或面部区。《十二星座庇护所》当前无人环境图不启用此规则。

本标准约束后续新建和主动修订的三视图；不回溯重生成全部旧资产，不撤销既有确认状态。仅在后续镜头实际缺少脸部信息时，补该角色所需的身份细节，并按项目原有流程登记候选与确认状态。

## 一张图内的必要内容

- 同一张人审设定图内保留同一角色的**中性全身正面、严格90度侧面、背面**，并增加一个**足够大的头肩面容近景区**。这是一个人的四种展示，不是四个人同处一个场景。
- 三张全身图均从头顶到鞋底完整可见，头脚不裁切，身高、头身比和展示比例一致；中性站姿、双臂略离身体，侧面不以四分之三角度替代，背面不扭头露脸。
- 面部区优先中性正面或轻微侧转的头肩近景，五官、双眼、眉形、鼻口轮廓清晰；面容不被手、发丝或饰品遮挡，不用夸张表情、浓重阴影或特效掩盖身份。保留发际线、发型轮廓与服装领口，便于对照。
- 四个展示中的脸型、年龄感、发型、发色、肤色、妆容、配饰和领口必须对应，面部近景不能独立“美化”成另一个人。
- 面部区是主要审查区之一，不是全身小脸的微小裁切或模糊放大。布局起点可用三张全身图并排、旁侧独立大幅头肩区；建议近景脸高约为全身视图中头部的2–3倍，最终以实际输出尺寸能检查五官与眼睛为准，这不是像素阈值。空间不足时扩大画布或移出可选色卡/装饰/英雄立绘，不牺牲三张全身完整性或面部可读性。
- “面容写真”表示近距离、可辨认的面容展示，不指定真人摄影。2D、动漫、绘本、游戏概念、风格化3D均沿用项目已锁画风、比例和材质；只有项目本来选择真人写实时才使用摄影语言。

## 人审板与正式视频输入

同图板用于核对身份、衣装和跨视角一致性。正式视频输入另选或导出**干净单人全身图**；近景身份确有需要时，再另导出**干净面部裁图**，去掉其它视角、网格、标签、边框及无关背景。不要把整张多视角板作为默认视频输入或主空间锚点，也不要在单视图导出提示词中要求再画四个视角。

全身图负责体态/服装，面部图负责脸部身份；按本次镜头选择最小参考集合，已有清晰身份锚点时不机械再加一张脸。四个展示共用一个角色身份，不能增加剧情人数。裁图没有新增细节时不可声称已修复脸部，需用已确认身份源补清晰候选后重新核对。

## 可复用生图提示词模块（仅用于三视图人审板）

```text
一张同一角色的身份设定图，沿用已锁定的[项目画风]。图内并列完整的中性全身正面、严格90度侧面、背面，三图从头顶到鞋底完整可见，身高与头身比例一致；同图另设一个独立大幅头肩面容近景区，中性正面或轻微侧转，五官和双眼清晰，发际线、发型轮廓与服装领口可见，面容自然无遮挡。面部区足够大，可直接检查眉眼鼻口，不以全身小脸裁切放大代替细节。四个展示均属于同一角色，脸型、年龄感、发型发色、肤色、妆容、衣装领口与配饰一致。三张全身与面部区都有充分空间，干净中性背景与均匀光线，保持原画风的线条、材质和人物比例。
```

此模块不用于普通头像、单视图导出或视频正文。具体身份与服装沿用项目真源；参数、文件路径和上传映射仍放在复制区外。规则不改变既有模型路由、图片生成授权、视频自动化暂停状态或平台模式。

## 验收

1. 请求是否真的需要人物三视图？若否，不启用同图加脸。
2. 同一输出图内是否同时有三张完整等比例全身及独立大面部区？只交三个全身加另一个脸文件，不算同图交付。
3. 严格侧面、完整头脚、面部实际可读性和四区身份/衣装一致性是否都通过？仅有字段或提示词不等于图像通过。
4. 是否保持原画风，并区分人审板、干净全身和面部输入？视频人数是否仍按本段角色表确定？
5. 本次只改文字规则时，应报告文本与路由检查，不声称已实测生图或视频。
