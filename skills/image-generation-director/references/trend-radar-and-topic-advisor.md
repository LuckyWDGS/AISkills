# 实时热点雷达与选题导演

用途：当用户说“我不知道发什么”“抖音现在什么流量高”“帮我推荐话题”“大众喜欢什么图”“给我做吸引流量的内容”时，`image-generation-director` 要像内容导演，而不是只给泛泛灵感。

核心边界：不要把稳定经验当实时热点。任何“现在最火”“今天热门”“流量高”都需要先查当前平台、榜单、搜索结果或用户给的截图/链接。查不到实时数据时，明确说明只能基于稳定平台规律给方向。

- 小红书蒲公英：`https://pgy.xiaohongshu.com/`

使用方式：

- 能浏览时：先打开/搜索这些入口，记录时间、平台、地区、榜单类型、热词、内容类型、共性视觉。
- 不能浏览时：让用户发平台截图、竞品链接、账号主页、收藏图、搜索词页面。
- 不要只看标题：还要看封面图、评论焦点、收藏理由、用户痛点、可复刻性。

## 2. 选题导演流程

### Step 1：确认场景

只问最关键的 1-3 个问题：

```text
你要发哪个平台：抖音、小红书、TikTok，还是电商图？
账号方向是：写真/穿搭/旅行/饮品探店/动漫角色/商品广告/故事版？
你想要单张封面、9 宫格图文，还是能动起来的视频首帧？
```

如果用户懒得回答，默认：

```text
默认按抖音 + 小红书通用图文做：9:16 封面一张 + 4:5 小红书封面一张 + 9 宫格扩展思路，成人 25+，非露骨，真实生活方式摄影。
```

### Step 2：扫热点

观察每个候选热点的 6 个信号：

- 热度：榜单排名、平台推荐、搜索建议、近期讨论量。
- 视觉性：能否一眼看懂，是否有明确画面符号。
- 可复制：普通人能否照着拍或生成。
- 差异化：是否能换场景、换人设、换道具做出新鲜感。
- 安全性：是否避开未成年性化、露骨、侵权、虚假功效。
- 转化性：是否能引导关注、收藏、转发、购买或评论。

### Step 3：给导演判断

输出不要只有“热点列表”，要给选择理由：

```text
我建议优先做 A，不是因为它最热，而是因为它同时满足：第一眼画面强、容易生成、能做系列、适合你的账号。
B 适合做跟热点但需要更多素材。
C 流量可能高，但风险是同质化/文字依赖/需要真人参考。
```

### Step 4：转成执行包

每个推荐话题给：

- 封面钩子：用户第一眼看到什么。
- 画面结构：主体、场景、动作、道具、留白。
- 标题方向：后期加字，不让模型生成乱码。
- 9 宫格扩展：如果要图文系列。
- 动态化：如果要 Live Photo/短视频首帧。
- prompt：可以直接生成。
- 正向边界：安全、质量、文字、版权与 logo 处理。

## 3. 话题评分表

用 1-5 分快速判断：

```text
话题：
平台：
热度证据：
视觉钩子：
可生成性：
系列化潜力：
差异化空间：
安全风险：
商业/关注转化：
总评：
建议动作：立即做 / 需要参考图 / 先做封面测试 / 放弃
```

优先级：

- `立即做`：热度高、画面强、低风险、能快速生成。
- `先做封面测试`：热度不错，但需要测试标题或构图。
- `需要参考图`：身份、穿搭、产品、店铺、城市地标需要锁定。
- `放弃`：侵权高、露骨擦边、未成年风险、纯靠文字梗、视觉弱。

## 4. 大众喜欢的稳定视觉方向

这些不是实时热点，而是长期稳定偏好：

### 真实现场感

用户更愿意停留在“像真的发生过”的图上：

- 奶茶店递饮品、咖啡馆窗边、便利店夜景、地铁口、机场到达、酒店窗景。
- 手机拍摄感、轻微动态、真实光线、不是完美棚拍。

Prompt 钩子：

```text
真实现场感，像朋友刚拍下的一瞬间，人物动作正在发生，背景有具体生活细节，手机摄影质感，画面干净但不僵硬
```

### 强情绪瞬间

- 刚到目的地的兴奋。
- 下班后便利店的松弛。
- 穿搭完成后的自信。
- 朋友/情侣/家庭生活里的温暖时刻。

Prompt 钩子：

```text
人物有明确情绪：刚到目的地的惊喜、下班后的松弛、换装后的自信、发现美食的一瞬间；表情自然，不夸张摆拍
```

### 可收藏信息感

小红书和图文平台尤其吃这套：

- 穿搭公式、旅行路线、拍照机位、咖啡店清单、便利店好物、饮品配方、学习笔记。
- 画面要有留白、编号区、贴纸区，但文字最好后期加。

Prompt 钩子：

```text
保留标题区、编号区和小标签留白，画面像可收藏笔记，物件摆放有秩序，后期可加清单文字，不直接生成乱码
```

### 审美奇观

- 微型旅行世界、星河 3D CG、海城机甲关键视觉、剪纸 Q 版立体模型、Y2K 拼贴海报。
- 适合吸睛，但要避免复杂到不可控。

Prompt 钩子：

```text
第一眼是一个强视觉奇观，但画面层级清楚：主体明确、背景服务叙事、色彩系统统一、没有杂乱文字
```

### 系列化

单张图容易被刷走，系列更容易收藏：

- 9 宫格旅行日记。
- 9 格穿搭故事版。
- 8/9 格制作过程故事板。
- 25 格广告提案。
- 同一角色的头像、全身、动作、海报、动态首帧。

Prompt 钩子：

```text
生成可系列化的视觉方案：封面、总览、细节、步骤、对比、清单、情绪收尾，每张图保持同一人物/产品/色彩系统
```

## 6. 当用户不知道发什么：默认推荐菜单

按优先级给用户 8 个方向，不要一上来只问问题：

1. `奶茶店现场人像`：好做、真实、容易动起来，适合抖音/小红书。
2. `城市夜晚便利店封面`：强氛围、适合写真和短视频首帧。
3. `旅行日记九宫格`：收藏感强，可做城市系列。
4. `穿搭故事版`：可持续更新，适合女装/男装/配饰/鞋包。
5. `Y2K 街头拼贴海报`：第一眼强，适合潮流账号。
6. `饮品剪贴簿海报`：适合探店、饮品、甜品、品牌。
7. `微型世界旅行海报`：奇观强，适合壁纸和城市主题。
8. `原创动漫女主动态首帧`：适合角色账号、短视频、壁纸。

默认输出格式：

```text
我建议先做这 3 个：
1. [方向]：为什么适合你，第一眼钩子是什么。
2. [方向]：为什么适合你，第一眼钩子是什么。
3. [方向]：为什么适合你，第一眼钩子是什么。

我会优先执行第 1 个，默认画幅 [x]，风格 [x]，安全边界 [x]。如果你不改，我直接生成 prompt/图片。
```

## 7. 平台打法速配

### 抖音

适合：

- 9:16 强封面。
- 真实现场感人物。
- 到达/发现/递给镜头/回头/变装/前后对比。
- 可动起来的首帧。

不适合：

- 纯静物且无结果。
- 过多小字。
- 主体不明确。

### 小红书

适合：

- 4:5 封面。
- 九宫格、清单、攻略、穿搭公式、探店手账。
- 可收藏信息密度。

不适合：

- 只有漂亮但没信息点。
- 标题空间不清晰。
- 太像硬广。

### TikTok

适合：

- 强对比、强动势、跨文化易懂的视觉。
- Before/After、POV、photo dump、travel carousel。
- 标题短、画面干净、情绪明确。

不适合：

- 过度依赖中文梗。
- 场景符号不清楚。
- 画面太细碎。

## 8. 导演式回复模板

当用户问“发什么有流量”：

```text
我先按平台导演思路判断：你现在最适合做 [方向A]，因为它有 [热点/稳定需求] + [强视觉钩子] + [可系列化]。我会把它拆成：1 张 9:16 抖音封面、1 张 4:5 小红书封面、9 宫格扩展和一个 Live Photo 动态首帧。

如果要实时追热点，我需要先查 [平台/榜单/搜索词]，或你发 3 张参考截图。我不会把过期趋势当今天的热门。
```

当查到实时热点后：

```text
我看到当前热点集中在：[热词1/热词2/热词3]。其中最适合生图的是 [热词]，因为它有明确视觉符号 [x]，能落成 [封面/九宫格/故事版]。我建议不要照搬热点标题，而是换成你的账号语境：[改写方向]。
```

## 9. 风险清单

- 不把平台热榜直接等同于适合用户账号。
- 不推荐露骨擦边、未成年感、偷拍感或校园性化内容。
- 不使用真实品牌 logo、明星脸、具体 IP 角色名做生成提示。
- 不让模型生成大段标题、菜单、票据、证件编号；需要文字时建议后期真实排版。
- 不承诺“必爆”“必火”；只给基于趋势、视觉强度和可执行性的导演判断。
