# 目标审美配置

用途：把“想给谁看”转成风格参数。不要把受众偏好写成绝对规则，按项目调性微调；也不要把“男士喜欢/女士喜欢”简单等同于露骨或保守。

## 女士目标审美

常见偏好：

- 干净、真实、松弛，有性格，不油腻。
- 穿搭有质感，妆发自然；可以适度露肩、锁骨、腰线或优雅领口，但关键部位覆盖。
- 姿态自信，情绪稳定；可以有成熟吸引力，但不廉价、不身体凝视。
- 色彩高级：低饱和、暖中性、胶片感、自然肤色。

可用词：

```text
成熟优雅，生活方式杂志感，真实肤色，干净妆发，质感穿搭，松弛自信，自然姿态，性格清晰，克制的电影感
```

## 男士目标审美

常见偏好：

- 主体明确，第一眼有吸引力。
- 轮廓、光影、服装比例清楚。
- 可以更强调镜头感、曲线、第一眼吸引力，但仍保持非露骨和完整语境。
- 画面干净，情绪直接，风格有记忆点。

可用词：

```text
成熟有魅力，镜头感强，轮廓清晰，穿搭比例好，曲线明确但不露骨，柔和但有冲击力，时尚大片感，亲近而克制
```

## 按性格而不是性别选风格

- `温柔松弛`：窗光、咖啡、低饱和、自然微笑、柔软针织。
- `自信成熟`：酒店窗边、合身长裙、腰线清晰、强眼神、85mm 人像。
- `甜酷街头`：便利店霓虹、机车夹克、短靴、回头动作、胶片颗粒。
- `文艺清冷`：旧书店、美术馆、雨天街角、侧脸、胶片相机。
- `明亮活力`：旅行到达、海边黄昏、运动后微笑、风吹发丝。
- `女王气场`：结构感西装、极简影棚、正面站姿、坚定眼神。

## 中性商业审美

适合头像、品牌、商品、平台展示：

```text
专业可信，亲和自然，背景干净，光线均匀，色彩准确，构图稳定，少修饰，高级真实
```

## 避免误区

- 不把“男士向”写成露骨、挑逗、身体凝视；可写镜头感强、曲线明确、成熟吸引力。
- 不把“女士向”写成单一温柔或过度滤镜；可写清冷、强势、甜酷、健康、复古、野性、精致。
- 不为了吸睛牺牲品牌安全、年龄边界和关键部位覆盖。

## 快速选择

- 社媒封面：视觉记忆点 + 安全边界。
- 电商穿搭：材质、比例、产品可见度。
- 头像：五官清晰、背景简洁、可信。
- 私房氛围：成熟、克制、柔光、关键部位覆盖、可适度露肩/锁骨/腰线。
