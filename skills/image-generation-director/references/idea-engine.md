# 灵感引擎

目标：当用户说“我不知道生成什么”“给我点灵感”“随便做几张好看的”“帮我想方向”时，Codex 不要只反问。先主动给可选方向，再问最关键的问题；如果用户不想回答，就用安全、通用、可执行的默认假设直接生成 prompt 或图片。

执行原则：

- 先给 3 个可选概念，让用户能快速选。
- 每类只追问会显著改变画面的信息：用途、主体、画幅、风格、参考图、边界。
- 用户懒得选时，采用默认假设继续，不让流程卡住。
- 成人人像默认 `成人 25+、非露骨、非裸体、非性行为、非未成年感`。
- 如果用户问实时热门、当前流量高、今天抖音/小红书/TikTok 爆款，需要先查当前平台或让用户给参考图，再把趋势转成 prompt。

## 1. 头像

### 3 个可选概念

1. 电影感职业头像：干净背景、自然窗光、成熟可信、适合社交账号和商业主页。
2. 城市夜景头像：霓虹、玻璃反光、浅景深，适合更有氛围的个人 IP。
3. 插画感头像：柔和手绘、清晰轮廓、干净色块，适合内容账号或品牌人格。

### 需要追问的问题

- 头像用于哪里：微信、抖音、小红书、LinkedIn、B 站、品牌账号？
- 要真人摄影感、半写实插画，还是动漫风？
- 需要像本人吗？是否有参考图？

### 默认假设

```text
默认做 1:1 头像，成人 25+，真实摄影感，半身近景，自然窗光，干净背景，表情自信温和，不生成文字、水印、logo。
```

## 2. 写真

### 3 个可选概念

1. 胶片生活写真：窗边、咖啡、柔光、真实皮肤纹理，像朋友拍的高审美照片。
2. 都市时装写真：街道、风衣、斑马线、玻璃幕墙，成熟、自信、有杂志感。
3. 私人空间安全写真：家居场景、覆盖性服饰、柔和窗光、亲密但克制。

### 需要追问的问题

- 要室内、街拍、棚拍，还是旅行写真？
- 画幅是 3:4、4:5、9:16，还是头像 1:1？
- 服装边界和氛围边界是什么？是否需要成人 25+ 明确写入？

### 默认假设

```text
默认成人 25+，非露骨、非裸体、非性行为，4:5 竖图，真实摄影感，柔和自然光，成熟松弛，不夸张磨皮，不生成文字水印。
```

## 3. 风景

### 3 个可选概念

1. 清晨山谷：薄雾、远山、第一束阳光，适合壁纸和治愈系封面。
2. 海边黄昏：浪花、湿润沙滩、落日反光，适合旅行和情绪图。
3. 城市雨夜：路灯、霓虹、湿地反射，适合电影感背景。

### 需要追问的问题

- 用途是壁纸、封面、海报背景还是视频首帧？
- 要真实摄影、电影感、插画还是概念艺术？
- 要有人物点景吗？

### 默认假设

```text
默认 16:9 或 9:16 两版，真实摄影质感，画面有前景、中景、远景，保留干净留白用于后期标题，不生成文字水印。
```

## 4. 旅行日记

### 3 个可选概念

1. 周末城市漫游：地铁站、咖啡店、街角、夜景，适合小红书图文。
2. 到达目的地第一天：机场/车站、行李箱、酒店窗景、第一杯饮料。
3. 复古胶片旅行：老街、车窗、路牌、夕阳，像一组真实照片冲印。

### 需要追问的问题

- 城市或目的地是哪里？
- 要单张封面、9 宫格，还是短视频首帧？
- 更想要攻略信息感，还是情绪日记感？

### 默认假设

```text
默认小红书旅行日记 9 宫格，4:5，真实现场感，人物成人 25+，包含地标、交通、咖啡/奶茶、路牌、行李箱、黄昏收尾，保留文字留白。
```

## 5. 穿搭

### 3 个可选概念

1. 通勤显贵穿搭：西装、针织、长裤、皮鞋/短靴，干净办公室到街头过渡。
2. 周末咖啡店穿搭：毛衣、半裙/牛仔、托特包、咖啡杯，松弛生活方式。
3. 城市夜约会穿搭：大衣、靴子、小包、夜景反光，成熟但不露骨。

### 需要追问的问题

- 性别/年龄感/身材比例要怎么设定？
- 季节、城市、场景是什么？
- 要真人上身、平铺清单，还是 9 格穿搭故事版？

### 默认假设

```text
默认成人 25+，4:5 小红书穿搭图，真人全身上身 + 局部细节，强调材质、版型、鞋包配饰和可复刻性，非露骨，不夸张拉腿。
```

## 6. 广告

### 3 个可选概念

1. 生活方式种草广告：人物在真实场景中自然使用产品，强调“我也想这样用”。
2. 高级产品主视觉：干净背景、精致光线、产品占主体，适合海报和电商头图。
3. 前后对比广告：使用前痛点、使用后结果、同角度对比，适合短视频封面。

### 需要追问的问题

- 产品是什么？核心卖点和目标人群是什么？
- 平台是抖音、小红书、TikTok、电商页，还是线下海报？
- 需要单张主视觉、9 格图文，还是 25 格广告故事版？

### 默认假设

```text
默认小红书/抖音通用生活方式广告，4:5 或 9:16，真实使用场景，产品清晰，人物成人 25+，标题留白给后期排版，不直接生成 logo 或乱码文字。
```

## 7. 商品

### 3 个可选概念

1. 干净电商主图：白/浅灰背景，产品轮廓清楚，材质真实。
2. 场景化商品图：产品在真实桌面、浴室、厨房、包内、旅行箱中出现。
3. 细节卖点图：包装、材质、开盖、质地、尺寸对比、使用手势。

### 需要追问的问题

- 商品品类、颜色、包装、尺寸和必须保留元素是什么？
- 是否有参考图或品牌视觉？
- 要电商干净图，还是社媒种草图？

### 默认假设

```text
默认 4:5 商品生活方式图，产品居中清晰，真实材质，旁边有少量相关道具，背景干净，留白用于卖点文字，不生成水印、乱码、未授权 logo。
```

## 8. 动漫女主

### 3 个可选概念

1. 都市治愈女主：便利店夜晚、耳机、制服灵感但非校服、温柔现实感。
2. 奇幻旅人女主：斗篷、发光道具、古城街道、冒险前一刻。
3. 夏日海边女主：白色衬衫、风、海边车站、青春但成人化的温柔氛围。

### 需要追问的问题

- 要现代、奇幻、国风、赛博，还是校园灵感但成人设定？
- 用途是头像、角色设定、插画、短视频首帧，还是壁纸？
- 是否需要三视图、表情表、服装设定？

### 默认假设

```text
默认原创成人 25+ 女主，非未成年感，非露骨，半写实动漫风，清晰服装设定，干净背景，避免使用在世艺术家或具体受版权保护风格名，改用具体视觉特征描述。
```

## 9. 节日海报

### 3 个可选概念

1. 温暖团圆海报：餐桌、灯笼、礼盒、暖光，适合春节/中秋。
2. 商业促销海报：产品居中、节日装饰、强留白，适合电商活动。
3. 城市节日氛围：街道灯饰、橱窗、雪/烟花/花灯，适合品牌社媒。

### 需要追问的问题

- 节日是什么？春节、情人节、七夕、中秋、圣诞、新年？
- 是否需要放产品、品牌色、活动文案？
- 要生成纯背景，还是带排版的海报参考？

### 默认假设

```text
默认生成无文字海报底图，竖版 4:5 或 9:16，中心主体清晰，上方或下方留白给真实文案排版，不生成乱码文字、水印、未授权 logo。
```

## 10. 情侣/朋友生活照

### 3 个可选概念

1. 便利店夜宵：两人拿着饮料和小吃，冷白灯，真实亲密但不做作。
2. 城市散步：斑马线、街灯、咖啡杯、回头笑，像朋友抓拍。
3. 旅行合照：车站、海边、民宿窗边、行李箱，轻松有故事。

### 需要追问的问题

- 是情侣、朋友、闺蜜、兄弟，还是家庭成员？
- 要真实摄影、胶片、日系生活感，还是商业感？
- 是否需要固定人物长相或参考图？

### 默认假设

```text
默认所有人物成人 25+，真实生活照，亲密但非露骨，动作自然，4:5 或 9:16，现场感强，不生成文字水印。
```

## 11. 宠物/家庭

### 3 个可选概念

1. 家庭早餐：餐桌、晨光、宠物趴在椅边，温暖纪实感。
2. 客厅陪伴：沙发、毯子、书、宠物靠近主人，治愈生活方式。
3. 户外散步：公园、夕阳、牵引绳、奔跑瞬间，适合封面和相册。

### 需要追问的问题

- 宠物种类、毛色、体型、性格是什么？
- 家庭成员数量和年龄段是什么？
- 要真实家庭纪实，还是插画/童书风？

### 默认假设

```text
默认真实摄影，温暖自然光，家庭成员非摆拍，宠物清晰可爱但不过度拟人，画面干净，适合相册或社媒封面。
```

## 12. 城市夜景

### 3 个可选概念

1. 雨夜霓虹街头：湿地反光、出租车灯、行人虚化，电影感强。
2. 天台城市远景：人物背影、城市灯海、风吹衣摆，适合头像和首帧。
3. 便利店夜归：冷白灯、玻璃反光、饮料货架，真实都市生活。

### 需要追问的问题

- 城市是哪一类：东京、上海、香港、纽约、首尔，还是虚构城市？
- 要无人风景、人物点景，还是主角肖像？
- 用途是壁纸、封面、广告，还是短视频首帧？

### 默认假设

```text
默认 9:16 城市夜景，电影感真实摄影，霓虹和湿地反射，人物成人 25+ 可选，构图留出标题区，不生成文字、水印、logo。
```

## 13. 奶茶店现场

### 3 个可选概念

1. 刚拿到新品：人物从店员手里接过奶茶，表情惊喜，适合短视频首帧。
2. 桌面测评：奶茶杯、吸管、小票、包装袋、口味标签留白，适合小红书。
3. 排队现场：门店招牌、菜单、队伍、朋友聊天，真实热闹。

### 需要追问的问题

- 是真实品牌参考、虚构奶茶店，还是不要出现品牌？
- 要封面、测评图、9 宫格，还是动态图首帧？
- 色调要甜美、清爽、夜晚便利店感，还是高级咖啡感？

### 默认假设

```text
默认虚构奶茶店，避免未授权 logo，成人 25+ 人物，真实现场光，杯身清晰，保留标题和口味标签留白，不生成乱码文字。
```

## 14. 涂鸦生活方式

### 3 个可选概念

1. 街头涂鸦墙穿搭：宽松夹克、帆布鞋、滑板/耳机，年轻但成人化。
2. 涂鸦咖啡店：墙绘、贴纸、手写菜单氛围，适合生活方式图文。
3. 夜晚创作现场：喷漆罐、工作灯、墙面草图，像艺术家纪录片剧照。

### 需要追问的问题

- 要街头潮流、艺术家工作室，还是咖啡店生活方式？
- 人物是否出现？成人边界和穿搭风格是什么？
- 画面要真实摄影、插画，还是海报视觉？

### 默认假设

```text
默认成人 25+ 街头生活方式摄影，涂鸦作为背景和文化氛围，不出现真实品牌 logo，不鼓励违法破坏现场，画面强调穿搭、色彩、创作氛围和城市质感。
```

## 15. 当用户完全不想选

如果用户说“你定”“随便来”“别问了”，直接给一个稳妥默认包：

```text
我默认做 3 个方向：一个适合头像，一个适合小红书/抖音封面，一个适合短视频首帧。统一成人 25+、非露骨、无文字水印、真实高级生活方式摄影。画幅分别为 1:1、4:5、9:16。每张都保留干净留白，方便后期加标题。
```

可以直接生成的三张：

1. `头像`：自然窗光半身肖像，干净背景，成熟可信。
2. `图文封面`：咖啡店或城市街头，强第一眼情绪，标题留白。
3. `视频首帧`：人物动作开始前一刻，环境有轻微动态，适合图生视频。

## 16. 快速输出格式

当需要快速给用户选择时：

```text
我给你 3 个方向：
1. {概念名}：{一句画面描述}，适合{用途}。
2. {概念名}：{一句画面描述}，适合{用途}。
3. {概念名}：{一句画面描述}，适合{用途}。

只需要你选一个方向；如果不选，我默认用第 1 个，画幅 {默认画幅}，风格 {默认风格}，安全边界 {成人 25+ 非露骨}。
```

## 17. 灵感转 prompt 模板

```text
用途：{头像/写真/风景/旅行日记/穿搭/广告/商品/动漫女主/节日海报/生活照}
概念：{选择的概念}
主体：{人物/产品/宠物/风景/场景}
边界：成人 25+，非露骨，非裸体，非性行为，非未成年感
画面：{场景、动作、情绪、道具}
构图：{特写/半身/全身/九宫格/分屏/首帧}
光线：{自然窗光/黄昏/霓虹/棚拍/柔光}
风格：{真实摄影/胶片/商业/动漫/电影感}
平台：{抖音/小红书/TikTok/电商/头像}
输出：{画幅、留白、不要文字水印}
```
