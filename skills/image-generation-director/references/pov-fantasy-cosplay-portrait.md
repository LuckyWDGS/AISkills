# 主观视角幻想 Cosplay 亲密人像

用途：复现“第一人称近距离手机闪光灯 + 幻想/Cosplay 华丽服装 + 手轻托脸颊/下巴 + 女主抬眼看镜头”的成人人像风格。适合原创幻想角色、Cosplay 风写真、情侣视角封面、短视频首帧和角色氛围图。

## 安全与创作边界

- 主体必须是成人 25+，视觉上成熟，非儿童化。
- 语义写成双方自愿的 staged portrait / couple POV portrait，不写胁迫、控制、偷拍、醉酒、无法拒绝或非自愿。
- 可以有亲密距离、抬眼看镜头、手轻托脸颊、华丽服装、优雅领口和成熟曲线；关键部位必须覆盖，有内衬或不透明结构，非裸体、非露点、非性行为。
- 不做胸部、臀部、腿部或隐私部位局部特写。画面重点是脸、眼神、妆发、服装、手势、闪光灯质感和整体氛围。
- 如果用户提到具体 IP/Cosplay，优先改写成原创幻想角色或“IP 气质灵感”，避免角色名、logo、标志性服装的直接复刻。

## 风格锚点

- 视角：第一人称 POV，手机近距离俯拍，镜头在人物上方，人物坐在低矮软垫或地毯旁，抬眼看向镜头。
- 手势：画面前景出现拍摄者手臂，手掌轻轻托住人物脸颊或下巴；动作温柔、自然、自愿，不用“抓住/强迫/控制”。
- 人物：成人女性模特，长黑发，几缕发丝落在脸旁，眼妆清透，腮红明显，唇部水润，眼神柔软但有镜头感。
- 服装：原创幻想舞姬/神殿侍者/古代王国角色服饰；白、金、红、粉色系；金色肩饰、耳环、刺绣边、披肩或披帛；优雅领口，关键部位覆盖，内层不透明。
- 场景：柔软椅子、地毯、暖暗室内、梳妆台或灯光小点，背景不重要但要有真实房间质感。
- 画质：手机闪光灯近拍、轻微高光、真实皮肤纹理、暗部有噪点、近距离透视、非棚拍精修。
