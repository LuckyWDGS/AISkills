# 文化服饰与旅行写真 Prompt 参考

用途：给 `image-generation-director` 处理日本写真、和服、旗袍、汉服/新中式、韩系咖啡馆、旅行写真、风景+女生系列照时使用。默认中文输出，必要时可补英文关键词。

## 总边界

- 主体默认：成人 25+ 女性，成熟、自然、非儿童化。
- 内容边界：非露骨、非裸体、非性行为、非窥视、非偷拍、非低俗凝视。
- 服饰边界：传统服饰要写成文化、礼仪、旅行、写真、时尚编辑语境，避免把和服、旗袍、汉服、韩服或新中式写成低俗化装扮。
- 姿态边界：站立、行走、回眸、端坐、整理袖口、持伞、喝咖啡、看风景、翻书、拎包、轻扶栏杆等自然动作优先。
- 镜头边界：优先写全身、半身、环境人像、生活方式摄影；避免过度身体局部特写。
- 语言边界：把暧昧词改写为材质、剪裁、气质、性格、光线、构图、生活场景。传统服饰可以表现身材曲线，但不能低俗化或身体部位凝视。

## 通用 Prompt 模块

### 主体模块

```text
一位成人 25+ 女性，成熟自然的东方气质，妆容干净，发型整洁，神态松弛自信，非儿童化面部比例，真实肤色和自然皮肤纹理。
```

可替换气质：

- 温柔清冷：安静、含蓄、眼神平和、低饱和色调。
- 明亮旅行感：自然微笑、轻松步伐、阳光、风吹发丝。
- 复古编辑感：克制表情、胶片颗粒、精致轮廓、杂志封面构图。
- 文艺生活感：看书、咖啡、手账、街角、窗边、自然抓拍。

### 服饰模块

```text
服饰尊重文化语境，剪裁优雅，面料质感清晰，衣襟、腰带、袖口、盘扣、刺绣或纹样细节准确。可以通过旗袍收腰、和服腰带、新中式腰线等表现成熟曲线，但关键部位覆盖，不做低俗化处理。
```

### 场景模块

```text
场景与服饰语境匹配，有真实环境层次：街巷、庭院、茶室、咖啡馆、古城、旅店窗边、海边步道、山间栈道、城市黄昏街角。背景服务人物，不喧宾夺主。
```

### 摄影模块

```text
真实摄影质感，35mm/50mm/85mm 人像镜头，柔和自然光，浅景深但保留服饰细节，真实肤色，轻微胶片颗粒，高级生活方式杂志感，构图干净。
```

### 输出模块

```text
画幅：4:5 或 3:4 竖图；需要旅行海报时用 9:16；需要风景+人物时可用 16:9。高清、细节清晰、无文字、无水印。
```

## 分类案例

### 日本写真：街巷自然光

适合：京都/镰仓/东京街角旅行写真、日系生活方式头像、清爽旅行封面。

```text
一位成人 25+ 女性，成熟自然的日系旅行写真，穿浅米色风衣、白色针织衫和长裙，走在安静的日本老街石板路上，手里拿着小型胶片相机，轻轻回头看向镜头。背景有木质店铺、暖色灯笼、低矮屋檐和少量行人虚化。35mm 胶片街拍，柔和阴天自然光，低饱和奶油色调，真实肤色，发丝和衣料细节清晰，生活方式杂志感，非露骨，4:5 竖图。
```

### 和服写真：传统庭院

适合：正式和服体验、旅行纪念、文化写真。避免把和服写成暴露或挑逗服装。

```text
一位成人 25+ 女性，穿正式浅樱色和服，腰带系法端正，衣领、袖口、织纹和发饰细节准确，站在日式庭院的石灯笼旁，双手自然交叠在身前，表情温和从容。背景有竹篱、青苔石径、枫叶和木质回廊，整体尊重传统礼仪语境。85mm 人像摄影，柔和散射光，浅景深，真实布料纹理，优雅克制的文化旅行写真，4:5 竖图。
```

### 旗袍写真：海派复古

适合：成熟女性复古肖像、民国风编辑大片、城市文化写真。注意旗袍应写剪裁、纹样、仪态，不写低俗化身体凝视。

## 通用正向边界

```text
成人 25+，成熟自然，服饰结构准确，材质、纹样、礼仪和场景服务人物气质。旗袍/和服/汉服/韩系等文化服饰以时尚、旅行、生活方式或编辑摄影呈现，关键部位由服装结构自然覆盖，构图关注脸部、整体造型、动作和场景氛围。文字、logo 和品牌元素使用留白、模糊背景或后期排版。
```

## 质检清单

- 是否明确 `成人 25+`？
- 是否明确成熟成人形象、完整服装结构和克制时尚语境？
- 传统服饰是否写了结构、材质、礼仪或文化场景？
- 构图是否强调脸部、整体造型、服饰材质和场景？
- 场景是否服务服饰和人物，而不是堆砌符号？
- 正向边界是否覆盖文化服饰结构、身份一致性和文字/logo 处理？
