# 紫灵月夜玄幻动漫海报风格

用途：复现“东方玄幻动漫女主 + 紫色月夜山谷 + 半透明纱衣 + 竖排书法标题”的竖版海报风格。适合原创玄幻女主、IP 气质原创化、人物参考换脸、封面图、动态首帧和角色海报。

## 参考图优先规则

如果用户给的参考图是“坐姿水边写真”而不是“文字海报”，先匹配参考图的观看体验：

- 人物占比：近景全身或七分身，人物占画面大部分，脸在上三分之一。
- 姿态：坐在水边石阶或亭台边，一条腿在前景形成纵向线条，一手撑地，一手整理头发。
- 场景：左侧木柱和暖灯笼，右侧瀑布、楼阁、湖面、桃花枝，背景有冷蓝月夜和雾气纵深。
- 服饰：淡紫/月白多层纱裙、透纱外层、刺绣、珠链、腰封、发饰，内层和结构覆盖关键部位。
- 文字：参考图没有文字时，使用纯图像构图；只有用户明确要标题时再加入“紫灵”竖排书法。

## 风格锚点

- 画幅：`9:16` 或 `2:3` 竖版，人物占画面中部到下部，背景纵深明显。
- 人物：成人 25+ 东方玄幻女性角色，成熟脸型，长黑发或深色长发，紫色/银色发饰，精致妆容，眼神清冷温柔。
- 服饰：淡紫、薰衣草、月白色纱质长裙，多层薄纱、飘带、刺绣、银饰、腰封。可以有成熟曲线和优雅领口，但关键部位覆盖，内层不透明，非露骨。
- 场景：月夜、山谷、瀑布、古风楼阁、灯笼、桃花/紫藤/花瓣、雾气、湖面倒影、远处万家灯火。
- 光线：冷蓝月光 + 暖色灯笼点光 + 紫粉花瓣反光，人物脸部和轮廓光清晰。
- 镜头：电影级竖版海报，浅景深但背景可读，人物和远景有层次。
- 文字：左侧或右侧留白处竖排书法字，白色或微发光，像浮在雾气里；红色小印章；小号诗句沿留白排列。文字不能覆盖脸、胸、手和关键服装结构，不能像一块贴纸压在人物上。
- 叠加关系：人物、飘带、花枝、灯笼、雾气、文字互相穿插，整体是一张海报，不是分块拼贴。

## 用户触发短句

用户以后可以这样说：

```text

```

如果没有人物参考，可以说：

```text
按“紫灵月夜玄幻海报风格”生成一个原创成人玄幻动漫女主，9:16 竖版，要有紫色月夜、瀑布楼阁、桃花灯笼、半透明纱衣层次、左侧竖排书法标题和红印章，文字放在人物外侧留白并融入雾气。
```

## 参考图工作流

当用户提供人物参考图时，拆成这些锁定项：

- Face anchor：脸型、五官比例、眼神、发际线和整体气质。
- Style/layout anchor：紫色月夜、瀑布楼阁、灯笼、花枝、竖排书法和红印章。
- Outfit anchor：紫色纱质长裙、飘带、银饰、腰封、内层覆盖结构。
- Pose anchor：站姿/坐姿/回眸/手扶栏杆/抬手整理发饰。

提示词中明确：

```text
保持参考人物的脸部特征和气质；服装、logo、角色名和世界观重新设计为原创成人东方玄幻女主。
```

## 变体方向

- 坐姿版：水边石阶、花瓣和倒影更多，人物近景更强。
- 站姿版：木台栏杆、月亮和远景山谷更完整，文字留白更稳。
- 动态首帧版：飘带和花瓣沿一个方向运动，人物正要转身，适合图生视频。
- 无文字版：去掉标题和诗句，只保留海报留白，方便后期真实排版。

## 质检

- 人物是否成人、成熟、非儿童化？
- 服饰是否有仙气和曲线，但关键部位覆盖、非露骨？
- 月亮、瀑布、楼阁、灯笼、花枝是否形成纵深？
- 竖排文字是否在留白里、半透明融入画面，没有压住人物？
- 整体是否互相叠加成一张海报，而不是左一块右一块拼贴？
