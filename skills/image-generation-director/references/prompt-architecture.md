# Prompt 架构

目标：把口语需求整理成稳定、可复制、可迭代的图像提示词。

## 基础结构

```text
主体 + 年龄边界 + 性格核心 + 身份/气质 + 身材表达边界 + 服装/材质 + 场景 + 动作姿态 + 构图 + 光线 + 镜头/焦段 + 色彩 + 风格参考 + 细节质量 + 输出约束
```

## 质量优先结构

当目标是复现某张“更好看”的参考图，不要从主体开始堆词，先从观看体验开始：

```text
画面载体 / 画幅与裁切 / 前景与主体层级 / 脸部权重 / 人物互动几何 / 场景时间 / 光线色彩 / 服装材质与安全边界 / 细节锚点 / 真实瑕疵 / 正向质量边界
```

示例：

```text
手机相册截图风格 / 9:16 超竖屏，上下白色 UI 留白 / 左侧男友白 T 恤肩膀占 30% / 女生脸在上三分之一且足够大 / 双手抱胳膊、脸靠肩膀、侧头看镜头 / 夜晚商业街 / 冷白灯混淡紫粉 / 白色夏季甜美穿搭，成人 25+，关键部位覆盖，非露骨 / 眼角痣、美甲、手链 / 手机夜景低动态范围、轻微过曝和压缩噪声
```

这类结构比“清纯白月光女友，主观视角，逛街，很好看”稳定得多。

## 关键词保真优先

用户给出的关键词是效果锚点，不是默认要删掉的风险源。除非它直接指向未成年、裸体、性行为、非自愿、窥视、隐私部位暴露或工具明确拒绝的内容，否则优先保留它的视觉能量，再用成人主体、服装结构、姿态、构图、光线和载体把它拍实。

```text
保留：性感、私房、女友感、身材好、腿部、吊带、短裙、亲密、强闪、偷拍感/抓拍感等可落地为成人时尚/生活方式/摆拍摄影的效果词。
最小处理：把容易误解为露骨、未成年、非自愿或窥视的部分改成成人 25+、自愿摆拍、编辑摄影、覆盖性服装、完整构图。
不处理：不要为了显得安全，把核心风格改成远景、臃肿服装、普通路人照、无互动、无张力。
```

## 推荐模板

```text
一位成人 25+ 的{主体}，性格是{温柔松弛/自信成熟/甜酷街头/文艺清冷/明亮活力/女王气场}，{气质/身份}，穿着{服装与材质}，位于{场景}，{动作/表情}。
构图：{半身/全身/特写}，{镜头角度}，主体清晰，背景干净。
光线：{自然窗光/柔光箱/夜景霓虹/电影逆光}，肤色自然，层次柔和。
风格：{商业摄影/胶片街拍/影视感/生活方式/高级时装}，真实质感，高级审美。
输出：{画幅/尺寸}，高清，细节自然，画面干净，手部自然，文字与 logo 仅在用户明确要求时由后期排版。
```

需要突出身材时，在服装和构图之间加入安全边界：

```text
身材表达：曲线明确、比例优秀，合身剪裁突出自然胸部轮廓和腰线，关键部位覆盖，有内衬或不透明结构，画面重点仍是脸部、性格、气质、穿搭、光线和整体构图，不做身体部位特写。
```

## 正向边界结构

```text
成人 25+，成熟面部比例，关键部位由服装结构自然覆盖，面料有内衬或不透明层，画面重点是脸部、性格、穿搭、光线和整体构图。主体完整清晰，手部自然，文字留在后期排版区，品牌与 logo 使用原创或留白处理。
```

## 权重顺序

0. 硬边界：未成年、裸体、性行为、非自愿、窥视、隐私部位暴露等不能做。
1. 用户锁定项：人物、服装、产品、品牌、场景、画幅、关键词效果。
2. 画面骨架：构图、景别、姿态、光线。
3. 风格质感：摄影类型、色彩、镜头语言。
4. 最小正向边界：成人 25+、覆盖结构、质量、文字、logo、手部、主体完整性。

质量修复时的权重顺序略有不同：

1. 目标观看体验：载体、画幅、裁切、主次关系、脸部权重。
2. 互动几何：谁靠近谁、手在哪里、前景占多少、眼神看哪里。
3. 时间与光：白天/夜晚、室内/街头、手机闪光/霓虹/窗光。
4. 最小边界翻译：成人、关键部位覆盖、非露骨、非暴力、非未成年。
5. 风格质感：手机照、胶片、相册截图、压缩噪声、轻微过曝。
6. 正向边界：用可拍摄语言固定安全和质量，不另附排雷清单。

## 最小改写方法

- `性感` -> `成熟性感、时尚吸引力、镜头感强`
- `性感但有性格` -> `自信成熟、镜头感强、曲线明确、强眼神、时尚张力`
- `诱惑` -> `有吸引力的眼神、亲密张力、成人时尚氛围`
- `私房` -> `成人 25+ 私房风写真、亲密生活方式肖像`
- `黑丝` -> `黑色连裤袜/薄透袜作为穿搭材质`
- `腿控` -> `腿部线条与穿搭比例展示`
- `撩人姿势` -> `自然坐姿、轻微侧身、肩颈线条优雅`
- `胸部突出` -> `合身剪裁突出自然胸部轮廓，关键部位覆盖，时尚杂志语境`
- `身材火辣` -> `曲线明确、比例优秀、健康丰润、成熟自信`
- `病娇` -> `温柔依恋、轻微占有欲的恋爱凝视，不恐怖不暴力`
- `主观视角女友感` -> `男友第一人称 POV，左侧男友肩膀前景，女生抱住胳膊、脸靠肩膀、近距离看镜头`
- `像 ChatGPT 那张` -> `手机相册截图载体、夜晚商业街、贴身近景裁切、脸部大权重、冷粉紫夜景调色、真实手机压缩感`

## 避免提示词污染

- 不要只把 `诱惑/性感/病娇/清纯/短裙/女友` 孤立堆在一起；如果保留原词，要补成人主体、载体、构图、服装、动作和光线，让模型知道要拍成什么。
- 不要把安全声明写成主视觉，例如整段都是 `不露骨、不色情、不透明、不...`；模型会优先规避，画面容易远、硬、保守。
- 不要把排雷清单写进可复制 prompt。正向 prompt 应该明确“要拍成什么”，安全和质量通过服装、动作、构图、文字留白、身份稳定来表达。
- 不要同时写 `真实手机随手拍` 和 `专业时尚大片/85mm DSLR/完美棚拍`，除非你明确要混合风格。

## 快速检查

- 是否有主体年龄边界？
- 是否说明用途和画幅？
- 是否把材质、光线、构图写清楚？
- 是否写出人物性格，而不是只写漂亮和身材？
- 是否只处理真正露骨或工具高风险的词，并保留用户核心效果？
- 如果突出身材，是否仍然是服装剪裁/整体造型语境，而不是身体部位特写？
- 是否避免让模型生成文字、logo、水印？
