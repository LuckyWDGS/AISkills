# 生图案例灵感地图

用途：把公开 prompt 案例库里的有用组织模式转成 `image-generation-director` 可复用的灵感地图。参考来源可以标注为：

```text
灵感来源：EvoLinkAI awesome-gpt-image-2-API-and-Prompts README_zh-CN
https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts/blob/main/README_zh-CN.md
```

注意：不要复制原 README 的 prompt 原文；只借鉴“分类案例 + 可复制 prompt + 正向边界”的组织方式，以及“主体、动作、场景、构图、风格、输出约束”这种结构。

## 使用方法

当用户说“参考某种爆款图”“做某类案例”“帮我写提示词”时，先选一个案例结构，再替换为用户自己的主体、产品、场景和安全边界。

基础拼装：

```text
类型：[人像/商品/海报/故事版/插画/旅行]
主体：[成人人物/产品/角色/城市/品牌]
动作或事件：[递饮品/走在街头/展示产品/展开故事]
场景：[咖啡馆/便利店/旅途/棚拍/城市夜景]
构图：[近景/中景/全身/九宫格/海报居中/拼贴]
风格：[胶片/手账/商业摄影/动画/矢量/水彩]
输出：[画幅、清晰度、无文字或可控文字]
正向边界：[成人/质量/版权/文字/logo/手部和主体完整性]
```

## 1. 涂鸦生活方式照片

可偷的结构：

- 真实生活照片作为底层：街角、咖啡馆、卧室桌面、旅行路边。
- 加一层手绘涂鸦：箭头、小星星、手写标签、贴纸边框、随手圈画。
- 人物动作保持自然：拿咖啡、翻手账、走路、看窗外。
- 涂鸦只做情绪和信息补充，不遮挡主体脸、产品或服装。

不要照搬什么：

- 不照搬某个案例的具体文案、贴纸图案、人物姿势或品牌字样。
- 不让涂鸦变成杂乱贴图，也不要生成不可读的大段文字。
- 不把成人写真做成儿童化贴纸风。

可扩展到什么：

- 小红书生活方式封面、旅行打卡照、穿搭记录、咖啡店探店、产品使用日记。

可复制 prompt：

```text
一张真实生活方式照片，成人 25+ 女性坐在窗边咖啡馆，穿浅色针织开衫和长裙，桌上有咖啡、手账和小花束。照片上叠加少量手绘涂鸦元素：细线箭头、小星星、纸胶带边框、简短手写风标签，但文字保持极少且不遮挡人物。柔和自然窗光，真实肤色，35mm 胶片感，温柔日常，小红书封面质感，4:5 竖图。
```

## 2. 旅行日记/手账插图

可偷的结构：

- 目的地场景 + 手账材料 + 少量纪念物：邮票、车票、地图角、胶带、手写日期。
- 画风可以是水彩、钢笔线稿、拼贴、复古纸张。
- 城市识别靠建筑、街道、食物、交通和色彩，不靠堆地标。

不要照搬什么：

- 不照搬具体城市海报模板或固定标题排版。
- 不生成一堆错误外文或伪造票据编号。
- 不把所有地标挤在同一张图里。

可扩展到什么：

- 旅行封面、攻略插图、城市手账、明信片、视频转场卡、旅拍系列页。

可复制 prompt：

```text
旅行日记手账插图，主题为[城市/国家]，画面像打开的纸质旅行本：左侧是钢笔线稿和淡水彩城市街景，右侧有咖啡杯、车票边角、地图小片段、贴纸、纸胶带和少量手写风短标题。整体温暖、干净、留白充足，细腻纸张纹理，复古旅行杂志感，避免大段文字，3:4 竖图。
```

## 3. 奶茶店动作人像

可偷的结构：

- 人物 + 饮品 + 明确动作：递给镜头、插吸管、放到托盘、从柜台取杯。
- 场景有商业店铺信息：灯箱、柜台、杯架、菜单氛围，但不生成真实品牌。
- 画面重点是亲和力和动作瞬间，不是性感凝视。

不要照搬什么：

- 不照搬任何真实奶茶品牌 logo、杯身品牌名或菜单文字。
- 不写舔吸暗示、挑逗姿势、过度身体局部特写。
- 不把人物写成未成年店员或校园制服少女。

可扩展到什么：

- 饮品新品海报、咖啡店员工形象、探店封面、短视频首帧、电商生活方式图。

可复制 prompt：

```text
成人 25+ 女性在现代奶茶店进行自然动作人像，她穿浅色西装外套和长裙，站在柜台前把一杯珍珠奶茶递向镜头，笑容亲和，姿态自然。背景有暖色灯箱、木质柜台、整齐杯架和柔和店内光，杯身无真实品牌文字。35mm 商业生活方式摄影，轻微动作感，色彩明亮干净，4:5 竖图。
```

## 4. 便利店霓虹人像

可偷的结构：

- 夜景便利店外部 + 冷白荧光灯 + 霓虹反光 + 湿地面。
- 人物拿饮料、推门、站在玻璃门边、看向街道。
- 胶片颗粒和高反差让画面有故事感。

不要照搬什么：

- 不照搬原案例中偏露骨的服装、姿态和身体描述。
- 不使用真实便利店品牌 logo 或可识别招牌。
- 不让“夜景人像”变成低俗偷拍感。

可扩展到什么：

- 都市奇幻首帧、胶片街拍、夜宵探店、人像海报、音乐封面。

可复制 prompt：

```text
成人 25+ 女性夜间便利店霓虹人像，穿深色风衣、白色内搭、直筒牛仔裤和短靴，手里拿一瓶无品牌冰饮，站在 24 小时便利店玻璃门外，侧身看向街道。店内冷白荧光灯与外部粉蓝霓虹混合，湿地面有反光，货架背景轻微虚化。35mm 胶片摄影，高反差，真实颗粒，都市电影感，非露骨，4:5 竖图。
```

## 5. 胶片街拍

可偷的结构：

- 一个明确街头动作：过马路、回头、等车、整理围巾、推门。
- 镜头语言：35mm、自然光、轻微颗粒、低饱和、偶然抓拍感。
- 背景有城市层次：橱窗、公交站、路灯、雨后反光、人群虚化。

不要照搬什么：

- 不照搬具体摄影师风格名、街拍博主脸、品牌服装 logo。
- 不做过度摆拍和夸张磨皮。
- 不把街拍写成偷拍或窥视视角。

可扩展到什么：

- 穿搭图、城市写真、音乐封面、杂志内页、旅行系列照。

可复制 prompt：

```text
成人 25+ 女性胶片街拍，穿复古风衣、白衬衫、深色长裤和皮鞋，正在雨后城市街角过马路，轻微回头，动作自然。背景有橱窗灯、路灯反光、模糊行人和湿润路面。35mm 胶片摄影，低饱和色彩，真实颗粒，柔和但有故事感，抓拍构图，16:9 横图。
```

## 6. 广告故事版

可偷的结构：

- 多格网格：6 格、9 格或 12 格。
- 每格负责一个广告动作：建立场景、产品登场、材质特写、使用动作、情绪反应、收束英雄图。
- 保持产品一致、光线一致、角色一致。
- 可以有少量镜头标签，但真正投喂生图时要小心文字乱码。

不要照搬什么：

- 不照搬案例中的具体产品、品牌、标题或镜头顺序。
- 不在一张图里塞过多小字。
- 不把故事版当成最终商品图；它是导演板或客户提案板。

可扩展到什么：

- 15 秒短视频脚本、商品种草分镜、品牌 TVC、餐饮新品、护肤品使用流程。

可复制 prompt：

```text
创建一张 9 格广告故事版，用于[产品名/品类]的 15 秒竖屏短视频。每格保持同一产品外观和同一高级生活方式摄影风格：1 场景建立，2 产品英雄中景，3 材质/细节特写，4 用户拿起产品，5 使用瞬间，6 效果或情绪反应，7 场景氛围，8 产品与生活方式组合，9 收束英雄图。干净深色故事版边框，少量可读中文镜头标签，商业摄影质感，9:16 竖屏提案板。
```

## 7. 商品英雄图

可偷的结构：

- 单一主产品居中或三分构图。
- 材质、反射、阴影和微环境负责高级感。
- 用“产品世界”讲卖点：水滴、果切、原料、烟雾、光束、微缩场景。

不要照搬什么：

- 不照搬真实品牌包装、logo、口号。
- 不生成虚假功效声明和不可读标签。
- 不让装饰物抢过主产品。

可扩展到什么：

- 护肤品、香水、食品饮料、数码配件、首饰、茶叶、文创商品。

可复制 prompt：

```text
高端商品英雄图，[产品]放在画面中央的浅色石材台面上，瓶身/包装形态清晰，材质真实，标签区域保持简洁无虚假品牌文字。周围用[原料/水滴/花瓣/金属配件/微缩场景]暗示产品卖点。柔和棚拍光，真实阴影和反射，浅景深，干净高级电商视觉，1:1 方图。
```

## 8. 时尚 Moodboard

可偷的结构：

- 中央主模特/主造型 + 周围素材拼贴。
- 素材包括妆容、面料、饰品、香水、咖啡、花、鞋、包、手写小纸条。
- Moodboard 的重点是统一色彩和材质，不是把所有元素都画满。

不要照搬什么：

- 不照搬具体杂志版式、真实品牌 logo 或原案例里的服装细节。
- 不让小字成为主体；文字可少量装饰，避免长文。
- 不把女性时尚 moodboard 做成露骨凝视。

可扩展到什么：

- 韩系时尚、复古法式、新中式穿搭、品牌调性板、角色服装灵感板。

可复制 prompt：

```text
高级时尚 moodboard 海报，中央是一位成人 25+ 女性模特，穿[服装主题]，姿态优雅自然。周围以拼贴方式排列材质样本、妆容特写、鞋包配饰、花束、咖啡杯、香水瓶、手写风短标签和纸胶带边框。整体色彩为[主色系]，留白充足，像高端韩国/编辑杂志视觉，真实摄影与拼贴结合，文字极少且不主导，4:5 竖图。
```

## 9. 旅行海报

可偷的结构：

- 城市/国家名作为视觉锚点，但文字要少且可控。
- 城市识别来自建筑、街道生活、交通、食物、植物、色彩。
- 风格可选：线稿、水彩、复古邮票、现代瑞士排版、微缩地图、拼贴。

不要照搬什么：

- 不照搬固定城市海报案例的排版和图形。
- 不把多个国家文化符号混用。
- 不生成错字地名；如文字要求高，建议后期排版。

可扩展到什么：

- 目的地推广、旅行攻略封面、城市明信片、节日活动海报、视频章节卡。

可复制 prompt：

```text
高级旅行海报，主题为[城市/国家]。画面用[水彩线稿/复古邮票/现代几何/微缩地图/拼贴]风格表现当地街道生活、代表性建筑轮廓、交通元素、植物和食物细节。构图干净，有充足留白，标题位置预留在上方或下方；如生成文字，只保留简短城市名，避免复杂小字。色彩符合当地气质，旅游杂志封面感，9:16 竖图。
```

## 10. 广告人物+品牌世界

可偷的结构：

- 参考人物保持身份，服装和场景重塑成品牌世界。
- 人物手持产品，产品打开/延展成一个微型世界或视觉隐喻。
- 背景用品牌色、材质、图形和少量标签统一。

不要照搬什么：

- 不照搬真实品牌 logo、广告语或包装。
- 没有授权时不要保留可识别名人身份。
- 不发明夸张医疗、功效、金融承诺。

可扩展到什么：

- 香水广告、饮品广告、护肤品大片、科技产品海报、个人品牌视觉。

可复制 prompt：

```text
为虚构品牌[品牌名/品类]创建一张广告人物海报。成人 25+ 人物站在画面前景，穿着符合品牌调性的原创造型，手持核心产品。产品周围延展出一个小型视觉世界，体现[卖点/情绪/场景]，背景使用[品牌主色]和对应材质纹理。商业广告摄影，主体清晰，图形层次干净，文字只使用占位符或不生成文字，9:16 竖图。
```

## 正向边界总库

### 人像安全

```text
成人 25+，成熟面部比例，服装结构完整，关键部位由服装自然覆盖，镜头重点是脸部、动作、场景、穿搭和整体氛围，公共场景写成自愿摆拍或编辑摄影。
```

### 版权与商用

```text
使用原创品牌名、占位符文字或留白；IP 与名人只提炼为原创角色气质、配色和镜头结构；商业包装、logo、广告语由用户授权或后期真实排版。
```

### 质量

```text
主体清晰，脸部稳定，手部自然，产品比例准确，反射和材质可信，文字区域留白或只做不可读背景符号，画面干净，构图可用。
```

## 迁移判断

- 用户要“好看图”：优先从人像、胶片街拍、moodboard 里选结构。
- 用户要“商业转化”：优先商品英雄图、广告故事版、广告人物+品牌世界。
- 用户要“系列内容”：优先旅行日记、风景+人物系列、9 格故事版。
- 用户要“参考爆款”：只借结构，不借具体文案、IP、品牌和可识别构图。
- 用户要“直接生图”：先补主体、画幅、安全边界和是否允许文字，再调用生成路线。
