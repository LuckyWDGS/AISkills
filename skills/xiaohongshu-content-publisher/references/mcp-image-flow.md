# MCP 上传与图文验收

适用于已有本地图片。每次读取当前 Chrome DevTools MCP 工具 schema，确认浏览器实例、页面 ID、最新 snapshot 和可见账号；不要复用历史 UID、文件输入或上传限制。

## 文件输入与上传

1. 进入创作者平台的“上传图文”入口，读取当前格式、大小、分辨率和张数限制。用户指定的图片应明确用于公开笔记；场景参考图不是私密上传区。
2. 按既定顺序核对源图：尺寸、SHA256、首图角色和每张的内容。A/B/C 外内对比可以采用 A外→A内→B外→B内→C外→C内；这不是所有题材的固定六图模板。
3. 从 snapshot 获取页面真实 `input[type=file]` 或其文件选择入口。当前工具通常为 `upload_file({pageId, uid, filePaths})`；文件必须位于浏览器所在机器。以本次 schema 为准，不用猜测的上传 API 或后台请求代替页面输入。
4. 若连接器明确拒绝项目路径，将本次批准素材复制到连接器允许的本机临时目录，逐张校验副本 SHA256 后上传。不修改原图，不规避连接器路径边界；临时副本不进 Git，也不写成固定机器路径。
5. 选择文件后等待页面异步进入图片编辑。页面已开始处理时不再点击上传。记录实际卡片数量／顺序、成功的上传请求状态及缩略图，不能以“已选择 N 个文件”或 `N/上限` 单独宣称上传成功。

上传请求的请求头、Cookie、签名 URL 和完整响应通常含敏感字段。只记录必要的请求编号、方法、状态和脱敏后的结果，不保存原始网络抓包。

## 编辑与预览

- 检查所有缩略图以及手机预览：图片可加载、尺寸合理、无破图，首图、顺序、裁切与标题相符。`complete=true` 还要结合 `naturalWidth/Height>0` 判断。
- 标题和普通表单可批量填写；富文本正文另核对段落。曾观察到表单填充把换行变为空格：若发生，使用真实编辑器支持的粘贴／输入方式修复，之后检查段落和页面计数。
- 正式话题是编辑器中的平台话题实体，普通 `#文本` 不算已选实体。修改正文时保留已选实体；不要用整体重新填充破坏它们。
- 编辑器和手机预览可能各渲染一套话题／图片。统计时限定编辑器、图片编辑区或对应预览容器，避免双计数。

## 保存、刷新、重开

1. 使用当前页面的保存入口，看到真实保存成功及时间；记录状态为草稿，不叫已发布。
2. 整页刷新后，从草稿箱切到“图文”分类，打开现有那篇。其他媒体分类显示零篇不代表图文草稿消失。
3. 核对全部图片、标题、段落、正式话题、活动、原创、AI、可见范围和非定时／定时设置。正文末尾换行归一化可能改变计数，必须确认正文含义和结构未丢失。
4. 草稿可能存于当前浏览器本地，重开图源仍是 `blob:`。这证明草稿可恢复，不证明 CDN 可取。远程加载在发布结果或页面已有的远程预览中另验。

## 文件哈希与像素核验

源图到临时副本应文件 SHA256 完全一致。页面初次 blob 若保留原文件，也可比对文件哈希。保存重开后 PNG 可能重新编码，但不能仅凭文件哈希不同就断言发生了重新编码。普通发布先检查画面完整、尺寸和顺序；若要声称“像素完全相同”，必须实际比对解码后的 RGBA 像素哈希并记录结果。

只有同样的像素排列、通道和色彩处理结果才适合直接比较 RGBA。平台 JPEG 压缩、尺寸变换或色彩转换可能改变像素；此时采用相应的视觉／尺寸核验，记录边界，不把“哈希不同”直接解释为传错图，也不把远程加载成功解释为原图字节一致。

## UID、shadow DOM 与超时

优先用工具的点击／填写能力。部分页面按钮位于 closed shadow DOM，普通 `document.querySelector('button')` 无法定位，但 snapshot 可能仍提供按钮 UID。如果当前 `evaluate_script` schema 支持 UID args，可以对最新 UID 解析出的真实元素操作，并在点击前检查标签及 disabled 状态。保存按钮示意：

```javascript
// args 传本次 snapshot 的保存按钮 UID；它不是普通字符串参数。
(el) => {
  if (el.disabled || el.textContent.trim() !== '暂存离开') {
    throw new Error('按钮状态已变化，重新读取页面');
  }
  el.click();
  return { saveClicked: true };
}
```

不探入框架内部状态、替换业务函数或伪造平台成功结果。最终发布按钮仍须满足本次授权及全部发布前验收条件。

点击或导航超时可能已经生效。先重新读取页面、请求状态和草稿／已发布列表，再决定下一步。发现图片失败时先分清未上传、未保存、预览加载失败三种状态；保留成功附件，不盲目重传或删除。HTTP400、ORB 或 CDN 错误也不自动授权改网络配置。
