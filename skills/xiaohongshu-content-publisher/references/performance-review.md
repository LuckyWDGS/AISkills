# 只读检查小红书笔记效果

用于“检查之前发布的星座 AI 图片效果”等请求。只读笔记管理和内容分析，不进入上传／发布流程，不编辑原笔记、回复评论、点赞、投流或创建监控。只查用户要求的平台和主题。

## 定位和采集

1. 核对当前登录账号，按真实作品 ID 对齐管理列表与分析页，标题和封面辅助。检查筛选与分页范围；未在本次列表看到某星座不等于从未发布，也不自动成为“下一篇”。
2. 记录采集时间／时区、内容类型、首发日期筛选、指标统计窗口和更新时间。首发日期区间与累计／近七天等统计口径分别记录。
3. 照录页面实际字段及单位，例如曝光、观看、封面点击率、点赞、收藏、评论、分享、涨粉、人均观看时长和来源。页面未展示的字段为未知，不填零。保留平台原始名称，不把观看改称去重人数。
4. 图文与视频单独建表，同题材跨媒体也不合计。人均观看时长、完播率、音频是否正常是不同证据；未展示或未试听不推断。
5. 逐条指标、来源页面和必要的脱敏运行证据写到项目指定的本地复盘目录。原始抓包、签名媒体地址及凭据不保存；真实后台数据不默认加入 GitHub、通用 Skill 或历史发布 manifest。

## 从数据到下一条假设

按曝光→封面点击／观看→互动收藏→关注逐层判断，仅评价实际有指标的环节。小样本收藏可作为有用反馈，不能据此推断广泛受众偏好、爆款或持续涨粉。低曝光或个位数播放不能单独证明限流。

官方封面点击率保留原值，不用观看／曝光擅自替换。自算收藏次数／观看次数、涨粉／观看等比例时注明分母及次数口径，不称去重用户转化率。汇总比例用合计分子／合计分母，不平均单篇百分比；分母为零或未知则比例未知。页面缩略数字只作近似，不伪造精确值。

优先比较同类型、相近发布后观察窗口和相同统计范围。发布时间不一的累计值只作现状描述，不能直接当作公平排名。单次快照不能隔离首图、标题、发布时间、选题与分发的影响，不称为严格 A/B 试验。

输出按用户目标说明：哪些内容获得点击、收藏或关注，证据支持到哪一层，哪些仍未知，以及下一条只改什么、用什么指标和窗口验证。首图情绪、具体居住情境或 A/B/C 互动形式可以成为待验证假设，不能写成平台定律。提出观察时间不等于设置了提醒或自动复查。

有历史数据而本次无法登录时，可分析已有快照并保留原日期，明确没有最新在线结论。不要为了补齐数据改动原笔记或重发。
