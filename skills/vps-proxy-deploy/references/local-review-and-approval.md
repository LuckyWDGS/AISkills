# VPS 验收后的本机检查与授权

本用户要求先完成指定 VPS，再检查本机、报告建议，由用户决定是否修改。服务器部署权限不自动包含本机加固；当前会话已明确批准的具体项目无需重复询问，后续撤销或收紧范围优先。

## 阶段与交付

| 阶段 | 执行内容 | 交付边界 |
| --- | --- | --- |
| VPS 部署 | 核实目标与版本，部署授权协议、证书、订阅、统计和维护 | 不更换正式客户端、不改本机保护设置 |
| VPS 验收 | 服务/监听、可信 HTTPS、最终 YAML、隔离核心逐协议与组合测试；按授权测速 | 记录真实路径、出口、失败样本和未测能力 |
| 本机只读检查 | 盘点下表现状，和已验证订阅对照 | 发现问题不立即修；先形成具体可审阅改动 |
| 用户决定 | 说明每项现状、风险证据、拟改字段/对象、影响、回滚与复测 | 用户明确选择后，只实施批准的范围 |
| 本机应用与复测 | 维护持久来源，核对运行时，再测授权场景 | 分别报告通过、失败、未测和需另行授权项 |

为 VPS 测试发现本机物理接口/路由属于前置只读检查。临时测试核心应独立目录、仅回环监听、TUN 关闭、无系统代理变更；使用最终订阅的副本。不能通过停止正式核心或关闭防火墙使它“独立”。受现有规则限制时说明限制，不绕开未获准的本机变更。

更新已有服务端订阅可能被其他设备自动刷新加载；先辨明共享影响。服务器完成不意味着原客户端已导入，订阅导入也不等于该设备的防火墙、浏览器或 CLI 保护已安装。

## 本机只读盘点

| 对象 | 检查什么 | 形成建议时说明什么 |
| --- | --- | --- |
| 正式客户端 | 当前订阅/组、GUI 与核心版本、运行配置、全局与订阅覆写、基础配置 | 哪个持久来源拥有该字段、影响当前还是全部订阅 |
| TUN 与 DNS | 路由/接口、fake-IP、UDP/TCP 53、引导与节点解析、DoH/DoT、国内明确策略 | DNS 与数据连接分别取证；strict-route 的回环/虚拟网络代价 |
| 分流 | 明确 DIRECT、AI/CLI 保护优先级、UDP 拒绝、末尾规则、嵌套组 | 默认代理无 DIRECT 回退；共享国内域名仍存在关联出口边界 |
| CLI 与子程序 | 实际独立程序、安装树、更新器、MCP/SSH、解释器及用户设置 | 路径是否被覆盖，程序级规则会影响哪些其他任务 |
| 防火墙 | ActiveStore、实际程序/包/接口/协议/地址/配置文件过滤器 | 保留回环、TUN、核心到 VPS 的 TCP/UDP；规则存在不等于有效 |
| 更新维护 | 已有任务的身份、触发器、脚本 ACL、日志、扫描范围 | 轮询有首次启动竞态，是否需要独立评估更强的启动控制 |
| IPv6 | 物理接口绑定、默认路由、公网/转换前缀、虚拟网卡与回环 | 关闭公网 IPv6 不应破坏 ::1；无公网 IPv6 时不能做实网结论 |
| 浏览器 | 实际有效 WebRTC 策略、版本、用户当前实例是否加载 | 限制 UDP 与禁用 API 不同，会议/共享/中继的可用性代价 |
| 回环 | 系统/应用绕过设置、已知服务的绑定与现有错误 | localhost、127.0.0.1、::1 分开；连接成功与业务修复分开 |
| WSL/容器 | 运行状态、实际网络模式与使用的 AI 程序位置 | Windows 路径规则不自动覆盖；现有业务不应被整体断网 |

只输出必要字段，环境变量、应用设置与订阅中可能含密钥。读取静态文件/文件版本元数据即可盘点安装情况；用户禁止运行某程序时，不为查版本启动它或执行其 CLI。

## 本用户当前选择的迁移边界

以下来自截至 2026-11-17 的明确选择，后续指令可覆盖；它们是本用户偏好，不是所有服务器的通用强制配置，也不代替本机修改审批。

- 优先用户提供的 VPS。已允许同出口 HY2、AnyTLS 与重新启用 REALITY；不使用微软 SNI。其他候选目标逐台核验，不固定照抄某品牌域名。
- 按授权启用 TCP BBR；正常校验证书，不用 `skip-cert-verify`，不虚填带宽。关闭公网 IPv6 时保留本机回环并检查业务依赖。
- 保留现有明确国内 DIRECT 名单，删除国内域名/IP 兜底；不恢复整 Chrome 按进程全量代理，不为检测站增加特殊直连/代理规则。
- 保护组不可回退 DIRECT；必须保留代理核心到 VPS 的必要 UDP。核心退出时部分国内网页也不可用，是需要先说明的可用性代价。
- WebRTC 当前选择为“暂不改，先了解利弊”。不要自动把它禁用或改成 `disable_non_proxied_udp`。
- 不打开、登录或请求 Claude/Anthropic 服务，不运行 Claude Code，包括 `--version`。用受控 HTTPS、STUN、DNS 和 DataChannel 测网络层，不能冒充真实 Claude 会话验收。
- “核心完全退出后仍可用的国内白名单备用服务”已暂停，不自动部署。

## 可审阅修改清单

每项包含：**现状与证据 → 拟改对象及具体差异 → 生效范围与可用性影响 → 回滚 → 验证方法 → 是否已获明确授权**。准备候选副本和离线语法/差异检查，不先应用再询问。

不要用“顺便加固”捆绑浏览器、防火墙、应用设置、计划任务和容器。用户批准部分内容时，继续完成那部分；未批准项保留建议。停核/禁用网卡、重启浏览器及真实业务测试分别说明操作，先建立[故障恢复能力](failure-testing.md)，再执行已获准阶段。

本机审查的结束语应给出真实状态，例如“VPS 与隔离订阅测试完成；本机已只读检查，以下改动待你决定”，而不是“全部设备已保护”。技能资料更新本身不触发这些改动。
