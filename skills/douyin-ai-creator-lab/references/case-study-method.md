# 公开案例研究

批量执行、时间轴拆解、并行分工和入库复核另读[研究执行与证据复核](research-execution-and-review.md)。该参考规定怎样让原始证据、实看范围和最终摘要相互对应；下面保留取样、时效与判断口径。

## 取样与记录

以用户提供的作品为起点。检查作者主页的部分高赞、相近主题/时长/日期的普通作品与近期作品；适合时每类选2条，但不可访问就记录缺口，不能凑摘要充数。扩展3–5位相近作者是常用首轮范围，不是硬指标。被置顶/搜索排序选出的作品有选择偏差，写「已检查样本内高赞」，不要称全账号排名。

要求深挖、发散或长期积累时，按[作者系列与原创转译](author-series-and-transfer.md)继续作者其他分支与普通对照，再查[案例库](case-library/index.md)避免重复采集。[标签与发布交接](tags-and-release-handoff.md)规定实际标签、研究分类和发布建议的不同来源；公开摘要可在用户要求下沉淀进案例库，完整媒体及私有数据仍留本地。

每条保留platform、work_url、author_url、原始标题、published_at_raw、observed_at与时区、时长、样本分组、证据等级、可见原始指标和观看范围。含「万」值只近似换算；缺失填null。主页总获赞不等于作品指标；收藏、分享、评论和点赞看清对应图标/页面语义。抖音点赞与B站播放分列，不能合成同一种热度；广告的「感兴趣」人数不能当互动或播放。

按平台作品ID/规范URL去重，不把分享链接、自动连播后的URL、上下集标题或同一作品不同入口重复计数。播放器切换后重新核对URL、作者、标题和已看时间点；不要把新作品的画面接在上一条拆片记录里。页面相对日期及加载前后时区变化按原始展示保留，未核实不自行统一成精确发布时间。

主页页脚的热门/SEO链接、相关搜索卡可能与真正作品列表一起被DOM提取。先核作品区与作者归属再计数，不能把所有含`/video/`的链接都算该作者作品，也不能仅因标题以数字开头就当指标行。卡片数字未核图标语义时保留`card_count_raw`；摘录标题明确标`title_excerpt`，不冒充完整原题。元数据广筛、实际看过的封面、动态采样与听审分别记录。

历史累积高赞不能当当前热点。同龄比较优先；累计数随日期、曝光、推广、粉丝基数变化，没有这些分母就不要宣称成功因果。

### 近期信息与时效窗口

用户要求近期信息时，当前选题与趋势结论只用日期可核的近期证据。无另行指定时，优先近7天作品，以近30天为主要样本窗口；这些是内部研究窗口，不是平台算法规则。分别记录作品发布日期、指标观察日期、统计截止日与覆盖周期；今天抓到的旧作不算近期作品，首页排序和搜索排序也不证明发布时间。

日期不明先记freshness=unknown并排除近期样本数，核清后再纳入。只显示月日但年份未核的近月作品记recent_candidate，不直接断言近30天；相对日期保留页面原文和观察时间。旧高赞可作历史技法参考，单列且不用于证明当前需求、近期爆款或当前增长；不把整个作者主页的卡片统称近期作品。

后台读取当次最新可用数据，同时写平台更新时间与真实窗口，不能把昨天以前截止的数据称今天累计。指数选最新完整的7天/30天窗口，平台只提供其他周期时照实保留起止，不改写成近30天。热点与短期活动在执行当天、提交前重查。报告注明实际发布日期和数据期，旧报告只作历史背景；样本不足就缩小结论或补查，不用旧资料凑近期数量。

### 不打断用户工作的研究

用户要求浏览器不影响工作时，使用工具支持的后台标签页与DOM/AX读取，不接管鼠标键盘或切换用户正在操作的窗口。视频研究页保持静音，避免自动播放外放；优先在独立研究页操作，不修改用户既有页面的声音设置或系统音量。若工具只能前台操作，先完成可后台读取的部分，明确该限制，不承诺完全无打扰。

静音研究只支持已查看的画面和元数据。需要声音证据时，使用当前工具实际支持、不会外放干扰的直接听审方式；没有这种能力就保留未听审状态，不靠后台播放时长补齐观看等级。

## 广告与作品分开判定

先看卡片/视频是什么，再判商业证据。推荐位并不自动是广告；游戏名称与庇护所题材相同也不代表它是同类作品。

| 所见证据 | 登记与处理 |
|---|---|
| 明示「广告」、游戏下载/评分/预约/购买等推广卡 | 记为ad_card或game_promotion，保留排除理由，不计作品样本或作者成绩 |
| 作品内明确合作标记、口播带货或购买引导 | 保留作品URL，记录商业证据及区间；与自然内容表现分组，不推断未公开投放量 |
| IP、品牌造型、音乐标签、简介商务联系方式 | commercial_status=unconfirmed；既不直接定商单，也不称非广告自然爆款 |
| 页脚投放入口、客户端推广、投稿活动卡 | 记页面上下文，不能作为作品观看机制或数据 |

每条增加content_kind、commercial_status、commercial_evidence、excluded_reason；明确广告卡单独入排除表。没有完成全片视听时，不能因为采样中没见广告就登记「全片无广告」。

把商业证据分层记录：`brand_visible`只表示标志/品牌物可见；`product_function_demo`表示实际操作、功能演示或明确推广字幕；`declared_cooperation`只记作者/平台明示合作。`paid_cooperation`与`paid_distribution`另外保持已证或unknown。偶然商标不能等同商单，明确推广段可按内容单列而不猜报酬。每个区间给起止、可见证据及边界精度。

## 证据等级

| 等级 | 实际完成 | 可支持范围 |
|---|---|---|
| A | 完整连续查看实际画面并完成直接听审 | 全片所见镜头和声音；仍不证明后台因果 |
| B | 实际视频抽帧/画面采样，无听音 | 画面内容、已核的切点、采样范围内构图变化；不支持曲名/对白/全片听审 |
| C | 详情/主页元数据或封面 | 标题、日期、可见数据、封面；不支持全片动态 |
| D | 搜索摘要、转述、无法打开 | 待验证线索；不称已经观看 |

记录采样方法。等距5帧可能漏掉短插入镜头，不能凭它准确数全片镜头；场景检测输出也是候选，需回看边界。浏览器无音频可感知能力、视频有AAC音轨或评论称音乐好听，都不构成完成听审。

B级同时记录sample_times/ranges、sample_count、visual_coverage（single_point/sparse/interval/boundaries）及audio_review。单点也可算实际画面采样，但不能称完整拆片；文件已下载或页面后台长时间播放不升级等级。若直接听过部分区间，记录区间，不把全片标成A级。

用户要求每秒3–5帧时，按[密采样方法](duration-and-shot-analysis.md#每秒35帧的密采样)执行。生成manifest与独立review分开：review至少含work_id、源hash、采样manifest、实际已读页/数量/时间范围、原帧补查区间、画面观察与声音状态；只有真正看过的页才登记完成。人物、物件身份或缺陷判断影响结论时，先放大或回原帧。

新证据纠正旧观察时，新增带日期的纠正记录，写明旧判断、变更理由和源时间区间；同步案例当前摘要、作者归纳、商业分组与项目报告。旧观察保留其历史范围，当前检索不得继续输出已被推翻的判断。例如空衣物舞动不能沿用为女性人体异常，机械手不能继续标作潜水头盔。

汇总分别报唯一作品数、实际画面采样数（注明单点/稀疏）、仅元数据/线索数及另排除的推广卡数；后两者不能并进「看完多少条」。同一作品以最高已完成等级计一次，同时保留历次覆盖记录。样本量没有固定及格线；继续扩样应回答新问题或补普通/近期对照，而非只堆推荐标题。

作者声明AI/自述某工具可以按原文记录；不能从画面反推全部制作链、确切提示词、模型版本、成本或原生声音。未证实就说「可用某流程近似实现」，不要说作者就是这样做的。

## 拆片

逐镜看首屏可读物、景别、前中后景、固定空间、主体/相机/环境各自运动、切点、光色材质、文案位置与结尾。每次切镜指出新增信息或情绪，声音缺口单列。不要把多段拼接解释为一镜到底，也不要把所有慢镜头都解释为治愈。

用户要时长、镜头约数或切换节奏时，按[时长与镜头核查](duration-and-shot-analysis.md)补实际媒体和切点证据；封面、播放器时长和稀疏接触表不能单独支持全片镜数。

### 声音主导环境片

研究音效、BGM或少独白的作品时，增加下列字段；未直接听到的部分填unknown，不从火焰、玻璃或雨的画面推断实际声音。

| 字段 | 记录内容 |
|---|---|
| audio_review | 直接听审状态、已听区间与方式；音乐署名、作者说明和评论反馈另标来源，不能代替听审 |
| sound_events | 时间点、对应的可见动作/结果、声源所在区域、实际听到的主声音；区分世界内动作声、连续环境和画外声音 |
| bgm_function | 音乐进入、延续、让位与结束的区间，以及它在建立期待、揭示结果、连接切点或收尾中的作用；曲名/授权未知就保持未知 |
| mix_relationship | 动作声、环境、独白与音乐的前后关系，关键变化是否可听清、是否存在突兀或遮蔽；听感判断只覆盖已听区间 |
| audio_promise | 标题/话题承诺的听觉体验，以及哪些实际声音兑现；ASMR、白噪音、音乐标签不互相替代 |

比较声音如何引导注意与兑现结果，不只罗列音效名称；高赞与普通样本共享的配乐方式仍只是共性。记录可学的功能，原创试法另选具体声音与有权使用的音乐，不把竞品声轨作为用户发布素材。

做同作者对照：高赞与普通共享什么，真正不同什么，哪些差异被日期/时长/主题混杂。必要时结论就是「现有证据不足以解释差距」。评论仅是可见、可能经排序的表达样本，不作为人口画像或多数人意见。

雨雪、列车、木屋等宽词先核观看意图：交通信息、实拍旅行、短时氛围体验与长时伴听可能混在同一结果页。关键词指数较大不证明环境片需求较大；长短视频服务不同用途，不用累计赞直接判断最佳时长。品牌话题是商业线索，未证合作就保持未确认，不并称纯自然表现。

形成可复用卡：

```text
事实：作品链接、日期、查看范围、可见指标与具体画面。
功能：观众在这里可能想看什么/期待什么。
边界：同类反例、未知后台、未听审/未核工具。
原创转译：保留观看功能；改变具体空间、视觉母题、路线或节奏。
试法：下一条只检验哪一个主要问题，怎样观察。
```

保留原始文案可用于短引用分析，不把整段竞品文案、现成视频或音乐作为用户发布素材。截图和短小分析材料记录来源与用途；完整参考视频保留在本地研究区，不随Skill或公开发布包提交。
