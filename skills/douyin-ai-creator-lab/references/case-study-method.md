# 公开案例研究

## 取样与记录

以用户提供的作品为起点。检查作者主页的部分高赞、相近主题/时长/日期的普通作品与近期作品；适合时每类选2条，但不可访问就记录缺口，不能凑摘要充数。扩展3–5位相近作者是常用首轮范围，不是硬指标。被置顶/搜索排序选出的作品有选择偏差，写「已检查样本内高赞」，不要称全账号排名。

每条保留platform、work_url、author_url、原始标题、published_at_raw、observed_at与时区、时长、样本分组、证据等级、可见原始指标和观看范围。含「万」值只近似换算；缺失填null。主页总获赞不等于作品指标；收藏、分享、评论和点赞看清对应图标/页面语义。抖音点赞与B站播放分列，不能合成同一种热度；广告的「感兴趣」人数不能当互动或播放。

按平台作品ID/规范URL去重，不把分享链接、自动连播后的URL、上下集标题或同一作品不同入口重复计数。播放器切换后重新核对URL、作者、标题和已看时间点；不要把新作品的画面接在上一条拆片记录里。页面相对日期及加载前后时区变化按原始展示保留，未核实不自行统一成精确发布时间。

历史累积高赞不能当当前热点。同龄比较优先；累计数随日期、曝光、推广、粉丝基数变化，没有这些分母就不要宣称成功因果。

## 广告与作品分开判定

先看卡片/视频是什么，再判商业证据。推荐位并不自动是广告；游戏名称与庇护所题材相同也不代表它是同类作品。

| 所见证据 | 登记与处理 |
|---|---|
| 明示「广告」、游戏下载/评分/预约/购买等推广卡 | 记为ad_card或game_promotion，保留排除理由，不计作品样本或作者成绩 |
| 作品内明确合作标记、口播带货或购买引导 | 保留作品URL，记录商业证据及区间；与自然内容表现分组，不推断未公开投放量 |
| IP、品牌造型、音乐标签、简介商务联系方式 | commercial_status=unconfirmed；既不直接定商单，也不称非广告自然爆款 |
| 页脚投放入口、客户端推广、投稿活动卡 | 记页面上下文，不能作为作品观看机制或数据 |

每条增加content_kind、commercial_status、commercial_evidence、excluded_reason；明确广告卡单独入排除表。没有完成全片视听时，不能因为采样中没见广告就登记「全片无广告」。

## 证据等级

| 等级 | 实际完成 | 可支持范围 |
|---|---|---|
| A | 完整连续查看实际画面并完成直接听审 | 全片所见镜头和声音；仍不证明后台因果 |
| B | 实际视频抽帧/画面采样，无听音 | 画面内容、已核的切点、采样范围内构图变化；不支持曲名/对白/全片听审 |
| C | 详情/主页元数据或封面 | 标题、日期、可见数据、封面；不支持全片动态 |
| D | 搜索摘要、转述、无法打开 | 待验证线索；不称已经观看 |

记录采样方法。等距5帧可能漏掉短插入镜头，不能凭它准确数全片镜头；场景检测输出也是候选，需回看边界。浏览器无音频可感知能力、视频有AAC音轨或评论称音乐好听，都不构成完成听审。

B级同时记录sample_times/ranges、sample_count、visual_coverage（single_point/sparse/interval/boundaries）及audio_review。单点也可算实际画面采样，但不能称完整拆片；文件已下载或页面后台长时间播放不升级等级。若直接听过部分区间，记录区间，不把全片标成A级。

汇总分别报唯一作品数、实际画面采样数（注明单点/稀疏）、仅元数据/线索数及另排除的推广卡数；后两者不能并进「看完多少条」。同一作品以最高已完成等级计一次，同时保留历次覆盖记录。样本量没有固定及格线；继续扩样应回答新问题或补普通/近期对照，而非只堆推荐标题。

作者声明AI/自述某工具可以按原文记录；不能从画面反推全部制作链、确切提示词、模型版本、成本或原生声音。未证实就说「可用某流程近似实现」，不要说作者就是这样做的。

## 拆片

逐镜看首屏可读物、景别、前中后景、固定空间、主体/相机/环境各自运动、切点、光色材质、文案位置与结尾。每次切镜指出新增信息或情绪，声音缺口单列。不要把多段拼接解释为一镜到底，也不要把所有慢镜头都解释为治愈。

做同作者对照：高赞与普通共享什么，真正不同什么，哪些差异被日期/时长/主题混杂。必要时结论就是「现有证据不足以解释差距」。评论仅是可见、可能经排序的表达样本，不作为人口画像或多数人意见。

形成可复用卡：

```text
事实：作品链接、日期、查看范围、可见指标与具体画面。
功能：观众在这里可能想看什么/期待什么。
边界：同类反例、未知后台、未听审/未核工具。
原创转译：保留观看功能；改变具体空间、视觉母题、路线或节奏。
试法：下一条只检验哪一个主要问题，怎样观察。
```

保留原始文案可用于短引用分析，不把整段竞品文案、现成视频或音乐作为用户发布素材。截图和短小分析材料记录来源与用途；完整参考视频保留在本地研究区，不随Skill或公开发布包提交。
