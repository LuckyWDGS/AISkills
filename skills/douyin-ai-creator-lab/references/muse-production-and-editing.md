# Muse首片制作与确定性剪辑

适用：用户已选择Muse并要求实际生成、剪辑或修片。研究、写提示词、整理Skill本身不触发新生成。本文件是制作方法，不是假定Muse永久提供某个模型或隐藏API。

## 分工与生成范围

- 先复用本次对话与有效持续偏好。明确「本次由你用Muse生成并剪辑」后，Codex负责参考、合理单元/秒数、逐段验片和常规剪辑；不因旧文档写「用户生成」再问一次同一分工。
- 「先一个，满意再做其余」只执行首片。用户后来明确要求全部生成并合并时，更新当前制作合同与进度入口，按新范围继续，不再被历史“只做首片”阻断；声音未听审与画面继续生产分别记录。扩集不自动授权发布、定时任务、付费升级或恢复其他暂停自动化。
- 通过当前允许的工具读取实际Muse页面和上传/生成入口；沿用工具的浏览器操作与下载边界，不把页面报告的内部工具名当可直接调用API。不占用或改动用户无关任务。
- 用户选了Muse而底层模型不可见时，记录unknown；不要从提示词、画风或分辨率猜H3/Seedance。仅在用户确实指定某底层平台时使用其语法。

## 一次生产单元的交付

生成前保存可复核的外部请求合同，控制语与模型正文分开：

```yaml
unit_id: Uxx
purpose: 本段给观众的新信息
reference: 本地干净单视图路径、尺寸、hash、稳定ID、唯一主要职责
generation_mode: 当前明确模式；普通参考不自动转硬首尾帧
source_duration_target: 当前入口允许的原片长度
editorial_duration_estimate: 预计使用长度；允许依实际结果调整
motion_and_end_state: 主要运镜、终点、应保留的自然动态
prompt_verbatim: 已定稿正文单独保存
request_limit: 只提交当前单元；不让网页代理自行连生、拼片或重抽
return: 原始文件、实际可见任务状态/ID、实际字段与提示词记录
```

新项目写明与旧项目分离；每个单元只附当前最小参考，主空间只有一张。多格导演板、错误旧图、上一任务附件、与当前空间竞争的前段尾帧不随手带入。计划切入另一空间不等于穿门插值或resume。

先核附件缩略图/名称和请求正文，再提交一次。任务未返回先检查同一任务的状态，超时未知不等于失败，不重名提交第二份。返回后保存原片并独立检查，再决定下一段；不要只依赖Muse自述「符合要求」。

系列素材可作为带manifest的资产库上传，文件过大时按单元拆成低于当前界面限制的若干包，不为运输大小重新生成图片。运输包不是模型的多参考请求：每个实际调用仍只选该单元唯一主图和对应正文，核文件名/hash与职责。平台回报文件名或hash不代表已经交付可下载附件；缺少附件时先让其补发已有文件，不重生。把“已生成、已附文件、已下载、独立检查通过”分开记，断点续作先看台账与当前界面，避免重复提交。

内容返修需写明具体失败、这次只改什么及尝试次数。可剪掉的重复/超程优先剪辑；确实需要重生时，在现有授权及工具预算内定有限尝试上限，不能改名字把同一缺陷的次数归零。技术失败按当前工具重试规则处理，不把下载失败当内容重生理由。

## 按真实素材决定剪辑

记录生成原片、预计成片与最终成片三个时长。不要为了凑设计秒数保留重复展示；也不要因原片每条一样长就平均分镜。先找每段的有效信息与实际稳定尾部，再选入出点。

EDL至少写源文件/hash、源入出点、目标位置和cut_reason。恒定帧率按`[in_frame, out_frame)`记出点不含，时长为`(out-in)/fps`；可变帧率用实际时间戳，或明确记录先转换到何帧率。不同源的帧号不能直接相减。记录重编码、缩放、裁切、音频及转场参数，原片保留。

- 画内标题、字幕、序号和说明标签属于可选包装，不因“做成片”自动添加。用户要求无字时，从已验源取消文字层重导，保留采用版本、构图、时长和切点；不用生成式擦字或裁掉主体。未要求改声音时可复制现有音轨并核字节一致；保留带字旧版作为历史，不将本次无字偏好扩成所有项目的规则。
- 默认不增加无理由的变速、循环、冻帧、数字推拉或叠化。需要这些处理时写叙事目的；不拿叠化掩盖几何冲突，也不把冻帧称为自然停留。
- 画面切点、旁白句界、环境声距离和音乐乐句分别检查。晚出现的画外旁白可在不改含义、声源语境和完整语句的前提下提前，音频入出点与视频分开记；同步对白、脚步、接触声不能照搬这种自由挪移。
- 移动原生混音会同时移动雨声和音乐，不是只移动人声。现有成片的原音乐若已被用户认可，先保留；未听审的新片不能继承另一片的声音认可。
- 交叉淡化在完整语句以外选择，按素材决定时长/曲线/增益。等响或峰值对齐不保证听感统一；固定0.25秒、某组dB值只可能是案例参数。
- 若相邻音频有交叉重叠，总音长为各段长度之和减重叠之和。改变重叠会改变进入时刻，须重新核与画面/台词的关系；不要只算总秒数。
- 按当次声音设计安排结尾：停止新旁白不等于把总混音淡没。要求雨声/BGM持续时保留底声，让镜头自然停留。

## 跨段旁白音色返修

- 用户反馈每段像换人时，先区分音色身份、表演/口音、响度与混音距离。增益归一和交叉淡化不会把不同声音变成同一人；重复“同一位女声”也不等于平台固定了声音身份。
- 固定声音后的下一轮仍可能被用户评价为太尖、太年轻、太硬或不自然：把已否定声线标为不采用，按具体气质换有限候选。明确要求“换一个”时选择不同声音身份；降音量、EQ或变调不能冒称更换了说话者。候选使用相同文案、相近试听响度，先核实际语种；目录标签、基频或频谱数值只能辅助筛选，不能替代听审。无法直接听音时不说“已试听确认柔和”，交实际可播放结果并保留听感待反馈。
- 保留可用画面，先核当前真实TTS/配音入口、语言、固定voice_id、长度限制与音频输出。短片优先用选定声音一次合成完整旁白，再从同一take的自然句间拆开对齐画面；不要把每个视觉UNIT自动变成新的随机配音请求。需要分批时复用实际声音身份与参数，并检查接句。
- 音色目录的气质/口音标签只是选型线索，语言参数已提交也不证明输出语言正确。生成后先核实际语种和完整台词；若返回英文翻译、错误星座或漏句，该take不进入合成，保留证据并针对语言/声音选择作有限修正。重试优先核实际入口支持的语言代码和明确中文声线；同时更换声线、代码和速度后成功，只证明该组合可用，不能归因为某个语言代码的普适修复。多语种声音可能支持中文，仍须检听普通话、自然度和跨句一致性；不能凭warm标签宣布效果。保留实际voice_id、文本、参数和原始完整take。
- 原生混音含旧人声时，不能直接盖新旁白。使用真实可用的分离声部，或从有充分语句余量的本片声音窗口重建背景，或另制无语言背景；记录采用哪条路线。语句间隙循环的是声音，不是画面；音乐重复、交叉点、残留气口/人声和尾段环境声都要单独检查。ASR无词不证明绝无人声。
- 改参数后的重试先核文件身份。若文件hash与已否定take完全相同，说明拿到的是相同字节，不算新的可选声音；保留请求与结果并结束这一路有限重试，不因文件名或新任务号增加候选数量。字节相同不证明后台缓存、语言参数被忽略或服务根因，无法独立查明时保持未知。
- 一条短中文曾成功，不代表同一身份的长稿或下一条短稿稳定支持中文。文字长度、传入方式和语速比只能提供排查线索：时长异常可提示先查语种，时长正常或ASR判为中文也可能大量错词。有限缩短仍间歇输出英文时，停止该路线，回到实际语言能力与声音身份选择；不要继续把文本拆得更碎并宣称已修复根因。另选身份时先做有限中文验证，再统一整片，保留无法直接听审的边界。
- 当前目录没有合适语言与气质的身份时，先核真实可用能力，再在已授权配音/剪辑范围内使用可靠的固定语种TTS替代。先用少量本片文案核语言和完整句子，通过后制作完整旁白；不能仅因界面列有某工具就忽略账户模型为空或付费限制。替代身份用于合集时，已认可首片的画面可保留，但其旧旁白也须按统一方案处理，否则首片处仍会换人。记录实际供应方、voice_id、参数、文本和完整take，不把临时工具安装路径或本次身份变成全局默认。
- TTS返回的词边界可能把同一短语分成一个或多个token；不要用某个固定token（如“这是”）出现次数作为段落完整性或剪切依据。先把返回词串与原稿按字符核对，用实际时间和低电平窗口选择句间切口，再用独立转写核全稿。供应方边界是辅助时间线，不等于直接听辨或精确音素边界。
- 只在完整语句外裁剪并保留辅音、气口和尾音；ASR词时间可能把前方静音也分给首字，切口需结合波形/低电平窗口与听审，不能把词时间戳直接当精确剪切点。旁白分布随画面意义，最后一句之后留出环境尾段。先利用自然停顿与时轴定位，不以加速或统一变调凑时长。导出纯旁白、背景和最终混音以便后续修订。
- 音频专修可用视频流复制，核所有解码画面或视频包hash与原版一致、帧数/时间线未变，再核新版完整解码、词句、时序和信号。无直接听审时音色接受仍待用户反馈，不把固定voice_id或ASR正确当听感通过。某次账户不可用的工具/音色清单只记案例，不能固化成Muse永久能力结论。
- 音频增益的测量与渲染使用同一声道/采样率转换链。默认单声道转立体声的声道矩阵可能改变每声道电平；先按实际混音域测量，再核导出值，不把上混导致的变化误判为素材声音消失，也不把某次约3dB差固定为所有转换的补偿。
- 延迟和混音后核每句的绝对起点、句间静音及环境尾段，不能只核总时长或滤镜参数。必要时用从零开始的定长静音轨/预分配时间线固定基准；核实际旁白波形对同一take的裁片映射，避免重置时间戳造成整体提前。ASR词时序若与波形矛盾，先核音频，不据词时间戳再移动已正确对齐的句子。

## 合集的统一声音与标题

- 合集保留逐单元源文件/hash和采用版本，片段验收撤回后同步EDL，不能只按序号或最新文件名拼接。统一标题图、旁白时间线和BGM与视觉素材分开管理；标题需在实际成片上检查可读性及遮挡，预览排版通过不等于压片后通过。
- 固定机位原片的局部污染可按导演参考中的条件做遮罩修复；交Muse剪辑时明确采用修复文件还是按蒙版重算，避免又拼入已撤回原片。静态恢复范围、仍活动区域与原声来源分开登记；本地预览通过后，仍核实际下载成片的源段映射和合成边缘。
- 合片后独立核对采用版本：从已验源按EDL重做若干帧的实际裁切、缩放和标题，比较下载成片的对应帧，再看放大的修复边缘；有损重编码的近似匹配只是来源证据，不代替审美验片。环境声被替换的单元也按实际源、增益和淡化重建后与stem比较，避免画面版本正确而旧人声仍混入；旁白、环境、器乐之和再与最终混音核对。
- 当前账户没有可用音乐模型时，先核已授权的现成无语言素材或其它制作能力。若选择已有代码工具合成原创音符/和声，保留音符表、脚本、WAV和来源说明，明确是代码合成候选；不能冒称音乐模型生成，也不把RMS/峰值通过当好听。此替代不授权升级、外部采样或下载安装。
- 旁白、环境与器乐各导出独立stem，核同一次take的裁片来源、绝对位置和尾句后余量。含旧人声的单元原声不能混入；替代环境素材要登记实际来源与适用的声源关系。BGM跨镜头连续与每个空间的环境声过渡分别安排，避免每段重新启动一首音乐。

## 尺寸与导出陷阱

实测原片尺寸、帧率、时长、音轨后再定导出。请求9:16/720p/2K不证明返回满足；保留实际像素，缩放后不称原生高分辨率。裁切需保护入口、食物、座位等观看重点，记录裁切矩形及是否放大。

### 竖版适配横版

- 已有竖片要改16:9时，先区分保留完整画面加背景、裁切铺满、重新制作横构图。用户已选择一种后直接沿用；“改格式”本身不授权新AI生成或扩景。
- 完整画面配模糊背景：前景按高度等比适配、居中且不裁切，背景由同一帧放大铺满、模糊并适当压暗。核像素取整、横向居中与SAR；背景和前景共用时轴，在每个切点同时换场景，不能混入上一段尾帧。具体模糊半径和亮度按素材判断。
- 无声音改动时直接复制已验音轨，核包hash与时长。复核首尾、每种场景和所有切点两侧，必要时从源按实际滤镜重建采样做对应比对；数值匹配不代替实际看图。
- 1920×1080横版画布不等于源片变成原生1080P横构图，更不等于增加细节。分别报告源片、完整前景、输出画布及平台播放规格，保留竖版源和独立横版文件。

FFmpeg处理yuv420等色度抽样素材时，`crop`默认可能对齐奇数偏移；例如设置横向x=1不保证精确从第1列裁。若逐像素起点确实重要，核当前滤镜的`exact=1`能力及输出，或选可验证的对齐坐标；检查**实际执行脚本**，不能只凭请求里的参数宣称精确居中。已有微小对齐差且不影响构图时如实登记，不为此重生整片。

## 独立验收与交付

拿到实际媒体后分开核验：

| 层面 | 做什么 | 不能据此宣称 |
|---|---|---|
| 文件 | 实际尺寸、fps、帧数、时长、codec、音轨、大小/hash；完整解码 | 审美/语音/全部生成约束通过 |
| 画面 | 全片合理间隔采样＋关键变化＋末帧；切点附近加密，核源段映射 | 稀疏采样等于连续看完、无任何短暂错误 |
| 运动与收尾 | 比较门窗/家具边缘、推近范围、雨汽变化、真正停止时刻 | 提示词写固定机位就等于输出固定 |
| 声音技术 | 音轨存在、峰值/响度、ASR与句界定位 | 听过、音乐好听、音色一致或逐字准确 |
| 直接听审 | 实际可感知的语音/音乐/环境声及衔接，写覆盖范围 | 没听到的区间也通过 |
| 用户/平台 | 用户反馈与真实发布、后台指标分别记 | 技术通过等于用户认可或市场验证 |

短片可用约0.5秒间隔作概览、切点前后数帧加密；这是实用起点，不是固定55张或固定抽样配额。快速动作、短闪帧、可疑重复需更密或连续检查。接触图看不清就放大，不用自动差值指标代替看图。

ASR出现近音词或原片/成片转写不同，标为待听辨，不硬改成预期句子、不凭此判定实际错读。没有直接听音能力时保持listening_pending，可以交试片并明确声音尚未听审，不能称全部验收通过。

交付实际可播放文件，说明改了什么、保留的偏差与下一条需要验证的问题。核下载文件与报告一致；网页显示完成、文件保存、面板已打开、用户已看过分别是不同状态。保留生成/剪辑/验收清单及原片，竞品媒体、网页截图、签名下载链接和凭据不随Skill进入源码。当前电脑使用过的任务ID与窗口编号留项目本地，不写成长期操作入口。
