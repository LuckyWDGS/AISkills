# 标签、引用与发布交接

用于从参考作品整理题材词、标题机制、标签及后续发布基础。事实采样和时效遵循[案例研究](case-study-method.md)，作者系列和转译遵循[作者系列](author-series-and-transfer.md)。

## 标签先记来源，再谈用途

热点须经过实体和落地作品的语义核验，再判断成片能否兑现；同名天气/影视或粉丝语境可能误配。当天复核与低播放诊断的完整方法见[热点与作品表现复核](trend-and-performance-review.md)。

| 字段 | 可放什么 | 常见误用 |
|---|---|---|
| actual_hashtags | 原作详情/作品卡标题中确实出现的hashtag，连同来源和观察时间 | 把“梦核/ASMR”研究分类当作者实际标签 |
| title_keywords | 标题中可核的对象、规则、愿望或结果关键词 | 把标题里没带#的词伪装成原作标签 |
| research_families | 研究者标注的观看机制和母题，可多值 | 声称这是抖音官方分类 |
| suggested_tags | 根据我们实际成片提出的候选词 | 因竞品用过就断言必涨播放 |
| current_topic_entity | 当天查到的原生关联热点实体，记录名称、实体ID/入口、观察时间与关联状态 | 以普通#热词或“热点小助手”文字冒充已经关联 |
| platform_activity | 当时或当天可核的平台活动/工具挑战及资格，有日期和入口 | 把旧创作活动当实时社会热点 |

没采到标签列表时填null/未采集；空数组只有来源确实支持时才能表示本次读取未发现。实际标签可按语义多重归类：

- 场景/对象：庇护所、地铁、深海、月亮。
- 观看用途：助眠、ASMR；这只是作者承诺，是否兑现还要听审。
- 审美/情绪：梦核、治愈系、脑洞、创意；梦核不保证舒缓。
- 制作/平台活动：工具名称、创作成长计划、创作者大会。作者写“由某工具生成”是自述，不推版本、成本或分成。
- 品牌/IP/商业活动：商品名、游戏名、广告比赛等。触发商业核查，不直接判所有相关作品都付费推广。

标签频次只说明这个样本库里作者用了什么。按作品ID计一次，同时显示覆盖作者数；某一大作者几十条重复标签不能冒充全赛道共识。比较同作者普通与较高计数样本中的共同标签，遇到共享词就保留反例。不能把这些频次称平台搜索量、热度指数或推荐权重。

作者覆盖优先按已核规范主页/稳定ID计数，只有显示名时明确“显示名数”，别名未核不能合并。原生“关联热点”、普通hashtag和平台活动分别保存；研究阶段查到实体不等于发布页已关联，实际关联状态由发布Skill按当次UI回读。

再区分三个容易混淆的线索：主页卡的“热点”徽标、从热榜打开作品时URL带的导航参数、作品主区域真实关联的实体组件。前两者各按原范围记证，未取得组件的名称和目标ID时保持`specific_topic_entity=null`；不由普通标签补全。详情只读过某个DOM区域而未见组件时，状态写“本次范围未观察到”，不能写“作品没有关联”。“大家都在搜”也不等于作者主动关联。

批量核证时遍历直接来源及嵌套来源列表，先验证来源hash，再把每处命中绑定到当前作品ID和区域。推荐卡、合集另一集、SEO页脚的活动文字不能转给本作品。没有对照分发数据时，不估算某标签或组件带来的额外推荐量。

实际选词遵循成片兑现：车窗深海片不自动挂“白噪音助眠”；没有能听到的细节声，不因为画面有水就挂ASMR；纯环境也不为追流量关联不相干天气灾情。相关常青词足够时无需硬挂热点。发布时按当日UI和当前内容复核，不设置万能标签数量或混搭配方。

## 标题承诺要回到作品

区分几种可用机制，而非逐句套原作：处境与去处、可选择的生活差异、明确任务与结果、熟悉交通通向陌生地点、时间规则与停留愿望。

每个标题草案回答：首屏怎样让人理解，结尾怎样兑现，什么不是成片内容。标题里许诺到达、动作完成、四季或“一年”，就核影片是否真的给出相应结果/变化；如果只是概念，缩小标题承诺。不要捏造危险亲历、观众选择权或不存在的完整故事。

原作只短引支持分析的部分，配规范作品URL、作者、观察日期和证据范围。分开“原文短引”“我们的解释”“原创试法”。不把竞品长文案、具体反转、镜头顺序和声轨转入用户发布包；署名引用也不自动赋予媒体改编/再发布许可。

## 交给发布Skill的最小材料

研究完成时给具体可复核的简报，实际作品确定后再接douyin-ai-publisher：

```text
研究来源：作品ID/原链接、样本窗口、查看范围、商业/声音未知项。
栏目承诺：这一条让观众获得什么，下次还期待什么。
原创变化：保留的观看功能；新对象/任务/空间/结果。
真实素材：最终文件、时长、画幅、画面与听审状态；概念封面单独标候选。
包装：标题、正文、能被成片兑现的标签；实际标签与建议标签分开。
热点：本次相关与否、核查时间；没有合适热点就明示不关联。
发布核查：真实AI来源与披露、音乐/素材使用状态、当前账号防重记录。
观察问题：本条主要检验什么，发布后哪项实际数据能帮助下一条。
```

首屏吸引、完成观看、收藏、分享、评论投射和关注理由分别提出假设，不用一项代替所有效果。留存/关注归因不可见就保持未知；少量排序评论只是表达样本。完成首条之后，按用户实际反馈与可见后台数据修订，不用漂亮的静态图或模型成功替代市场验证。

研究、存案例或制定发布基础不触发上传和提交。当前用户约定优先：有“准备后由用户最终发布”的持续分工时照此交接，不从“完善Skill”推导发布授权，也不因此新增定时任务。
