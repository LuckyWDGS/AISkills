# 作者系列与原创转译

用于“喜欢这些，继续深挖、更多案例、吸收优缺点”。先核[案例库](case-library/index.md)与当前项目记录。用户给的作品是审美入口；要继续研究作者其他作品、相邻母题和普通表现，不能只把几条标题改成提示词。

## 把喜欢拆成可检验的问题

先区分观众主要在做什么，同一作者可以经营多个格式：

| 观看任务 | 值得继续查的问题 | 不能直接合并的格式 |
|---|---|---|
| 选择：哪个住处属于我 | 每个选项提供什么不同生活，选择是否容易投射自己 | 奖金惩罚选择、灾难求生、安静伴听 |
| 跟随进入：门后还有什么 | 门槛、路线、逐次揭示的新用途、最后是否真的安顿 | 一次推门揭示与多房长巡游 |
| 等结果：这次操作会怎样 | 对象初始状态、操作目的、接触、可见结果及结果后的停留 | 清洁修复、物质反应、无目的变形 |
| 抵达：下一站通向哪里 | 熟悉载体如何固定，外部世界怎样逐层换新，最终去向 | 旅行奇观、深海压迫、怪谈逃生 |
| 停留：可以在这里休息 | 一个可使用的位置、持续的微变化、声音是否兑现用途 | 短时氛围、长时白噪音、音乐展示 |
| 追角色：这次他会怎样选择 | 具体欲望、挫折、决定、可见后果和关系变化 | 毛绒外观、生活小能力、霸凌复仇和长篇漫剧不自动属于同一受众 |

这些是研究分类，不是平台分类或原作标签。梦核、微缩、灾害、天象和列车可以交叉；同样的建筑美术可能服务不同情绪。不要把深海恐惧、怪谈和强烈失重自动包装成助眠。

材质和能力只是入口：毛绒角色也要看其工作、关系与结果；带超能力标签的作品可能服务报复、权力或爱情，而非轻松生活。先按实际冲突与情绪落点细分，再借系列机制。职业、身份和工具用途优先回到字幕/原帧核验，不能由滚刷、木纹或服装缩略图猜职业。

## 体验转折与可使用的空间

跨夜林、房间、列车或商场比较时，先沿实片定位：威胁在窗外还是已进入身边；门窗/扶手等边界何时保持或失效；镜头有无可见退路、选择或被迫移动；熟悉路线何时失去方向感；结尾是安顿、逃出、回环还是悬念。每项绑定时间与线索，再写体验假设。标题“微恐”只能证明作者承诺，不能确定惊吓强度；没有听审，不为助眠背书。可选`experience_profile`保存`promise_basis/observed_turns/ending_observation/trajectory_hypothesis/unknowns`，不强制给全部标题卡补情绪分。

停留片的首屏可以已经兑现承诺。房间持续的雨、叶片、屏幕等细动不必改成任务剧情；判断重点是观众能否把自己安放进去：从入口到床/座位的路线、身体尺度参照、枕头和视线朝向、屏幕/窗景/灯的关系、干湿与内外边界、伸手能否够到想用的东西。只对画面可读性下判断，不由AI画面认证真实尺寸、防水或建筑安全。把“能躺、能看、能用”与“装饰很多、材质精细”分开评审。

用可见评论补需求而非替代市场测量：保存作品ID、观察时间、默认/排序/展开范围，将原话短摘→需求解释→可见支持/反证→下一次原创试验分列。评论可以提出枕头、床宽、怕虫、熟悉感等具体问题；不能算全体观众比例，也不能倒推出低留存原因。相反体验要同时保留，不只选夸赞。

同作者同日同文案/标签/时长/画幅的普通与高计数作品尤其值得实看：共性若同时存在，不能单独解释差距；不同房间构图也仍有声音、发布时间、曝光和投放混杂。实际例与反例见[雨窗、夜林与微恐研究](case-library/evolution-studies.md)。

## 深挖一位作者

以公开主页原链接确认同号，再选能回答问题的作品。主页卡须属于作品列表且作者归属可核，排除页脚SEO、推荐位与别人的作品。按当前工具可访问范围推进，不设置“必须收满多少条”的及格线。

按规范主页/稳定作者标识统计作者覆盖，显示名变体仅作别名线索；未建立同号证据就不合并，未核作者不计入已核覆盖。形成一张有实际作品ID支撑的作者卡：

- **固定承诺**：观众每次回来能得到什么；美术、进入方式、角色视角、声音用途哪些保持稳定。
- **变化维度**：已观察到的空间、尺度、天气、任务、对象、结果、身份、时间规则和目的地。按事实列现有分支，再另列尚未验证的新分支。
- **系列内对照**：近期、样本内较高计数、普通计数、相同母题的新旧作；记录年龄、时长、画幅、商业与查看范围差异。置顶不是全账号排名。
- **重复与疲劳**：哪些段落只换颜色或外壳，哪些真正增加新用途、动作结果或情绪；有多条动态证据才下片内重复结论。
- **账号边界**：同作者也可能做怪谈、商单、工具活动或其他受众内容。作者自述工具按自述记录，不从画面推确切模型和制作成本。
- **下一步**：尚缺哪个普通样本、动态节点、声音或近期日期，它会改变哪一个判断。

“越多越好”要同时增加覆盖广度和可解释深度。分别报新增唯一作品、旧样本复核、元数据广筛、实际画面采样和深入案例；未知作者归属的线索单列。按母题饱和度选择下一批：新作者是否带来新规则，新作品是否提供反例，是否补上此前缺失的声音/结果证据。不能用一页标题凑成几十条完整拆片。

多批主页清单、账号分母与同周普通对照的具体记录按[研究执行](research-execution-and-review.md#多层样本与批次快照)。吸收教程时把教学主张与实片示范分开：可以学相机怎样揭示目的地/用途/结果，不能由示范反推作者的实际模型、提示词或“某关键词必然有效”。

## 制作来源与作者的转化目的

逐作品核`production_origin_evidence`：作者声明AI、游戏开发/实时渲染自述、教程示范与独立工具链验证分层。昵称“游戏开发中”、#UE或画面风格不能确认全部作品来源；#muse也可能是音乐等语境，不能映射成本Skill的Muse工具。跨媒介作品可教路线、空间和叙事，但其点赞或长片时长不证明AI生成的成本与稳定性。来源未核样本单列，不静默升为AI成片。

另存`conversion_evidence`的原文、区域、时间与范围。昵称“收学员”只作线索；主页明确招生/素材/私信引导与本条实际CTA分开，本条广告、付费合作和投流仍分别核。教程或课程潜在受众不能直接当环境故事受众。部分文案被省略时写范围不足，不补全引导内容。

## 优缺点有不同证据门槛

每个重点案例用：**可核观察 → 可能观看机制 → 原作已见限制 → 对我们定位的适配限制 → 制作风险 → 原创试法**。

例如，已见人手/乘客可以判定与“无人环境”交付不同；不能因此称原作错误。区分偶然品牌可见、产品操作/推广演示和明示合作，按[商业证据分层](case-study-method.md#广告与作品分开判定)登记，付费状态独立核。只有标题时只能分析标题承诺与风险线索，不能评价实际运镜、空间稳定性、音乐或全片节奏。等距采样漏短镜，视频有音轨不等于已听审。

后台播放器跳时后要等解码画面就绪。`currentTime`变了但仍在seeking或`readyState < 2`时，canvas可能抓到上一个时间点的旧帧；仅seeked/ready也不能独立证明目标帧，适合时核实际解码帧mediaTime及buffered覆盖。无法确认就登记失败，改用真实本地媒体或缩小覆盖，不能补成有效帧。实际看过接触表才能登记B级；文件和脚本生成成功不等于完成看图。

用户要求每秒3–5帧密分析时，使用[密采样工具](../scripts/sample_reference_video.py)对实际本地媒体默认取4fps，保留源PTS、时间点、源hash与接触表；随后逐页检查并另记已看范围。疑似切镜/动作接触/身份或几何变化附近以`--native --start ... --end ...`加密。4fps是时间采样，不等于逐个检查原片24/30fps全部帧，也不等于有声完整观看。镜数仍须人工确认，抽帧量不自动升级A级。

## 从作者经验发散到自己的栏目

先保留观看功能，再改变具体表达。不要只换星座、颜色或字幕；任务、核心对象、空间关系、生活愿望、操作结果、进入路线或情绪走向至少要有实质新设计，且能解释自己保留了什么、改变了什么。这是创作检视，不是原创或版权的数量判定公式。

| 已见系列机制 | 可探索的邻近问题（创作假设） | 首次试验可缩到什么 |
|---|---|---|
| 外险内安 | 不升级灾难，能否用一个“有人替我准备好”的生活细节成立 | 干燥拖鞋或烘暖毛巾的一次结果 |
| 天体维护 | 奇观能否承担照料、休息、修复日常的情感 | 一项可读任务与一个清楚结果 |
| 固定载体换目的地 | 窗内稳定、窗外换世界，可否从恐惧转成舒缓抵达 | 保留一个车窗锚点，只换一层外景 |
| 缩小进入私人空间 | 归属感能否来自尺度与可使用性，而不只身份分配 | 入口、身体尺度参照与一处可停留位置 |
| 有规则的秘境 | “住一年”之类规则能否在生活变化中兑现 | 同一地点一次时间或天气变化 |
| 无尽供应/压缩物件 | 等结果的满足感能否转成一次有节制的补给 | 一个容器、一次操作、一个可确认状态 |

发散后收敛到当前账号和制作条件。给每个方向写观众承诺、首屏物、值得等的变化、声音职责、最大失败点和简化退路。没有用户选定的新方向不能自动变成连续制作授权；只研究时到研究和简报为止。

高低数据对照的结论必须允许失败：同问句、同标签、同美术在普通作品也出现，就不是高赞的充分解释。缺曝光、同龄、投流和留存时，不能归因。自己的测试先选一个主要问题，发布后读取实际可见指标，再决定保留、修订或淘汰；研究没有授权无人值守发布或监控。
