# 时长与镜头核查

用于回答“这些作者的视频多长、约几镜、我的方案该多长”。给出实用约数与证据边界，避免用卡片时长猜剪辑结构。具体作者、作品、切点和本轮结论存项目；Skill保留核查方法，不把一批样本的秒数固化成模板。

## 先分清在数什么

| 项目 | 计数口径 |
|---|---|
| 整片时长 | 详情播放器或实际媒体；保留来源，四舍五入的页面秒数与文件实测分列 |
| 可见镜头 | 明确可见剪辑切换之间的观看段；摇移、进门、转向、明暗变化本身不新增镜头 |
| 空间／主题段落 | 换房、换星座、换主要情境；一个段落可以有多个镜头，一个长镜式段也可经过多个房间 |
| 内容节拍／用途 | 新物件、生活功能、动作结果、情绪或声音意义；不换机位也可增加信息 |
| 生成UNIT／隐藏接缝 | 作者制作链通常未知；不能从一镜式观感推断一次生成，也不能把微跳自动算成新镜头 |

先分短氛围或揭示片、多房选择合集、叙事巡游、商业产品展示、长时伴听，再在相近观看用途内比较。横竖画幅、第一人称人手与无人空景也记录；跨格式只能借功能，不能直接照搬片长或镜数。广告卡排除，作品内产品段单列，未证实的付费合作与投流保持未知。

## 取得与核验

1. 回到原作品核作者、完整标题、发布日期和当前URL，沿用近期窗口及广告分组规则。历史高赞单列为技法参考。页面元数据升级为实际动态证据时保留前次范围，不倒写成此前已经看过。
2. 核真实时长和画幅。需要本地分析时只用页面实际观察到的媒体资源；blob或分轨播放器可先查实际媒体请求。临时签名URL、请求日志和完整参考视频只留本地，不进Git、Skill或用户发布包。页面时长、视频轨时长与完整音画文件不等价，分轨来源照实写。
3. 对实际视频作全帧场景变化筛查，再结合全程等距抽样、首末和所有候选邻域人工查看。阈值服务于该素材，没有通用及格值；候选过少时查低对比切点，候选过多时排除运动与纹理变化。稀疏抽样或单阈值检测不能证明没有短插入镜头。
4. 候选前后要看相机位置、物件状态与运动路线是否连续。出隧道、开门遮挡、快速转向、扫过暗墙、闪光、雪雾和变形都可能误报；±一两帧不足时扩大邻域、加密到约0.25秒或查看连续片段。相邻帧重复触发同一次过渡时合并，结尾渐暗不单独加镜。相似机位微跳与疑似生成接缝单列，不强判为真实剪辑。
5. 已确认硬切给切点；覆盖不足就给约数／下限。全片有三处不同空间不必然等于三镜。适合时写“3个明确长镜式房间段、2处换房硬切，内部接缝未决”；只复核了两个段落，就只报告这两段的一镜式观感和用途数，不补全片精确镜数。

工具场景分数是候选证据；最终计数依赖实际查看范围。没有听审则audio_review=not_listened，不能用声音连续性证明隐藏接点，也不能评价BGM、音效或独白。

## 记录与给方案

每条至少保存作品/作者链接、原始日期与观察时间、时长来源、比例、格式分组、确认切点、可见镜头约数或下限、空间段数、每段时长、用途/节拍、疑似接缝、取样区间与数量、声音状态、商业证据。没有核的字段填unknown，不用0；“约1个长镜式段”不写成“确认原生一镜到底”。

交付先给作者—作品—时长—镜头约数表，再解释对自己方案有什么影响。多房合集比较每房时长；单空间比较注意转移、新用途与结果；商业段较密的作品另算其节奏；长时伴听不与短片平均出一个“最佳片长”。这些样本不能证明时长或镜数导致流量。

自己的片长是编辑判断，标为建议而非已验证结论。先确定首屏承诺、值得等的小变化、可停留结果，再决定是否切镜与保留多久。相邻时段只有同义陈列就缩短或重写；需要更多信息时可先改变注意、动作结果或声音，而非增加新房间。不要用冻结、循环或无效缓推凑秒数；生成稳定性需要拆UNIT时，也不必增加可见切镜。用户只要研究时交到建议和证据，不自动生成或发布。
