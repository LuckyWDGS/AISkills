# chatgpt-apps

`chatgpt-apps` 用来规划、搭建和修复 ChatGPT Apps SDK 项目，重点覆盖 MCP server、widget UI、工具注册、资源注册、CSP、部署与示例迁移。

## 什么时候用

- 你要从零做一个 ChatGPT App
- 你要把现有 MCP/网页能力接进 ChatGPT Apps
- 你要检查 Apps SDK 项目结构、工具 schema、widget bridge 或 CSP
- 你希望 Codex 先查官方 OpenAI 文档，再生成代码

## 重点

- 默认和 `openai-docs` 配合，先确认最新 Apps SDK 文档
- 先判断 app 类型，再决定用官方示例、上游示例还是本地 scaffold
- 产出应包含可运行项目结构、验证步骤和实际验证结果
