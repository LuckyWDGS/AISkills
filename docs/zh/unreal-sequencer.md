# unreal-sequencer

`unreal-sequencer` 通过 UE 5.8+ 内置的 Epic MCP（Sequencer 工具集，共 140+ 个工具）搭建、检查、验证和渲染关卡序列（Level Sequence）。显示名称为 **Unreal Sequencer**，依赖同目录下的 `unreal-engine-mcp`（共享 MCP 客户端）。

## 什么时候用

- 做过场动画、开场/结尾镜头、镜头巡游、游戏内演出
- 摄像机推拉摇移、镜头切换、焦距/对焦/光圈动画、淡入淡出
- 给关卡里的 Actor 打位移关键帧或挂骨骼动画
- 审查或修复已有序列：镜头空档、重叠、没绑摄像机、空轨道、关键帧超范围

## 它会帮你做什么

- 先写镜头简报（节拍、镜头表、焦段、运动、触发方式），确认后再动手
- 用一份镜头计划 JSON 一次生成整段序列；`look_at` 自动算朝向，`focus: auto` 自动对焦
- 只读检查与 lint，逐帧采样核对每个关键帧的位置、角度、焦距，并做视线遮挡检查
- 只在有明确视觉问题时渲染关键帧 PNG（取景、可读性、是否被挡）

## 重点

- 帧号一律按显示帧率计；新建摄像机会自带变换轨和焦距/对焦/光圈轨，直接用，不要重复加
- 关卡 Actor 绑进序列前，先把变换通道默认值设为它当前的变换，否则会被转正、缩放归一
- 官方 `set_camera_cut_binding` 在 5.8.4 有 bug，技能用编辑器 Python 绑定镜头切换
- 不会自动保存；需要你明确要求才保存
