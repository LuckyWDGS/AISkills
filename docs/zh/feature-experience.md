# feature-experience

`feature-experience` 用来把一个功能从“点子”变成“能落地的产品模块”。

## 什么时候用

- 用户要一个功能、模块、流程、菜单或页面
- 需要判断这个功能应该包含什么、怎么串起来、怎么接真实数据
- 需要决定要不要补设计参考、补状态图、补空态或错误态

## 它会帮你做什么

- 梳理入口、动作、状态、数据源和相关流程
- 判断性能、缓存、离线、重试、空态这些约束
- 如果需要设计参考，会配合 `ui-from-design`
- 如果需要补视觉参考或素材，会配合图像生成技能

## 重点

- 功能不是一张图，而是 intent + data + states + verification
- 默认接真实数据，不要把演示数据当运行时数据
- 先把功能边界讲清楚，再开始写代码或补设计
