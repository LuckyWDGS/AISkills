# mentalout-image-browser

`mentalout-image-browser` 是通过 `https://image.mentalout.top/` 操作的图像工作流。

## 什么时候用

- 用户明确提到 Mentalout、Snow AI 或 `image.mentalout.top`
- 需要按参考图生成、编辑图片或做多张风格统一的图
- 需要走网页界面而不是通用图片技能

## 你会怎么用

- 先开网页，再填 `MENTALOUT_IMAGE_API_KEY`
- 再填 prompt、尺寸、数量、风格提示和输出设置
- 生成后从展示区或历史里选结果

## 重点

- 它是“网页驱动”的技能，不是 CLI 包装器
- 适合做统一视觉系统、连续批量风格探索
- 没有浏览器自动化能力时，要先说明限制
