# codex-session-continuity

`codex-session-continuity` 用来把长会话里的关键信息外置到项目文件里，方便下次继续。

## 什么时候用

- 任务跨很多轮，容易丢上下文
- 你要切新窗口、换电脑或暂停后再接着做
- 你要在结束前整理变更、验证结果和下一步

## 它会关注什么

- `HANDOFF.md`
- `PROJECT.md`
- `ASSETS.md`
- `DEBUG_SCREENSHOTS.md`
- `DECISIONS.md`

## 重点

- 只记录可复用、可验证、能恢复工作的事实
- 不要把聊天过程原样搬进去
- 变更前先读最近的 handoff，再对照当前仓库状态
