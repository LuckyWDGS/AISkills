# image-generation-director

`image-generation-director` 是偏创意总监的图片与短视频前期技能，负责生图方向、提示词修复、趋势选题、账号内容建议、AI 视频概念和故事板规划。

## 什么时候用

- 你要优化或重写生图 prompt
- 你要保留原始画面效果，同时修掉污染词或过度保守改写
- 你要做海报、人像、产品图、写真、贴纸、微型世界、机甲或 3D CG 风格图
- 你要诊断抖音/小红书/TikTok 低流量、新号内容方向或选题
- 你要把图片概念延展成短视频或分镜

## 重点

- 先保护用户真正想要的视觉效果和关键词
- 对实时热点或平台趋势要先查证再下结论
- 成人向非露骨人像只做审美和服装剪影层面的安全表达
