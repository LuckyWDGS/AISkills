# cm-imagegen

`cm-imagegen` 是这套 skills 里的图片生成与编辑技能，负责常规生图、参考图生成、UI/mockup、布局重做、素材生成等工作。

## 什么时候用

- 你想生成一张新图
- 你想根据参考图做图生图、改图或重做布局
- 你想做 UI mockup、海报、产品图、游戏素材或多图批量
- 你明确要走 CodexManager / 本地图像路线

## 重点

- 先把需求写清楚，再给出用途、画面目标和限制条件
- 有参考图时，说明哪些内容要保留，哪些要重画
- 批量生成时，优先保持同一套风格锁

## 注意

- 不要拿它去绕过安全拒绝
- 如果用户明确要求系统 built-in imagegen，就按那个路线走
- 更详细的中文说明可看 `skills/cm-imagegen/README.zh-CN.md`
