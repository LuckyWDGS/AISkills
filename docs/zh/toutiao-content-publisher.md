# 今日头条图文发布助手

[执行入口](../../skills/toutiao-content-publisher/SKILL.md) · [技能目录](README.md)

把已批准的图片和文字整理成头条号图文文章：正文插图按段落落位，独立三图封面逐槽核对，广告收益、AI 标识、首发与同步按事实设置；保存后刷新重开、滚动完整手机预览，再在本次明确授权下提交一次并核验真实文章 ID 与审核状态。也可仅离线归档历史记录，或只读复盘文章数据。

例：`$toutiao-content-publisher 把这组 A/B/C 六图整理成头条文章，保存草稿并核对封面，暂不发布。`

不处理微头条、图集或视频；与小红书分别查重和授权，不借用对方的原创、活动或封面规则。技能源码统一在 AISkills；各内容项目的素材、账号记录与防重台账继续保存在各自项目。
