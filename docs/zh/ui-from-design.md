# ui-from-design

`ui-from-design` 用来把明确的设计稿、截图、mockup 或原型变成可实现的界面。

## 什么时候用

- 用户明确给了设计图、参考图或截图，要按它做界面
- 需要对齐布局、层级、间距、字体、图标和状态
- 需要拆分大设计，补缺失模块、空态、错误态或响应式版本

## 它会帮你做什么

- 先看设计覆盖了哪些区域和状态
- 建设计到实现的对照表
- 缺参考图时，补最小可实现的模块图
- 再按设计去改代码，而不是凭感觉重排

## 重点

- 只有用户明确把图当设计参考时，才走这个技能
- 大设计先拆成小模块，再逐个实现
- 如果只知道“想要什么功能”，先走 `feature-experience`
