# fantasy-character-design

`fantasy-character-design` 用来把玄幻、仙侠、神女、女帝、精灵、法器、服装等角色想法整理成可复用的角色设定板和生图提示包。

## 什么时候用

- 你要做人物设定图、角色 bible、三视图或转面图
- 你要先锁定主角形象，再进入分镜、首帧图或视频生成
- 你需要脸、服装、道具、材质和风格参考的权重/裁剪优先级
- 你要把零散参考图整理成统一角色资产

## 重点

- 先锁定脸、服装轮廓、主色、道具和风格锚点
- 人物三视图应在同一张审查图中保留完整正面、90 度侧面、背面及清晰面部近景；正式视频输入另导出干净单人图。
- 输出适合给生图、分镜或视频工作流继续使用
- 避免只写气氛词，要给出可执行的视觉约束
