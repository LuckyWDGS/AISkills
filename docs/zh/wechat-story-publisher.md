# 公众号故事图文

[执行入口](../../skills/wechat-story-publisher/SKILL.md) · [技能目录](README.md)

从近期资料和账号表现出发，写完整、容易理解的故事，单独选择有钩子的发布标题，再做连续配图、中文排版、实际图片复核和公众号草稿回读验证。按当前请求交付草稿或执行具体发布。

标题优先突出故事里真实的冲突、反差或悬念，并在正文中兑现。例如情节成立时，工作名《房东让我恢复原样》可改成《退租时我拆了窗帘，房东不让了》。不为吸引点击虚构金额、纠纷或情绪。

例：`$wechat-story-publisher 结合最近一周资料写三篇完整故事，比较后制作推荐篇；标题要有钩子，保存并验证公众号草稿，由我发布。`

配图方向复用 `image-generation-director`，实际生图复用 `cm-imagegen`。故事、图片、浏览器证据、账号与发布记录留在各自内容项目；技能源码统一在 AISkills。
