# vps-proxy-deploy

搭建、维护和排查用户自有 VPS 的代理节点，以及 Clash Verge/Mihomo 订阅、DNS、应用分流、WebRTC/CLI 出口保护与性能。

执行流程与参考资料见[技能入口](../../skills/vps-proxy-deploy/SKILL.md)。

- 使用当前选定的服务器、客户端和协议，优先局部修复现有配置。
- 只读诊断与实际部署按用户请求区分；真实服务器地址、凭据和订阅地址由用户本地提供。
- 历史分流候选表需要现场复核，不应整表自动安装。
- 支持保留抖音、B站、公众号等明确直连名单，同时移除国内全量兜底；按任务验证 UDP 回退、物理网卡阻断及故障恢复。
- 区分本机回环代理绕过、端口连接和 UE/Zen 缓存可用，未完成应用验证时不宣称修复。
- 不用于代理购买推荐或网站风控规避。

开始示例：

```text
$vps-proxy-deploy 只读检查我现有节点和订阅，定位无法连接的原因。
```
