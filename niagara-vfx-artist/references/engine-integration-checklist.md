# 引擎接入检查清单

## 用途

这份文档用于处理特效方案落到 Unreal 引擎里的最后一公里问题。

适合在这些场景读取：
- 效果已经做出来，但还没真正接进玩法
- 需要动画、蓝图、User Parameters、Effect Type、Scalability 的接入检查
- 需要减少“效果本身没问题，但游戏里接得不对”的问题

## 1. 使用目标

重点不是“效果怎么做”，而是：
- 效果怎么挂到角色 / 技能 / 场景
- 参数怎么从游戏逻辑驱动
- 性能预算怎么接进工程体系

---

## 2. 动画 Notify 接入

适合：
- 挥刀命中
- 武器附着特效
- 蓄力 / 释放节点

### 检查项

- [ ] 起始帧是否对齐动作
- [ ] 峰值帧是否对齐重击点
- [ ] 结束是否拖太长
- [ ] 循环类效果是否该用 timed notify

### 原则

- 短促爆点：普通 notify
- 持续循环：timed Niagara notify

---

## 3. 蓝图参数驱动

适合：
- 颜色随状态变化
- 强度随技能阶段变化
- 生命周期 / 尺寸跟玩法逻辑联动

### 检查项

- [ ] 蓝图只驱动必要参数
- [ ] 没有把所有内部值都暴露出去
- [ ] 参数名清楚
- [ ] 默认值合理

### 原则

- 游戏逻辑应驱动玩法相关变量
- 不要让蓝图直接控制所有材质细节

---

## 4. User Parameters 暴露

### 推荐暴露项

- 颜色
- 强度
- 尺寸倍率
- 生命周期倍率
- 开关类状态

### 不建议大量暴露

- 每个噪声细节
- 每个局部微调值
- 只为特效师自己用的内部参数

### 检查项

- [ ] 暴露参数数量克制
- [ ] 命名统一
- [ ] 默认值能单独成立

---

## 5. 特效附着与空间检查

### 检查项

- [ ] 挂点是否正确
- [ ] 本地空间 / 世界空间是否合理
- [ ] 角色移动时不会明显漂
- [ ] 武器附着时不会错位

### 常见错误

- 本地空间和世界空间选错
- 特效跟角色动作不一致
- 旋转轴没对齐

---

## 6. Effect Type / Scalability

### 检查项

- [ ] 是否分配了 Effect Type
- [ ] 是否配置了距离裁剪
- [ ] 是否有 Spawn Count 缩放
- [ ] 是否有平台差异缩放

### 原则

项目稍微大一点，就应该把 Niagara 资产纳入统一预算体系。

---

## 7. 平台与低配接入

### 检查项

- [ ] PC 版和低配版资源路径是否明确
- [ ] 低配版是否真能切换
- [ ] Flipbook / 材质 / Emitter 简化是否已接入
- [ ] Android / 低端机是否有单独预算

### 原则

低配版不是文档里写一下，而是要真正能被系统调用。

---

## 8. 最终接入检查表

- [ ] 动画时机正确
- [ ] 蓝图驱动参数合理
- [ ] User Parameters 暴露克制
- [ ] 挂点与空间正确
- [ ] Effect Type / Scalability 已接入
- [ ] 平台版本切换可用
- [ ] 效果在真实玩法链路里能稳定工作

---

## 一句话原则

特效在编辑器里成立，只算完成一半；
真正交付，要看它是否已经被正确地挂进动画、蓝图、预算和平台体系里。
