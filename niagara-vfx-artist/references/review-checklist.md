# Niagara VFX 审查清单

## 用途

这份文档用于在拿到“别人已经做好的特效”时，系统地做审查、点评和复盘。

适合在这些场景读取：
- 你想 review 别人的 Niagara 特效
- 你想快速判断一个效果好不好、问题在哪
- 你想做团队内统一的审查标准
- 你想把“凭感觉看”变成“有条理地看”

## 1. 审查目标

审一个特效时，建议始终按这几个方向看：

1. 好不好看
2. 看不看得懂
3. 技术结构是否合理
4. 性能是否可接受
5. 是否符合目标平台

不要只看“酷不酷”，也不要只看“能不能跑”。

---

## 2. 第一眼检查

先不用看细节，先回答这几个问题：

- 这是什么效果，一眼能不能认出来？
- 最重要的信息有没有在第一时间出来？
- 视觉重心是不是明确？
- 有没有明显糊、乱、白、闪爆的问题？

如果第一眼就读不懂，后面的复杂细节通常意义不大。

---

## 3. 视觉设计检查

### 检查项

- [ ] 色彩层次清楚
- [ ] 主次关系明确
- [ ] 节奏有起伏
- [ ] 动势方向合理
- [ ] 不会从头到尾一个状态

### 常见提问

- 核心层是不是最重要的视觉点？
- 边缘、中心、尾部有没有区分？
- 是不是只有“亮”，没有“层次”？

---

## 4. Niagara 结构检查

### 检查项

- [ ] Emitter 数量合理
- [ ] 每个 Emitter 职责明确
- [ ] 没有明显重复层
- [ ] 生命周期设置合理
- [ ] Spawn / Burst 与视觉节奏一致

### 审查重点

- 这个 Emitter 是不是有存在价值？
- 有没有两个 Emitter 做了差不多的事？
- 结构是不是过度复杂但收益很小？

---

## 5. 材质检查

### 检查项

- [ ] 材质是否和效果类型匹配
- [ ] 参数命名是否统一
- [ ] 发光是否克制
- [ ] 噪声是否服务于表现，而不是乱加
- [ ] 流动是否真的增加了质感

### 审查重点

- 是不是靠堆亮度假装效果成立？
- 参数是否清晰到别人接手也能改？
- 材质复杂度和视觉收益是否匹配？

---

## 6. 可读性检查

### 检查项

- [ ] 玩家一眼能理解效果类型
- [ ] 不遮挡关键角色 / UI
- [ ] 命中、爆发、结束节点清晰
- [ ] 同屏多个效果时仍能区分

### 审查重点

- 特效是不是比游戏信息更抢戏？
- 屏幕中心是不是被过度占满？
- 远看还认不认得出它是什么？

---

## 7. 性能检查

### 检查项

- [ ] 粒子数量合理
- [ ] Emitter 数量合理
- [ ] 透明覆盖没有失控
- [ ] 材质采样数合理
- [ ] 已有 LOD / Culling 思路

### 审查重点

- 单个效果能跑，不代表同屏能跑
- 视觉收益最低的层，是否反而最贵

---

## 8. 平台检查

### 检查项

- [ ] 目标平台是否明确
- [ ] 有没有移动端专用减配版
- [ ] 有没有低配回退策略
- [ ] PC 方案是否被误用到 Android

### 审查重点

- 这套方案是不是默认只适合 PC？
- 如果切到移动端，哪些层必须先删？

---

## 9. 复盘输出建议

当你审完一个特效后，建议输出可以按这个顺序组织：

1. 先说整体判断
2. 再说最影响效果的 1 - 3 个问题
3. 再说最值得保留的优点
4. 最后给出明确修改方向

### 推荐输出模板

```text
整体判断：
[一句话总结]

主要问题：
1. [...]
2. [...]
3. [...]

优点：
1. [...]
2. [...]

修改建议：
1. [...]
2. [...]
3. [...]
```

---

## 一句话审查原则

不是看“它做了多少”，而是看“它最重要的视觉信息有没有被正确、清晰、便宜地表达出来”。
