# 项目级特效风格统一指南

## 用途

这份文档用于解决“单个效果成立，但整套项目特效风格不统一”的问题。

适合在这些场景读取：
- 一个项目里要做很多技能或场景特效
- 需要统一视觉语言
- 需要让不同技能既有区分度，又像同一个世界观下的东西
- 需要建立项目级 VFX 风格标准

## 1. 为什么需要项目级统一

单个特效好看，不代表项目整体成立。

项目级 VFX 常见失败点不是：
- 某个效果太丑

而是：
- 每个效果像不同项目做的
- 技术路线和审美判断不统一
- 阵营和属性语言冲突

所以项目级统一的目标是：

- 让玩家感觉这些效果属于同一个世界
- 让不同技能有区别，但不是完全割裂
- 让风格成为系统，而不是偶然结果

---

## 2. 什么叫同一套视觉语言

同一套视觉语言通常意味着以下几件事是相对统一的：

### 形状逻辑

- 圆润还是尖锐
- 几何还是有机
- 线性还是块状

### 色彩逻辑

- 主色体系
- 高光体系
- 明度控制方式

### 节奏逻辑

- 峰值是快还是慢
- 残留是长还是短
- 常驻状态是否克制

### 材质逻辑

- 是否偏干净发光
- 是否偏脏噪声
- 是否偏流动表皮
- 是否偏体积和烟感

如果这些完全没有共性，项目就会显得碎。

## 3. 必须统一的项目级规则

下面这些东西，最好在项目层统一，而不是每个效果各自为政。

### 1. 命名规范

- 材质
- 纹理
- Niagara System / Emitter
- User Parameters

这已经在现有文档里有基础，但项目里必须严格执行。

### 2. 主材质思路

例如：
- 护盾类是否都用 Fresnel + Noise
- 命中特效是否都用 Additive 主闪光 + Ring
- 常驻 Aura 是否都更克制

### 3. 亮度控制标准

必须统一：
- 最高亮区面积
- 常驻效果亮度上限
- 峰值爆发强度范围

否则项目里会出现：
- 有的技能像手电筒
- 有的技能像没开灯

### 4. 残留控制标准

要统一：
- 命中特效残留是否一律短
- 常驻效果是否允许长尾
- 群战中哪些层必须缩短

### 5. 层级习惯

例如：
- 主层永远先做
- 辅层不能压过主层
- 残留层只做补充

这些规则越统一，整体风格越稳。

## 4. 必须区分的技能级规则

统一不代表每个技能都长一样。

必须允许技能之间在这些维度区分：

### 1. 属性

- 火
- 冰
- 电
- 毒
- 治疗
- 黑暗
- 神圣

### 2. 功能

- 攻击
- 防御
- 位移
- 回复
- 蓄力
- 召唤

### 3. 强度等级

- 普通技能
- 强化技能
- 终极技能
- Boss 技能

### 4. 阵营 / 职业 / 势力

同属性不同阵营，也应该有细微差别。

例如：
- 同样是火
- 骑士系火焰可以更干净、金红
- 深渊系火焰可以更脏、黑红、边缘侵蚀

所以项目级统一不是“同色同形”，而是“同规则不同表达”。

---

## 5. 阵营、属性、职业的统一与差异

### 推荐做法

先定义三层规则：

#### 第一层：项目总风格

例如：
- 偏写实
- 偏风格化
- 偏科技
- 偏魔法史诗

#### 第二层：阵营 / 势力规则

例如：
- 圣堂：更干净、更对称、更金白
- 深渊：更破碎、更脏、更黑紫
- 科技组织：更规则、更几何、更蓝青

#### 第三层：属性 / 技能功能规则

例如：
- 火：上升、热核、扰动
- 冰：硬边、脆裂、低温
- 治疗：包裹、向上回流、柔脉冲

### 这样做的好处

最终一个技能既能看出：
- 它属于哪个世界
- 它属于哪个阵营
- 它是什么属性
- 它是什么功能

## 6. 风格漂移的典型症状

### 症状 1：每个效果都很好看，但不像一个项目

原因：
- 单效果标准高，项目级规则缺失

### 症状 2：同属性技能之间像不同属性

原因：
- 属性语言没统一

### 症状 3：同阵营技能没有家族感

原因：
- 阵营层规则缺失

### 症状 4：有的技能很炸，有的很弱

原因：
- 亮度和节奏上限没统一

### 症状 5：常驻效果和爆发效果一样吵

原因：
- 功能级别没有建立差异化标准

---

## 7. 项目级检查清单

当你在看一整套特效时，快速检查：

- [ ] 命名规范是否统一
- [ ] 常驻与爆发效果的强度边界是否清楚
- [ ] 同属性技能是否有家族感
- [ ] 同阵营技能是否有统一材质 / 色彩 / 形状逻辑
- [ ] 不同技能之间是否既可区分又不割裂
- [ ] 高亮控制是否统一
- [ ] 残留控制是否统一
- [ ] 风格化 / 写实方向是否一致

---

## 一句话原则

项目级统一风格不是把所有特效做得一样，而是让它们遵守同一套底层规则，再在属性、功能和阵营层面做有控制的差异化。
