# Niagara Fluids 排错手册

## 用途

这份文档专门用于处理 Niagara Fluids 里最常见的实战问题。

适合在这些场景读取：
- 模拟结果明显不对
- 你知道大概该调哪些参数，但不知道先动哪个
- 需要把“症状”快速映射到“排查顺序”

这份文档和 `fluids-parameters.md` 的关系是：
- `fluids-parameters.md` 更偏“参数理解”
- 这份文档更偏“问题排查”

## 1. 使用原则

排 Niagara Fluids 问题时，不要一看到结果不对就同时改：
- 分辨率
- Source
- Noise
- Temperature
- Density

更稳的方式是：

1. 先看大形体
2. 再看大运动
3. 再看细节
4. 最后看成本

也就是说：

先解决“像不像”，再解决“精不精”。

## 2. 烟太松

### 典型症状

- 烟雾像一团很散的雾
- 没有明显体积感
- 看起来不聚、不卷、不成形

### 优先检查项

1. `Pressure Iterations`
2. `Density`
3. `Source / Injection`
4. `Dissipation`

### 常见原因

- 压力求解太弱
- 密度太低
- 注入量太弱
- 消散太快

### 推荐修复方向

- 先适度提高 `Pressure Iterations`
- 再提高一点 `Density`
- 如果还是太空，再加强 `Source`
- 最后确认是不是 `Dissipation` 太高

### 不要先做什么

- 不要一开始就只加 Noise

原因：
- 烟太松不是“细节不够”
- 是“骨架先没立起来”

## 3. 火不往上走

### 典型症状

- 火焰像在原地抖
- 或横向乱散
- 没有热空气上升的感觉

### 优先检查项

1. `Temperature`
2. `Buoyancy`
3. `Source Direction`
4. `Velocity / Injection`

### 常见原因

- 温度太低
- 浮力太弱
- Source 本身方向就没往上
- Dissipation 太快，刚起来就没了

### 推荐修复方向

- 先提高 `Temperature`
- 再提高 `Buoyancy`
- 再检查 Source 的主方向是不是正确
- 如果还是短促，检查 `Dissipation`

### 常见误判

- 看到火不活就拼命加 Noise

问题是：
- Noise 只会让它更乱
- 不会自动让它像热流

## 4. 水花不成形

### 典型症状

- 水花像一团湿雾
- 不像 splash
- 没有冲击和分离感

### 优先检查项

1. 你是不是本来就选错方案了
2. `Source Strength`
3. `Velocity / Injection`
4. 分辨率是否足够

### 先做判断

很多时候问题不是调参，而是路线选错了。

如果你要的是游戏常规 splash：
- 很多情况下应该先用 `Flipbook + Niagara`

而不是强行让实时流体承担所有工作。

### 推荐修复方向

- 先确认是不是需要改成 `2D FLIP` 或干脆烘焙
- 如果路线没错，再增强注入和冲击速度
- 再看分辨率够不够支撑 splash 断裂感

### 常见误判

- 想用一套重液体模拟直接解决所有 splash 视觉问题

社区成熟经验恰恰相反：
- 很多 splash 的最终效果都是 flipbook

## 5. 细节太糊

### 典型症状

- 流体整体有了
- 但边缘糊
- 小翻卷不清楚
- 近看不够精致

### 优先检查项

1. `Grid Cell Size`
2. `Noise / Turbulence`
3. `Pressure Iterations`

### 常见原因

- 分辨率太低
- 细节扰动太弱
- 压力求解不够

### 推荐修复方向

- 先降低 `Grid Cell Size`
- 再补一点 `Turbulence / Noise`
- 再确认 Pressure 质量够不够

### 常见误判

- 细节糊就疯狂加 Noise

如果分辨率不够，再多 Noise 也只是更脏，不会更清楚。

---

## 6. 结果太块

### 典型症状

- 边缘有明显格子感
- 结果像低分辨率体素
- 形体不够圆润

### 优先检查项

1. `Grid Cell Size`
2. 可视化尺度是不是过近
3. 是否超出当前分辨率预算

### 常见原因

- Cell Size 太大
- 模拟域太大但分辨率不够

### 推荐修复方向

- 先减小 `Grid Cell Size`
- 或缩小模拟空间范围
- 不要一边想要超大域，一边又想要超细节

### 常见误判

- 结果太块就去调颜色、密度、噪声

这类问题通常首先是分辨率问题。

## 7. 模拟很好看但游戏里太贵

### 典型症状

- 编辑器里很棒
- 多放几个就掉帧
- 游戏里根本不敢用

### 优先检查项

1. 这东西是不是应该烘焙
2. 分辨率是否过高
3. 是否用了不必要的 3D 方案
4. 是否缺少低配回退方案

### 推荐修复方向

- 先问：这是不是应该 `Bake to Flipbook`
- 先降分辨率
- 能用 `2D Gas` 就别硬上 `3D Gas`
- 能用 `Flow Map` 就别直接上体积模拟

### 社区成熟路线

很多“很好看但太贵”的流体，真实项目里最后都会走：

1. 高质量模拟
2. 渲染成 Flipbook
3. 游戏中用 Niagara Sprite 播

### 常见误判

- 觉得真实就一定要实时

实际项目里：
- 很多最好的流体画面，最终都是烘焙资产

---

## 8. 先查什么后查什么

遇到 Niagara Fluids 不对时，建议按这个顺序查：

1. 先查路线是不是选错了
   - 是不是该用 Flow Map
   - 是不是该用 Flipbook
   - 是不是没必要实时算

2. 再查大结构
   - Source
   - 温度 / 浮力
   - 密度 / 消散

3. 再查质量
   - Grid Cell Size
   - Pressure Iterations

4. 再查细节
   - Noise / Turbulence

5. 最后查成本
   - 是否该烘焙
   - 是否该降级

---

## 一句话原则

Niagara Fluids 最常见的问题，不是“参数没调够”，
而是“路线没选对”或者“先后顺序搞反了”。
